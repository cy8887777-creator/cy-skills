# flow-front-ui-line-cy-design-pack-pipeline — 图包 → 多页前端项目管线

把一包效果图变成一个高保真、带交互、有 mock 数据的多页 H5 前端工程。
**L1/L2 分派**：检测到 `flow-front-ui-line-cy-img-to-code` → L2（默认），⑤⑦
走单页技能完整状态机（verify + 独立裁判）；未安装 → L1 降级——
⑤⑦降为"布局文档 + 源图参照直写 TSX"（走⑧结对流水，主力页补
源图参照字段，保真降级在交付报告如实声明），环境前置的
doctor/模型步骤仅 L2 需要。

## 激活协议（激活回合一次性收集全部 8 项；中途零打断）

**激活回合顺序：输出能力卡 → AskUser #1（需求 4 问）→ **本地跑设备
形态探针**（`intake.py <图包目录> --probe`——AskUser #1 拿到图包路径
后、#2 弹出前执行，激活回合内本地步骤不构成打断，零 VLM）→ AskUser
#2（执行策略 4 问，含按探针预填的「目标设备」）→ 全部到手后才开始
①盘点。**

**执行策略 4 参数不依赖盘点结果**（并行子代理数决定②盘点怎么分批
跑——必须在盘点前收集；参与度是流程结构属性（决定升级路径与停等
密度）；目标设备定壳/验收视口（C-09，探针预填）；主力页精细与
失败处置是质量/处置偏好）。全部前置，参数赶不上执行的倒挂不允许
再发生（2026-09-30 实证：第三幕放在②后，导致子代理开跑了策略
还没收集）。

用户激活后可以离开——回来即见进展或成品。中途唯一例外打断：
②gap 报告中不可自裁的矛盾（约定的人工 gate）。此外零打断。

|---|---|

## 铁律

1. **逐页反 one-shot**：禁止"把剩下的页面都建了"——一页一个独立任务，
   每页完成即回填 `pipeline/PLAN.md` 状态。
2. **交互职责分界**：**页内交互（选择/开关/tabs/弹窗开闭/页内状态）
   由页面制作站本地实现完毕**（本地 state+onClick）——data-intent 是
   语义标注，不能代替功能实现；**⑨只接跨页导航与跨页数据**
   （读代码设计交互，比读图便宜且精确）。select:/tab: 类标记须验证
   页面有本地处理器，有则⑨跳过、无则回写码站补实现。
3. **用户"停" = 冻结**：用户表示停下/接受现状 → 立即冻结修复，
   按现状交付，未决问题如实进交付报告。禁止继续修复、禁止用
   AskUser 续期。
4. **输入路径只能来自用户**：图包/文档/工程路径一律由用户指定，
   禁止自行扫描、搜索、猜测任何目录来"找输入"（扫描会把测试
   残留/无关文件误当输入——2026-09-30 实证）。没给路径就问，
   不动手找。
5. **图标零打扰**：图标库比对后由模型自动定稿落 manifest（带证据
   note）；低置信静默降级。禁止就图标引用打断用户。
6. **工具缺陷可就地修（1010-02，主会话级）**：执行会话发现本技能验收
   工具结构性缺陷可直修无需请示——限本技能自有脚本；单页技能只读；
   语义分歧仍走 UDP；回报单列「工具修订」四件套。（本条纪律主体=执行
   会话本体而非派发子代理，故豁免"纪律改动只改任务书"原则；子代理版
   条文见三份任务书同名节）
6. **布局文档是唯一视觉源**：页面写码阶段禁止看原图——布局文档
   （inventory/）+ PRD + tokens + 组件库是全部输入。
7. **中间产物存废标准**：一个中间产物只有两种存在理由——被后续
   生成直接消费，或承载必须的人工决策记录。两者都不占 = 砍。
8. **职责边界**：本技能管多页编排，不碰单页内部细节；精绘页
   按 `flow-front-ui-line-cy-img-to-code` 第 2-5 步完整状态机执行，禁止拆其
   脚本零散使用。
9. **修复轮根因门**：用户报 bug 第一动作=复现+定位根因
   （截图对比/像素采样/最小复现），报告根因后才动手；每轮修复
   必须能回答"为什么上一轮没修好"；禁止"改一版试试看"。基准选错
   类修复必须对照正确源图逐区块核对。**冻结终审**（1008-11）：管线
   内部修复轮额度用尽后逐项终审——定点小修（~30 分钟级，判断参考
   非硬门槛）→ 修完再交付；仍冻结须给"留档代价>修复代价"理由进
   交付报告。终审服从铁律 3：**用户明确叫停即冻结交付，终审不得
   覆盖用户停止指令**。

## 关键机制

- **dpr 归一**：入口检测源图密度并归一逻辑 px（详见单页技能）——
  坐标全栈 1:1 消费；非 2x 图不归一 = 全局缩放错误；
- **素材按需 + hash 共享**：素材由 精绘页的技能流程按需抠取，
  内容 hash 缓存跨页去重——不存在独立的全量素材抽取站；
- **mock 双层**：`src/mocks/entities/`（共享实体库，先于页面 mock
  生成）+ `src/mocks/pages/`（页面组装，禁止内联实体字面量）——
  跨页一致；
- **status**：PLAN.md 每页 `pending / in_progress / done / failed /
  降级后置`；failed 连续 2 轮 → 降级后置（不卡流水线）。
