## 使用方法

1. **改版前**：逐层过检（新设计在哪层落点？破坏哪层？）——记录进工卡；
2. **新问题归类**：翻车后按七层定位缺陷所属层，卡标注归属（1009-13）；
3. **收口检查**：一批卡完工后，问"这些卡该收进哪层/是否需要新层"——
   防散卡（2026-10-09 大改造即此方法产出 22-24）。
