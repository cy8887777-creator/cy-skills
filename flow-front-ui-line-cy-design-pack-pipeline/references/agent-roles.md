# 子代理角色与协作契约（agent-roles）

三个核心角色，每个 = 角色提示词 + 产出契约 + 停止条件。
角色提示词全文放 `templates/`（任务书），本文件定义契约要点。

## 角色 1：页面分析师（②盘点）

- 输入：负责批次内的图（每批 8-10 张）+ 盘点任务书
  （templates/inventory-prompt.md）+ 布局文档规范
  （references/page-doc-spec.md）
- 产出：`inventory/<页id>.md`（§0-§3）+ 每图一行回报
- 契约：单图视角纪律；四章节齐全；格式与同批一致；无跨页推断
- 停止：批次完成即回报；不做策略终审（终审在人工 gate）

## 角色 2：产品经理（③PRD）

- 输入：全量页文档 §0+§1 + manifest + （可选）功能清单/会议纪要
- 产出：站点地图 + 功能逻辑（含 states 枚举）+ 每页行为清单
- 契约：页面 id 全覆盖对账；行为必须溯源（页面可见元素或全局推断
  说明）；纯交互行为不设计（后置⑨）；目标页不存在的行为 → 进 gap
  流程不凭空接线
- 停止：三层产出齐 + 自查对账通过

## 角色 3：前端工程师（⑥典型页转换 / ⑦主力页 / ⑧铺量）

（⑤典型页的技能状态机阶段不经本角色——单页技能自足执行，输入
仅源图；本角色从⑥转换开始介入。）

- 输入：该页布局文档（§0-§3，精绘 另有完整标注）+ PRD 该页节
  （结构规则/states）+ tokens.ts + 组件库 + mock 约定
- 产出：`src/pages/<页id>.tsx` + `src/mocks/pages/<页id>.ts`
- 契约（DoD）：build 零错 + 布局文档全覆盖（区块/文案/尺寸）+
  mock 已接（引用 entities 禁内联字面量）+ data-intent 占位齐
  + 页面根节点挂 `data-route="<路由path>"`（⑩运行时路由探针锚点）
  + 与源图/布局文档对照通过
- 停止：DoD 达成或连续 2 轮失败 → 标降级后置（不卡流水线）

## 角色 4：结对裁判（⑧铺量流水常驻）

- 输入：单页"源图 vs 成品截图"并排 + build/对照结果一行（任务书
  templates/judge-prompt.md；严重度体系与单页技能 judge-guide
  一致）
- 产出：行式 verdict + findings（每条带 页id/区块/类型/严重度/证据）
- 契约：只判不修（禁写码/禁建议改法）；每条带证据，禁模糊结论；
  1-2 个常驻滞后跟进写手流，与写手数解耦
- 停止：逐页结论即回报；同页 2 轮 blocker/major → 标降级后置

## 协作纪律（所有角色）

| 纪律 | 内容 |
|---|---|
| 分片 | 按页面子集领任务；禁止跨片写文件；路由表/组件库/manifest 由主会话独占维护（⑥设计系统阶段除外） |
| 命名 | 页面 `src/pages/<页id>.tsx`；mock `src/mocks/pages/<页id>.ts`（实体 `src/mocks/entities/`）；组件 PascalCase；页 id 用①盘点清单 id 禁止自造 |
| 编辑 | 定点替换禁整文件重写；共享文件只读；完成后自验才回报 |
| 回报 | 固定格式一行（页id/状态/偏差）；失败必须带错误尾部；禁贴大段代码 |
| 停止 | 用户"停"= 立即冻结按现状交付；连续 2 轮失败 = 降级后置标记 |
| 素材 | 精绘页素材由技能流程按需抠取 + 内容 hash 共享库去重；**直写页不走抠图链**——共享 hash 库已有的位图素材（照片/头图）直接引用，需新抠 → 页面升级精绘或记偏差；纯装饰图标用 iconify |

## 主会话（编排者）职责

- 轻状态：只持 manifest / PLAN / gaps / 各角色回报行——不持页面
  全文与图片内容
- 分派与验收：按 PLAN 分派 → 收回报 → 更新状态 → 下一批
- 脚本执行：intake / route-audit / plan-io（确定性工具）
- git 操作：每批完成统一 commit（子代理不碰 git，避免 index 锁）
- 例外裁决：gap 人工 gate / 难页降级决策 / 用户"停"的执行
