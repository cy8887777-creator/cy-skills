# gap 审计与质量防线（gaps-and-quality）

## gap 审计（②站 2b，三方对照）

真实现场：图包从来不会完整且正确。审计 = 功能清单（需求侧真值，
若有）× 图包（设计侧事实）× 盘点解读，产出三类 gap：

| 类型 | 定义 | 处置 |
|---|---|---|
| 缺失 | 功能清单有、图包没有的页面/状态/字段 | **有功能依据的 simple 页 → 直写补页**，执行点：②gap gate 裁决后 manifest 加条目标 `synthesized` → **②裁决后主会话立即按功能清单生成推导布局文档草稿**（§0+§1，标 `derived-from-prd`）→ ③PRD 以此为输入完善 → **④冻结路由清单时一并纳入** → PLAN/PRD 行为表同步；⑧按推导文档+组件库直写。关键视觉页或无依据 → 人工 gate，未补的目标页在⑨悬空占位 + 已知问题清单。**判例（2026-10-07 用户拍板）**：悬空分诊按**错误代价**不按依据来源——PRD 是证据不是门槛（PRD 本身继承图包缺陷，写没写都不豁免）；低代价直接补、中代价补+标"常识推导"交付确认、高代价（交易/权限/外部依赖）集中问用户，**拿不准归问用户档宁问勿造** |
| **命名不一致** | 文件名/编号与实际页面内容不符（首轮实跑 9 处：p006 授权实为主页等） | **按实际内容重命名**——页 id/名称/清单跟随实际内容；文件名降为线索（不可信） |
| 矛盾 | 图与功能清单冲突 | 以功能清单/PRD 为准（意图层 > 视觉层，视觉可能是旧版）+ 偏差清单 |
| 存疑 | 模糊/截断/多版本难定终版 | 人工 gate 一次性裁决；不可用部分按 PRD 推导 + 标记 |

**无功能清单时**：gap 靠领域常识推断——**精度降级，如实声明**，
人工 gate 权重加大（博物馆项目即此场景）。

处置原则：不阻塞主流程（问题页跳过，其余推进）；集中一次性过
人工 gate（绝不逐个打断）；语义冲突以 PRD/功能清单为准。

## 质量防线汇总

| 防线 | 抓什么 |
|---|---|
| verdict 硬门禁（单页技能） | 坏掩码物理不落盘（引用即 404 强制降级） |
| 掩码审计（单页技能） | 贴框/切边/不对称/低保真 → 非硬禁即 REVIEW |
| RAW 相邻收缩（单页技能） | 带底贴片压字 |
| base_box 断言（单页技能 verify） | 误扩框 garbage-in |
| 墨迹宽 gate / raw_occlusion / icon_contract（单页技能 verify） | 文字入侵/贴片遮字/未确认图标 |
| **style-lint（⑧铺量伴随，scripts/style-lint.py 已实现）** | tokens 外样式发明（跨页漂移） |
| **结对裁判（⑧铺量流水常驻）** | 铺量页视觉偏差——写手自评漏检；错误第 1 页拦截防复制整批 |
| **导航一致性走查（本技能⑩）** | 多页结构/导航不一致（模型最弱项） |
| **像素基线（本技能⑩产出后）** | 任何后续修改的回归对比——基线=⑩ route-audit 逐路由截图（route_<id>.png，复制为 preview_desktop.png 后用单页技能 `selftest pixel-regression --a --b` 对比，其 `--file` 参数可直接指定文件名） |
| 已知偏差清单制度 | AI 交互模拟/拍照模拟/支付流程模拟/字体兜底——如实呈现不静默 |

## 已知偏差清单制度

⑩验收时必须产出 `docs/known-deviations.md`：
- 模拟能力边界（AI 对话为模拟/拍照为假结果/支付为流程）
- 字体兜底（无匹配字体时的系统栈）
- L1 模式的素材底色差
- gap 报告中未处置项
每条：现象 / 原因 / 影响 / 建议。**交付报告必须链接本清单**。
