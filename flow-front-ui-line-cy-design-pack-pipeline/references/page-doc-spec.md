# 布局文档格式规范（page-doc-spec）

每页一份 `inventory/<页id>.md`，是全管线该页的**单一事实源**：
②盘点产出 §0-§3；§4 交互标注由⑨接线后回填；§5 实现记录由
写码站（⑤⑦⑧）补。页面写码阶段**禁止看原图**——
本文件 + PRD 该页节 + tokens + 组件库是全部输入。

## 视角纪律（硬规则）

盘点子代理是**单图视角**——只描述本页可见事实。**禁止**：
- 跨页推断（"是 XX 页的上游""入口来自菜单"——你没见过别的页面，
  猜的关系会污染 PRD 的交互设计）；
- 凭空补全（图上看不清的功能按常识脑补）。
主题判断可以写，但**必须附判断依据**（"标题与图片内容显示为…"）。

## 章节规范

```markdown
# <页id> <页面名>

## §0 页面叙述
100-200 字：本页是什么、展示/操作什么、服务于什么使用场景。
附主题判断依据。禁止跨页关系与入口来源。
**文件名仅作参考线索——命名与实际内容不符时，以实际内容为准**
（首轮实跑 9 处命名不符实证）。

## §1 布局结构
区块清单（从上到下），每区块一行：
- 类型（导航/横幅/列表/卡片/表单/浮层/底栏…）| 位置 | 内容概要

## §2 素材清单
表格：序号 | 类型(位图/图标/文字) | 描述 | 位置
- 位图素材数是策略判据之一（≥3 → 倾向 精绘）

## §3 复杂度画像与策略建议
- 素材数 N；浮层数 N；不规则元素 有/无
- 策略建议：直写 | 精绘（判据**唯一权威**见 strategy-rules.md——
  本文件不复述，防口径漂移）
- 质量标记：清晰 | 模糊 | 截断
- 长图标记：h/w > 2.2 时标注

## §4 交互标注（⑨交互接线后补）
表格：交互元素 | 触发 | 行为（跳转目标/弹窗/状态变化，引用 PRD 条目）

## §5 实现记录（⑤⑦⑧写码站产出）
策略实际执行 / 耗时 / 偏差 / 已知问题
```

## 质量自查（盘点子代理回报前）

- 四章节齐全、§0 有判断依据、§2 含计数；
- 无跨页推断、无脑补功能；
- 与同批其他页格式一致（模板即法律）。

**豁免：synthesized 补页**（gap 规则产出的无图页）不产盘点文档，
其"布局文档"由③PRD 推导生成——仅 §0 叙述 + §1 功能结构，来源标
`derived-from-prd`，无视觉细节（§2/§3 留空）。质量自查对 §2/§3
不适用（见 gaps-and-quality.md 缺失行）。
