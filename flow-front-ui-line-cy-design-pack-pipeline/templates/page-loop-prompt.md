# 精绘页转换任务书（page-loop-prompt）——技能产物 → 工程 TSX

> 适用：⑥设计系统阶段（⑤典型页 HTML 成品转换进工程）与
> ⑦主力页（技能状态机产物转换）。单页技能完整状态机已产出
> verify PASS + 独立裁判 PASS 的 index.html，按本任务书五步转换。
> 禁止跳步、禁止并行合并步骤。

## 输入

- 技能产物：`<页id>/index.html`（结构已断言）+ `styles.json`
  （字体合同）+ `assets/`（素材）
- 工程：tokens.ts + 组件库 + mock 约定（`src/mocks/`）
- PRD 该页节（结构规则/states，③已冻结）+ ④归并结果（同编号组页
  的状态清单）——⑥转换排在④之后，两者必已齐备；发现缺失即停下
  报告，禁止 `TODO(state)` 占位抢跑

## 五步（依次）

0. **状态核对**（第一步，硬门）：对照 status_map 确认本平铺稿 =
   该页**默认态**——不是默认态 → 停下报主会话（先还原默认态或明确
   条件渲染方案），禁止把交互态直接转成默认渲染。
1. **去壳**：剥掉技能产物 body=画布的外壳包装，保留画布内 DOM；
   画布容器改为组件挂载点（逻辑宽按 PLAN device_profile 视口档——
   默认 375，禁止引入响应式断点；非手机档按 §6 宽屏兜底壳，1010-04）。
2. **JSX 提取**：HTML → JSX（class→className、style 字符串→对象、
   自闭合补全、实体解码）。**内联样式保留**——此时不做样式重构，
   等价优先，重构留给后续迭代。
3. **mock 外置**：页面展示数据抽出为 `src/mocks/pages/<页id>.ts`
   类型化导出；跨页实体（用户/场馆/订单等）引用
   `src/mocks/entities/`，**禁止内联实体字面量**。
4. **data-intent 注入**：可交互元素（按钮/链接/输入/卡片行）打
   `data-intent="<语义动作>"` 占位——**不接线**（⑨统一接线）。
   语义动作从 PRD 行为清单取词；无 PRD 按元素语义命名。
   **页面根节点挂 `data-route="<路由path>"`**（route-audit 运行时
   路由真值探针的锚点——SPA fallback 下"URL 200"不等于"目标组件
   渲染"，⑩验收靠它裁决）。
5. **等价验证**：转换前后同视口各截一张并排对比（结构一致）；
   `npm run build` 零错；`plan-io.py set <页id> done` 回填 PLAN。

## 纪律

- **等价优先**：转换不改视觉——任何"顺手优化"都是偏差源；
- 工程侧文件定点替换，禁整文件重写；
- 连续 2 轮失败 → 降级后置标记，不卡流水线。
