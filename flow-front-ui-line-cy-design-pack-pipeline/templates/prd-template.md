# PRD-Lite 模板（prd-template）

> PRD 子代理（产品经理角色）基于全量布局文档 §0+§1 的全局理解产出。
> 三层结构逐层可独立审核。规范见 `references/prd-spec.md`。

```markdown
# PRD — <项目名>

## 层 1：站点地图
（页面关系/信息架构：模块 → 页面 → 层级；入口关系。
从全量 §0 叙述推断——此层是跨页推断的合法位置。）

## 层 2：功能逻辑
### 业务规则
- 规则 N：…（状态机/权限/流程，含依据——页面可见元素或全局推断说明）
### 每页 states 枚举
| 页id | 状态（默认态必含；空/加载/错误按需）|
（未枚举 = 只做默认态，防状态爆炸）

## 层 3：每页行为清单
| 页id | 触发 | 行为（跳转目标/弹窗/状态变化）| 依据 |
（行为必须溯源；目标页必须存在于 manifest——不存在进 gap 流程。
 纯交互行为不在此设计——后置管线⑨交互接线。）
```
