# 设计和技能演化文档（新版）

安装 Python 的 `markdown` 包后，在本目录运行 `python build.py`，生成同目录的 `设计和技能演化文档-新版.html`。HTML 内嵌结构化会话，离线打开即可阅读。

数据来自本目录的原始 JSONL、上一级技能源码和 Git。阶段、注释和问答在 `build.py` 中编辑；展示与交互分别在 `template.html`、`theme.css` 和 `app.js` 中维护。注解必须唯一匹配一条用户原话，否则构建失败。

会话按原始行号排列。当前原始快照为 10,382 行，新增内容是在旧快照的 6,999 行后追加；下次更新前须再次核对旧文件是实时记录的完整前缀，避免重复。AI 同一轮的文字合为一个响应，思考、工具和队列事件默认收起；队列记录不被解释为用户中断。编辑器自动事件归入执行记录，转引的评审材料单独标识。页面分别显示会话截止时间、构建时间和技能 Git 版本。分享前应检查原始 JSONL 和内嵌会话是否含有不适合公开的项目路径或内容。
