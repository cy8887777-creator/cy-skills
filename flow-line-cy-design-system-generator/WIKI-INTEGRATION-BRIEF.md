| 5 | **指纹唯一合理位置 = 尾端可选**：九段走完、设计系统成稿后，实测成稿视觉值（色数/圆角/阴影/字体族）对照推荐卡的 fingerprint 照镜子，输出「贴合度自查」——可选动作，写进第九步收尾，不做硬性步骤 | 成稿才有可实测的视觉值 |
| 6 | **形态 = 探查式可选增强**：执行时探测本机是否存在 `design-style-wiki/atlas/INDEX.md`（由用户给路径或常见位置探测，不写死绝对路径）；存在 → 启用；不存在 → 现有路径照旧（uupm 检索 + AI 自拟），零报错 | 技能可移植；wiki 独立生长，不反向绑死 |
| 7 | **血统纪律**：凡引用卡的段落生成候选，候选卡/决策链必须标注卡 id 与所用段（如「底座：glassmorphism card §3」）——与 wiki 的血统纪律对齐 | 双方都要求"谁写都留出处" |

## 2 · 画像风格判断 · 检索协议（执行者操作卡）

1. 探测 wiki：用户给路径或常见位置（Desktop / 技能目录旁）发现 `atlas/INDEX.md` → 在位；找不到 → 跳过并标注
2. 读 INDEX ② 家族谱系表（建立家族意识，**不全库通读**）
3. 三键过滤出候选风格集（可 grep 各卡 front matter 的 best_for/avoid_for/mode/era）
4. 取 top-3，只读这 3 张卡的 §1 一句话 / §2 家族层 / §3 GUI 实现层
5. 输出推荐卡（弹窗）：每张 = 名称 + 家族 + 观感话术 + best_for 命中点 + avoid_for 风险提示
6. 用户确认/改选 → 写进画像（`推荐风格` 字段，含确认状态）→ 九段全程引用，**用卡必标卡 id**
