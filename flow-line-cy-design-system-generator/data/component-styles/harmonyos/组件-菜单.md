# HarmonyOS Design（华为官方设计规范） · 组件 · 菜单

> 来源：https://developer.huawei.com/consumer/cn/doc/design-guides/menu-0000001957001877（抓取日期 2026-10-22）

一种临时性弹出窗口，用于展示用户可执行的操作。开发相关描述请参考 Menu 文档。
### 如何使用
菜单项中不显示与当前内容无关的项。菜单顺序：最常用菜单项放在菜单顶部依次排列。菜单的通用基础构成元素通过 MenuItemOptions 进行配置，选中状态及选中图标可通过 Selected 进行配置。多级菜单的展开样式可通过 subMenuExpandingMode 进行配置。长按悬浮菜单通过 bindContextMenu 进行调用。

### 视觉规则
#### 沉浸光感
组件已提供沉浸光感样式，建议使用菜单组件时，采用沉浸光感样式为应用页面带来更丰富的空间感交互视觉体验。
### 响应式布局
手机
泛手机统一宽度为固定 224vp
电脑设备
电脑菜单宽度根据内容自适应，默认最小宽度 224vp，可配置菜单最小宽度，但不得低于 64vp
