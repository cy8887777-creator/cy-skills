# 产物章节模板（设计系统的章节结构 · 14 章 · 生成方式分类）

> **本表是章节结构的唯一权威**：工作台预览 Tab（`scripts/build-workbench.mjs` 的 CHAPTERS）与纯净版导出（`scripts/export-clean.mjs` 的 CHAPTERS）都按本表的章 id、顺序、章名执行——预览即最终交付物的实时形态，两者必须与本章表完全一致。**增删章节必须三处同步**（本表 + 两个脚本的 CHAPTERS 数组）。章节英文标签（DESIGN VALUES 等）以 export-clean.mjs 的 CHAPTERS 为准。
> 每章标注生成方式：【问】需要用户决策（可视化对比）/【推】前序决策自动派生（免决策推导（内嵌决策链与对应章节，不单独成面板））/【生成+审】AI 撰写用户过目 /【固定模板】整章收录不变。

| # | 章节 id | 章节名 | 生成方式 | 内容要求 | 上游依赖 |
|---|---|---|---|---|---|
| 01 | values | 设计价值观 | 【生成+审】 | 3~5 条产品原则（含第二步选定风格卡的完整风格描述与血统小节），每条一句诠释；后续章节可追溯到价值观 | 画像 + 第二步风格定义 |
| 02 | layout | 布局 | 【生成+审】 | 从原型**布局归类**生成：先归类布局样（聚合类/列表类/聚焦类/表单类/设置类/结果反馈类/消息类/身份创作类，每类带页数+代表页），再逐类定义骨架（导航/底栏/卡片/弹窗形态）——以原型结构为事实 | 原型 + 画像 |
| 03 | density | 密度与多端 | 【推】 | 密度倾向 + 画布宽/断点 + 多端差异说明 | 原型 + 画像 |
| 04 | rules | 设计要求 | 【固定模板】 | refactoring-ui 通用规则（data/refactoring-ui 快照，跨场景组装规则） | — |
| 05 | color | 颜色 | 【问】主色系 →【推】语义六件套/状态色/深浅变体 | 语义色表（主/次/CTA/底/文字/边框）+ 状态色 + 禁用于说明 | 第三步令牌 |
| 06 | type | 字体 | 【问】配对 →【推】字阶/行高/字重规则 | 家族配对 + 字阶档（最小/正文/标题/大标题）+ 使用映射 | 第三步令牌 |
| 07 | spacing | 间距 | 【推】4pt 网格惯例档 | 间距档位（4~64）+ 使用场景映射 | 惯例（密度倾向从原型读） |
| 08 | radius | 圆角 | 【推】第四步按组件库基调派生档 | 圆角档位 + 载体列举 | 第四步组件基调 |
| 09 | shadow | 阴影 | 【推】第四步按组件库基调派生（含色相策略） | 阴影档位 + 色相说明 | 第四步组件基调 + 第三步主色 |
| 10 | motion | 动效 | 【生成+审】 | 动效原则与占位（过渡时长/缓动/微交互/页面切换）；**「默认不做动效」的明确声明也是合格结论**——但不允许留空 | 画像 + 组件基调 + 样品页回流 |
| 11 | component | 组件 | 【生成+审】分组过目 | **组件大卡规格书**（实战标准）：**覆盖 = 原型实际组件清单 ∪ 常用标准件 ≥ 20 组**；每组一张大卡：头栏（N.名称 + 英文 + **来源徽章**「已提取 N 处 · X 态为 AI 补全」）+ 变体行 + **状态穷举**（交互组件 default/pressed/disabled ≥三态，展示型 default）+ 实物用**真 HTML 控件**（button/input，禁装饰 span）。三原则：**实物即规格**（尺寸/圆角/投影直接来自 token，找不到实物的组件=规范缺口）· **状态穷举** · **来源分层**（蓝标=实测提取/橙标=token 推断待回填）。只写三五族或装饰 span 演示 = 不合格 | 章 05~13 全部 |
| 12 | icon | 图标 | 【问】风格+来源 →【推】应用规则 | 风格（线性/填充/双色/3D）+ 来源库 + 尺寸/圆底规则 | 第六步 |
| 13 | imagery | 图像与插画 | 【问】策略 →【推】空态/加载态应用 | 图片策略 + 空态/加载态样式 | 第五步 |
| 14 | bans | 设计禁令 | 【固定模板】+【生成+审】 | 通用禁令（refactoring-ui 反模式）+ 业务禁令（画像/价值观推导）+ A11Y 红线 | 画像 + 价值观 |

## 纯净版规则
导出的 system-rules.md / spec HTML：**按本表章节顺序（01~14）成文；零决策痕迹（不写谁何时选了什么）、零来源标注（不写值从哪来）**；章 04、14 为固定模板整章收录。

## 来源追溯（仅工作台内）
工作台的看板与决策链保留全量来源信息；纯净版一律剥离。
