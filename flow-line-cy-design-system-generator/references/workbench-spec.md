# 工作台规格（workbench.html 细则）

> 铁律层（开链 / 落锤写链 / 预览章可视化）在 SKILL.md；本文件是工作台的展示层规格。

## 形态

`workbench.html`——单文件自包含（决策链 JSON 内嵌），file:// 直开，发给谁都能开。窄屏（≤960px）自动折叠为单列。

| Tab | 内容 | 性质 |
|---|---|---|
| ① 工作台（首屏，左右布局） | 左 = 共创流程步骤列（✓/●/○ 状态，已完成步骤展开可见当时选项与选择——过程留痕长在这里，可回改；曾回改的步骤显示「⚠ 此步曾回改，下游建议重看」）；右 = 当前决策处理（候选卡渲染 + 参数控件试调 + 推荐标记） | 动态，干活的屏 |
| ② 预览 | 左 = 章节目录（01~14，状态点）；右 = 对应章节正文（已定=正式渲染，未定=待定灰字） | 动态，**最终交付物的实时形态** |

## 顶栏右侧四个原始素材入口

构建时自动生成（build-workbench 同步产出，与工作台同目录，新窗口打开），给用户随时回看原始素材，**不是决策屏**：

- 「原始组件库规范」= **23 个组件库的风格样张卡**（基础控件 + 各库代表组件的实际视觉形态，形态参数按各库官方规格；卡尾标本库快照数）
- 「原始参考令牌库」= data/uupm/zh 中文参考数据全可视化（色板 / 字体搭配含中文开源组与授权 / 风格基调 / 图表迷你图形 / 落地页版式缩略）
- 「品牌设计语言」= 58 个知名产品的 DESIGN.md（色板一瞥 + 品牌摘要 + 展开全文）
- 「原始图标库」= 10 个开源图标库的离线图标墙（真实 SVG 抽样渲染，内联前经 sanitizeSvg 消毒 + 按名实时过滤 + 全量打包数）

## 样例模式

`node scripts/build-workbench.mjs <样例链> <输出目录> --sample` —— 左栏全部步骤可点（预览案例用）；真实项目不带 --sample，未解锁步骤不可点防跳序。

## 信息披露原则

每个决策屏同步披露该决策的全部直接推导（同屏同确认）；未定的不披露；预览静默更新不占确认节奏。**渐变/海拔/字阶等术语不单独提问**——它们长在样张上，用户看得见。

## 技术约束

静态页 + 原生 JS + CSS 变量；**页面只有展示权**——试调不落状态，决策一律在会话流落锤，AI 每轮把决策链渲染成新一版页面。
