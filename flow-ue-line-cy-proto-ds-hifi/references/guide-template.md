# 生成规范模板（guide.md 的结构基准）

> 用法：阶段二（规范编译）把设计系统内容**逐条映射**进本模板（零丢弃机制见 §7），产出 guide.md 作为全部子代理的唯一执行依据。本模板的组件配方源自实战验收项目，照抄结构、替换 token 值。

## 0. 铁律（违反=返工）

1. 内容零编造：页面每段文字只能来自该页内容清单（dump）
2. `.stage` 画布容器：`<body>` 后第一个元素 `<div class="stage">`，宽度=本版本基准宽
3. 多倍数由 `scale.mjs` 派生，禁止手写非基准版本
4. 字体路径 = `'../'×页深 + 'fonts/'`
5. 素材全部本地引用（外链图生成期下载进产物 assets）
6. 声明优先：原型/设计系统自带声明零误差直接采信，推断只兜残差
7. 布局一律语义流式（flex/常规文档流），禁止绝对定位平铺（地图容器内部与弹窗遮罩除外）
8. dump 中负坐标/越界画板内容 = 相邻画板串入，剔除不入清单
9. 照片素材缺失的图片区：mist/中性底虚线占位框 + camera/image 图标，不编造内容
10. 主 CTA（品牌主色渐变胶囊）全页唯一；卡内次级动作用品牌色淡底胶囊
11. 组件规格没写的装饰（描边/阴影/渐变/底色）一律不加；确要加=先在 guide 立规格再上页面（禁止页面临场加戏）
12. 黄色/品牌主色只给主操作·选中·核心入口，一屏至多一处；与全局主入口（如底部导航中央件）同屏时页面内不再复现

## 1. 公共头部 CSS（每页必粘的 token 块骨架）

```css
@font-face{font-family:'<中文字体>';font-weight:400..700;src:url('<深度>fonts/<文件>.woff2') format('woff2');}
/* 数字字体 Inter/SF 同理 */
:root{
  --color-text-primary:#…; --color-text-secondary:#…; --color-text-brand:#…;
  --color-bg-page:#…; --color-bg-card:#…; --color-border:#…;
  --btn-primary:linear-gradient(…); --card-shadow:0px …px rgba(…);
  --card-radius:…px; --tag-bg-*:rgba(…,0.12); --tag-text-*:#…;
  --space-*:…px; --font-base:'…',sans-serif; --font-num:'…',sans-serif;
}
*{margin:0;padding:0;box-sizing:border-box;}
html,body{background:#E4E9EF;}           /* 画布外的中性底 */
body{min-height:100vh;font-family:var(--font-base);color:var(--color-text-primary);font-size:<正文>;line-height:1.45;}
.stage{width:<基准宽>px;margin:0 auto;background:var(--color-bg-page);min-height:100vh;box-shadow:0 0 32px rgba(31,37,43,.14);display:flex;flex-direction:column;}
main{flex:1;padding:0 var(--space-page) 20px;}
.sr-only{position:absolute;width:1px;height:1px;overflow:hidden;clip:rect(0 0 0 0);white-space:nowrap;}
```

> audit 断言要求：`.stage{…}` 块内必须含 `width:<基准宽>px`（属性顺序不限）；字体 url 前缀必须 = 页深 + `fonts/`；正文/占位文案写在文本节点或 value/placeholder 属性里皆可（溯源两种载体都认）；**属性值含空格的文案（手机号/「¥ 请输入…」类）两种载体都命中不了，须同步一条 `<span class="sr-only">原文</span>` 文本节点**（.sr-only 已在 §1 预置；禁用 &nbsp;——audit 按去空白比对，实体串会破坏命中）。
>
> 白底页（如「卡包页=白」）：`<div class="stage">` 标签**保持无属性**，直接把 §1 中 .stage 规则的 background 改 var(--white)——audit 断言匹配 `<body>` 后无属性的 stage 标签，内联样式会挂断言。

## 2. 页面骨架（五层）

状态栏(44) → 导航(44) → main 内容(左右边距=规范值) → 底栏(58+安全区19，仅主页签页) / 底部操作条(详情页，置于内容末尾不悬浮)。
**骨架数字为示例**（源自实战案例），以所用设计系统的实测声明为准。

## 3. 组件配方（HTML 片段级，样式内联或页内类）

> 本节示例仅授权结构与写法；样式值及描边/阴影规则一律以本项目设计系统契约为准；通用类名只许是契约的省略写法，冲突以契约为准。

| 组件 | 配方要点 |
|---|---|
| 状态标签 | tint 底（主色 12% 透明）+ 同色实色字，r6，字号最小档+500；成对出现 |
| 主按钮 | 品牌渐变胶囊 999、白字、字阶标题档+600、品牌投影；全页唯一 |
| 次按钮 | 白底胶囊、次级文字色、描边 line 色 |
| 卡片 | 白底 + 卡片圆角档 + 卡片阴影；内边距=规范值 |
| 菜单行 | 行高规范值；左图标底（正方形、中圆角、tint 底+品牌图标）+ 文字标题档/500 + 行尾 chevron-right（次级色） |
| 表单行 | label 正文档 左 + 值/占位 右对齐（占位=placeholder 色）；输入底=浅灰 token r8 |
| 列表页签 | 选中=品牌色 600 + 圆角短下划线；未选中=tertiary 400 |
| 地址双腿 | 圆形小徽标（起=ink/终=accent，白字）+ 地址 body-lg/500 + meta 小字（数字用数字字体） |
| 弹窗 | 遮罩 rgba(0,0,0,0.4) 盖满 stage（z 高于一切）+ 白窗 r16 宽约 300 居中：标题/正文/按钮排（取消=次、确定=主） |
| bottom-sheet | 遮罩 + 底部白板上圆角：标题行 + 选项行 + 确认 |
| 时间线 | 左圆点列（当前=品牌实心、完成=success、未到=line 色）+竖线；右标题+说明 |
| 结果状态页 | 居中 tint 圆底大图标 + 文案 + 全宽主 CTA |
| 空态 | 居中图标 48（语义近似的线性图标）+ 文案，不编造 |
| 资金数字 | 数字字体 + 强调色 700 |

> 弹层/弹窗页底：dump 含同页列表内容→渲染同构列表+遮罩；仅弹窗文字→纯遮罩不画底。

## 4. 模板分类（页面 → 配方组合）

| 模板 | 组合 |
|---|---|
| 列表页 | 页签/筛选 + 卡片×N + 底栏（tab 选中按页面语义） |
| 地图详情 | 地图区(相对容器+cover 图+浮层) + 信息卡组 + 底部操作条 |
| 表单页 | 表单行 + 输入底 + 上传占位 + 主 CTA + 协议勾选 |
| 弹窗页 | 遮罩 + 白窗（dump 无底层内容则不画底层，零编造） |
| 协议页 | 长文本（正文档/1.7 行高/段距一档），标题层级按原文符号 |
| 结果状态页 | 居中圆底图标 + 文案 + CTA |
| 主页签页 | 底栏 + 各面板（统计卡/菜单行/列表） |

## 4.5 区块→组件映射表（编译完成的前置条件）

> §3 配方回答「长什么样」，本表回答「哪个区块用哪个」。缺了它，子代理只能凭内容清单即兴组装（组装漂移）。**无本表 = guide 编译未完成，禁止派发。**

- **样板页**：逐区块列出：区块名 → 组件配方/类名 → 依据（设计系统组件名 / 原型结构注记）
- **全量页**：按模板类（§4）归并映射；模板类覆盖不到的区块随批次清单补充
- **批次清单 JSON 必须携带该页适用的映射条目**
- **映射缺口**：子代理回执 `blocked: 页+缺口`，不得即兴组装；主代理补映射（推导的逐条留痕 `<产物根>\.gen\decisions-log.json`：决策+原型结构证据+设计系统规格证据）后重派

## 4.6 派发简报（任务书）模板

> 主代理派每批时照此填一块、随批次文件下发给子代理；**五块缺一不得派发**。此简报即 worker 的全部开工依据——讲清楚在工作前，检查只做兜底。

```
【派发简报 · BXX】
① 规范指针：guide.md 全文遵守（先读后写）；图标库 icon-snippets.html
② 本批构成：N 页 / 模板类 X / 每页 dump 路径（已验证存在）/ 深度前缀='../'×层级
③ 本类配方与坑：§4.5 对应条目摘抄 + 本类已知坑 2-3 条（按类摘 pitfalls）
④ 通用红线速览：内容零编造｜<body> 后无属性 <div class="stage">｜白底页改 .stage 规则底色｜
   属性文案同步 .sr-only 文本节点｜禁 &nbsp;｜素材只引产物 assets｜dumps 目录只读｜
   跨批链接一律 void(0)（主代理统一接线）
⑤ 完成定义：每页写完自检（href 全部解析存在 / dump ≥6 字行全部命中 / .stage 首元素）
   → 自检通过才报 done；回执含 done 数=批内页数；失败/blocked 单列
```

## 5. 状态色彩语义（示例，按设计系统实际标注替换）

品牌=选中/可操作；橙=进行中/等待/强调；绿=已完成；红=删除/危险/失败。状态标签=tint 底+同色字成对。

## 6. 字体规则

- 中文=设计系统中文字体（无则 PingFang SC/Microsoft YaHei 栈）；数字/金额/时间/电话=数字字体
- 字号只用阶梯档（就近归档）；正文行高 1.45、小字 1.5
- 禁正文用 700 冒充标题；禁阶梯外字号

## 7. 零丢弃映射（设计系统 → 本指南）

> **条目化数据源优先级**：若设计系统带机读版（system-rules.json），条目化**优先用 json**（markdown 表格可能有派生粘连伪影，逐 token 提取有漏读风险）；无机读版才解析 md。

| 来源条目 | 落格 |
|---|---|
| 每个 token | §1 token 块 / §3 配方对应值 |
| 每组组件规格 | §3 对应配方；token/组件用途栏语义（页面级底色归属、XX 专用等）须随条目落格 |
| 每条禁令/红线 | §0 铁律 |
| 布局/多端/动效章节 | §2 骨架 / 生成时的口径决策 |
| 不适用条目 | 标注「不适用+理由」留档（静默丢弃=审计失败） |
| AI 补全条目 | 标「待确认」→ 样板验收门回填 |
| 图像/图形区块 | §4.5 映射表（纯图形区块凭内容清单图片段+原型节点登记） |
| 素材文件 | 以拷入产物 assets 后的清单为准（阶段一主代理整目录拷贝原型 `assets\`，worker 只引产物内素材） |

**审计断言**：guide 覆盖率 = 已映射/设计系统总条目，未映射=失败。
