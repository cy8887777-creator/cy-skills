# 画布宽度区间判定表（声明优先，区间归类，问询即确认）

## 原则
1. **声明优先**：先读原型自带声明（viewport meta / .stage 或 body 显式宽 / 设计系统口径标注）——声明是零误差事实来源，读到就直接用
2. **区间归类**：无显式声明时按宽度区间归类（设备尺寸是区间不是点）
3. **问询即确认**：判定连建议一起亮给用户，识别错了用户一句话修正——问答本身就是纠错机制，不做交界带硬判

## 宽度区间表

> **区间有意重叠**（交界带，如 750 手机@2x ≈ 768 平板；844 手机@2x ≈ 834 平板）：落在重叠处时判定写「介于 A 与 B 之间」+ 声明依据，由用户在倍数问答里直接确认——**不硬判唯一行**。

| 画布宽度 | 判定 | 倍数建议 |
|---|---|---|
| 300 ~ 520 | 手机 · 1x 逻辑宽（320/360/375/390/414/428） | 1x（H5/浏览器标准）；2x 可选（小程序/Figma 高清） |
| 520 ~ 700 | 大屏手机 / 折叠屏展开 / 小平板竖 | 1x |
| 640 ~ 920 | 手机 · @2x 画布（640/750/828/844/926） | 2x 基准（÷2=逻辑宽）为主；1x 可选 |
| 700 ~ 1100 | 平板（768/810/834/969/1024） | 1x 平板基准 |
| 1100 ~ 1400 | 平板横 / 小笔记本（1194/1280/1366） | 原生尺寸 |
| ≥ 1400 | PC 桌面（1440/1920） | 原生尺寸，无倍数概念 |

**交界带**（如 750 手机@2x ≈ 768 平板；834 平板 ≈ 844 手机@2x）：不硬判，判定输出写「介于 A 与 B 之间」+ 声明依据，由用户在倍数问答里直接确认。

## 判定输出格式（给用户看的样式）

> 已识别原型画布：**750px**（区间判定：手机 @2x，依据：viewport `width=750`）。
> 请选择输出倍数（可多选）：
> ☑ 2x / 750 基准（推荐——数值即 rpx）
> ☐ 1x / 375 基准
> ☐ 3x / 1125
> 识别不对？直接告诉我实际情况（如：这是平板/这是 PC）。

## 倍数语义（写进给用户的话）
- 倍数是**同一套页面的缩放口径**，不是不同页面：N 倍产物 = 全尺寸 ×N，内容与结构完全一致
- 1x = H5/浏览器 CSS 标准口径；2x = 微信小程序 rpx 一比一 / 高清走查
