# 编辑器产物整套换风格重建

输入两样：**产物文件夹**（`index.html` + `assets/` + `docs/` 供料文档）和一份**风格提示词**（设计风格 wiki 各卡自带）。四步走完，新风格**回装进原产物文件**：产物内右侧风格面板多一张新风格卡，点切时左侧页面树/项目内组件/中间内容整套换，原风格保留随时切回——**不产新文件**（交付形态定案 2026-11-23）。绘制阶段原产物只读，第 4 步回装前自动备份（`.bak-<时间戳>`），跑坏随时还原。

本技能自包含：样章规则、画师方法、旁批规则、转化脚本全在包内，不依赖任何外部技能。图标族内置 lucide（`assets/icons-json/lucide.json（Iconify 聚合件，icon 技能同源）`），构建用 `scripts/build.py`。

## 铁律（always-on）

1. **第一性材料**：开工先读产物 `docs/` 供料（用户输入文档【盘问裁决并入此件时以一件呈现】→开工文档 1.0→盘问文档→页面地图扩展，命名可能带风格线后缀；旧风格的设计资产规范不读——新风格自产）+ 风格提示词。风格提示词第一步落盘为 `rebuilt/intake/风格提示词.md` 冻结，禁转写禁派生。`docs/` 缺件时**停下上报用户**由上游补产——执行会话禁自己钻原产物 DOM 补料（零接触原则优先于流程连续性），交付说明声明缺件。
2. **风格提示词唯一视觉权威**，页面功能的合理性优先于风格——风格服务于功能，禁为风格效果牺牲可读与可用。
3. **执行会话全程零接触原产物**（只读 docs/ 供料四件，主管线现成产物，零新写）：①用户输入文档（含盘问裁决原文）②开工文档 1.0（项目定义/业务链路/功能刻度/动效档）③盘问文档 ④页面地图扩展（每页一句行为叙述）。旧风格的设计资产规范不进供料（新风格自产）。文案与演示数据：画师按开工文档 1.0+页面地图扩展**自编像真、页内自洽**（自查正本 style-selfcheck 文字层），禁读原产物 DOM 抄文案。新产物**页面数以页面地图扩展为底线守恒**——地图没写的空态/异常页允许画师补（执行会话禁看原产物页面清单，地图不全只能靠补），补页在交付说明列清单对账；**多风格回装场景：页数跨风格可不守恒**（每个风格按自己的布局语言组织页面，各风格各自对齐供料底线即可——v2 架构合法场景）。**布局禁参照原产物**：每页布局由「风格提示词 × 行为叙述」重新生长（不同风格=不同布局语言，换风格不是换皮）；原产物 index.html/DOM/截图/骨架/字体配色，执行会话一律禁读（jiancewuyou 三轮照抄事故同源纪律）。**禁读=禁布局参照与内容抄用**；两类读取除外：启动端型实测（读壳 device 档/契约块 device 字段）与第 4 步回装链（页面清单/撞车检查/注入目标）——只取结构与契约事实，禁看布局细节。
4. **全程禁读历史轮次痕迹**（任何阶段含开工盘问）：工作区里的 `pilot*-rebuilt/`、各 `report.md`、`ledger.md`、旧交付说明、其他产物线目录（非本次对象的一切文件）——**一律禁读**。产物对象不明（目录里多条产物线分不清）时**问用户**，靠翻旧材料判断=上下文污染（旧轮次的风格/裁剪/口径会锚定本轮执行）。开工只读两样：产物 `docs/` 供料+技能包文档（外加用户在对话里给的信息）。
5. **画布像真产品**：零"示例/未接入/示意"字样；界面文案三分类各自站得住（可行动的操作文案 / 像真实用户所填的动态内容 / 互洽的规范数据），页面每个字的读者都是终端用户。
6. **图标**：从 `assets/icons-json/lucide.json（Iconify 聚合件，icon 技能同源）` 取语义匹配的 SVG 内联，禁 emoji 当图标，一套一线宽；风格提示词要其他图标族时如实报告"本包内置仅 lucide"，征得用户同意后以 lucide 中语义最接近的图标替代实现。
7. **字体真装配**：按风格提示词把真 woff2 装进产物（@font-face 相对引用，禁系统栈回退、禁外链 CDN）；拿不到停下告知，禁静默回退。样章卡上的字体同样真渲染——**风格提示词的气质关键词（如"字要胖"）必须在样章字体阶梯上兑现，用户第一眼就能验**。
8. **先落盘**：每件产物（样章卡/页面/令牌）完成即写盘，防上下文耗尽零产出。
9. **原产物只读（第 4 步回装例外）+ 目录树一处定死**：第 1-3 步原产物一个字节不碰；第 4 步回装是**唯一**写原产物的动作（注入工具机械执行，先自动备份 `.bak-<时间戳>`，可还原），画师/AI 判断环节仍不接触原产物。一切新文件按此目录树落位（各文档只引用不复述）：

```
<产物根>/（用户给的 index.html 同级——一切锚定这个路径）
├── index.html        原产物（只读；回装目标）
├── docs/             供料四件（只读；语义匹配容错：实际文件名可能不带"文档"后缀/带风格线后缀，
│                     启动按 用户输入/开工/盘问/页面地图 四语义 glob，缺件停线上报）
├── AGENTS.md         产物自带——宿主会自动注入其内容：按零接触纪律对待（禁采信禁转写）
└── rebuilt/          本轮一切新文件（已存在=上轮残留：自动改名 rebuilt-prev-YYYYMMDD 留档，
                      死规则不问用户、命名禁带风格名）
    ├── intake/       风格提示词.md（冻结）/ palette.json / 风格封面-<族>.svg
    ├── preview/
    │   ├── specimen/ sample.html + 定调后 sample-ref.html
    │   ├── <风格id>/  静态稿全套（壳+页面+assets，相对引用离线可看，零网络请求）
    │   └── design/    设计资产与动效规范.md
    ├── build-work/    转化中间层（fragments/ accounts/ qa/ 开工说明）
    └── shots/         实看截图（按步骤分子目录）
```
10. **收口清账才交棒**：每步交付下游前清完本步欠账（自查/实看/对账），补完或经用户明示跳过并登记；静默跳段=违规。

## 启动流程（第 1 问产物路径 + 现场盘点 + 三问 + 锁定单；话术与分支见 references/onboarding.md）

开场先告知（换完效果=产物里多一张可切风格卡，原产物只读+回装前自动备份随时回退；能自己查的不问用户）：

- **第 1 问（核心问）：产物文件在哪**——用户给 index.html 路径或所在文件夹，**一切锚定这个路径**（供料 docs/ 在旁边找、rebuilt/ 建同级、回装回装这个文件）；目录内多候选 → 列出来点选（禁翻旧材料自行判断——铁律 4）；
- **现场盘点（拿到路径即做，不问用户，结果进锁定单）**：供料四件语义匹配实名（文件名可能不带"文档"后缀）/ 端型实测（铁律 3 除外条款）/ rebuilt 残留（存在即**自动改名 `rebuilt-prev-YYYYMMDD` 留档**——死规则：不问用户、不解释、命名禁带风格名）/ AGENTS.md 在否（宿主将自动注入其内容，按零接触纪律对待）；
- **三问（人话点选）**：①**风格哪来**——想好了给提示词/库卡（白话描述按 references/prompt-protocol.md 起草成前言+九段呈确认；点名库卡=九段**原文冻结**，呈报时问一句要不要适配起草版）/ 没想好进 **第 0 步 选型**（references/selection.md：约束表→wiki 检索出候选报告→**比稿池呈用户确认文字才算拍板**→比稿卡 2-3 张三选一→冻结）/ 自己逛库选中回走 ①；②**画多少**——全量（默认，页数=页面地图扩展逐页取）/ 裁剪试点（用户给页数授权，占位屏机检自动排除）；③**过程盯多紧**——标准（样张定调一次其余自动跑完）/ 盯紧（评审两道关也停下来呈报确认）。**配色禁问用户**——唯一出处=风格提示词色彩段（原产物品牌色禁读）；
- **锁定单**（问完输出，字段固定）：✅ 配置已锁定——产物文件路径（N 屏+端型实测）/ 供料四件实名 / 风格来源 / 范围 / 节奏（标准|盯紧）/ 现场盘点（残留留档名+AGENTS.md）/ 防锚定声明（零接触+任务书路径白名单）。锁定后进四步，中途变更走用户。

## 四步流程

### 第 1 步 风格样章（骨架图）——唯一的强制调子卡点
按 references/specimen-rules.md 产出**风格样章卡**（单卡 HTML，落 `rebuilt/preview/specimen/sample.html`）：卡头（风格名+气质句）+ **骨架图集**（从页面行为叙述挑 3-5 个代表页做纯情绪色块缩放并排，骨架区零文字）+ **载体样本条**（色板真值/字体阶梯真渲染/成文排版/组件形态/图标+图形母题与材质质感）。卡结构细则与生长公式见该文件。风格提示词的一切气质主张都要在卡上**真渲染兑现**，不许只写在规范文档里。完成后把样章卡路径给用户**定调**——这是全流程唯一的强制确认点；用户过调才进第 2 步。呈报定调时附**一行字体声明**：原产物已装字体 X（启动端型实测可读）/本风格按契约用 Y——要沿用原字体说一声（默认按契约；2026-11-24 uni-ui 字体预期差实测补的口径，是声明不是提问）。
**定调后立即产「精剪参照副本」**：复制样章卡为 `rebuilt/preview/specimen/sample-ref.html`，**删掉骨架图集段只留卡头+载体样本条五节**（骨架图集只给用户定调，绘制环节禁看——看了骨架=照抄骨架布局，jiancewuyou 事故同源）。绘制环节唯一允许的样章参照=这份精剪副本。

### 第 2 步 令牌与字体准备
样章定调后，从定稿样章提取令牌集（主色/底色/文字/表面/线色、圆角档、间距档、字重体系），落盘为 `rebuilt/intake/palette.json`（第 4 步 `editor_gen_tokens.py --palette` 的输入）→ 字体正式装配（铁律 7；样章试装的字体即定稿）→ **设计资产与动效规范成文**到 `rebuilt/preview/design/设计资产与动效规范.md`（可复用部件/模式/动效用法 + 性格词/世界/Signature——第 3 步批量绘制的风格锚）。这份规范是新风格自产的，禁止拿原产物的旧规范凑数。

### 第 3 步 全量绘制（默认不卡点）+ 走查优化闭环
**绘制输入 = 铁律 3 供料四件 + 风格提示词 + 精剪参照副本，禁多读**；端型约束两件按锁定单端型加读（draw-rules §端型约束），资产供给见 draw-rules §资产细则。文案与演示数据画师自编像真、页内自洽。布局由「风格 × 行为叙述」重新生长，信息架构恒定（工单列表还是工单列表），布局表达必须带新风格的组织语言。**禁为本步新写任何文档**——现成文档就是全部喂料。
页面清单从行为叙述逐页取。多页时**一个代理画全套**（同风格的设计判断必须连续，禁一页一个代理——派工纪律见 references/draw-rules.md）。样章已定调，本步**默认直接出全量静态**，不做主力页确认；用户明示想先看一两页时给 1-2 页再全量。同链路已画页互为底稿（学皮不抄骨，draw-rules），复用第 2 步冻结的资产规范；每页循环：写码→落盘→DOM 自查（溢出/断链）→渲染实看（每页 ≤3 次）→修，每页交稿附一句"画了什么"设计要点（第 4 步旁批的喂料）。**断点续跑**：上下文断了重跑时，先盘点 `rebuilt/preview/` 现状只补缺页（铁律 8 落盘是续跑的本钱）。**静态稿全部页装进预览壳** `assets/preview-shell.html`（左列表+手机框画布+旁批面板+画布档位条 375/390/430 切换+恢复；交互标注语法见 draw-rules §交互结构标注——标注缺失=转化后交互全灭）。全量完成后做减法自查（draw-rules §减法纪律）与**页面数对账**（铁律 3 底线+补页清单）。

**绘制完成后必须走「走查+优化闭环」，清零才准进第 4 步转化**（画完就交=违规）：
1. **机检**：`node <SKILL>/scripts/ui_audit.mjs <产物index.html> --out <findings.json>`——对比度（WCAG 实测，阈值 4.5:1，大字 3:1）/字号下限/横向溢出/交互遮挡/断图五探针，产 findings 台账；占位屏自动排除；
2. **功能覆盖对账**：按 references/audit-rules.md §8 双向矩阵——供料功能逐条到产物找承载（文档有→稿无=缺功能必修），每个用户操作过操作真实性三问（对照端型约束）；
3. **七轴规则审**：按 references/audit-rules.md 逐轴审（无障碍/布局/文案/排印/色彩/打磨/动效），只报证据确凿硬伤，品味分歧不算 finding；
4. **审美评审+三方盲测**（两道独立的关，评审者禁是画师本人）：协议见 references/style-selfcheck.md 二、三节——独立评审无壳截图挑观感差距（只诊断不修法），盲测混图裁风格归属；抽 2-3 页（代表页必含）不全铺。锁定单节奏=盯紧则两道关结果呈用户确认后再修复（标准=自动进修复，结果写进交付说明）；
5. **修复**：全部 P1+硬伤**按根因聚类修**（共享层→模板级→单页，禁逐条乱序）→ **复跑机检清零** → 进第 4 步。无 playwright 时机检不可用，降级为七轴规则审全开+渲染实看逐屏过+交付说明声明。

### 第 4 步 回装原产物（同文件多风格卡）
新风格页面**回装进原产物文件**（不产新文件）：拆屏转化（CSS 挂域）→令牌骨架→撞车检查→lint 清零→claims 生成→开工说明组装→契约校验→U2 终检→**注入回装**（自动备份→屏集合组注入（data-style-id）→受控块合并→面板新卡）→真点验证→截图对账→**渲染对账门**（acc_render_diff.mjs 静态稿↔产物逐屏计算样式差分——机制回执拦不住渲染退化，差异清单即工单）→交付。操作手册、命令序列、坑表、例外机制全在 **references/conversion.md**，回装前通读。旁批行文规则见 references/annotation-rules.md。交付=回装后的原产物文件+交付说明（页面数对账/补页清单/跳过了什么/未验证项/**回退指引**：同目录 `.bak-<时间戳>` 还原即回单风格原状）；**交付=回执链三件齐**（渲染对账门 0 差异+回归全绿+交付说明五项，缺一不算交付——旧版运行时产物走 conversion.md §旧版运行时产物，注入器门口即拦）。
