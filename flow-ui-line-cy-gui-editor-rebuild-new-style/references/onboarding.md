# 启动引导（onboarding）

触发本技能后的开场与问询。原则：**告知在先、能自己查的不问用户、问就问人话点选项**。

## 开场（触发后第一句：先说效果，再要路径）

> 换风格，可以。先告诉我：**要转化的产物文件在哪个路径？**（指到 index.html 或它所在的文件夹都行）
>
> 后面就三个小事要你定：风格哪来、画多少、过程盯多紧。你的原产物全程只读，回装前自动备份随时可回退；旧风格不会丢——换完产物里是多一套可切换的风格卡。

**第 1 问 = 产物文件路径**（核心问，必问）：供料文档在它旁边找、重画工作目录建在它同级（rebuilt/）、回装也回装这个文件——一切锚定这个路径。用户给了目录就找里面的 index.html；目录里有多个候选产物 → 列出来点选（每条一行：路径+屏数，禁翻旧报告自行判断——铁律 4）；找不到 index.html 才追问。

## 现场盘点（拿到路径后技能自查，不问用户，结果全写进锁定单）

| 盘什么 | 怎么盘 | 缺/异常处置 |
|---|---|---|
| 供料四件 | docs/ 下按四语义 glob 匹配（用户输入/开工/盘问/页面地图；实际文件名可能不带"文档"后缀、可能带风格线后缀） | 缺件→停线上报，禁钻原产物补料 |
| 端型 | 壳 device 档 / 契约块 device 字段实测 | 读不出或一产物混多端→才问用户 |
| rebuilt/ 残留 | 产物根下是否存在 | 存在→**自动改名 `rebuilt-prev-YYYYMMDD` 留档**（死规则：不问用户、不解释、命名禁带风格名），锁定单记一行 |
| AGENTS.md | 产物根下是否存在 | 存在→锁定单记"宿主会自动注入其内容，按零接触纪律对待（禁采信禁转写进任务书与对用户消息）" |

## 三问（人话点选，就这三个）

**风格来源必须显式点名（2026-11-24 VI 图抢跑实测补）**：用户发来的附件/补充材料（VI 图/logo/参考截图）禁默认当风格来源——材料与供料混发时先一句确认「X 是风格来源还是背景材料」再动笔，禁自主起草提示词。

| # | 问什么 | 选项与走向 |
|---|---|---|
| 1 | **风格哪来** | ①想好了，给我名字或提示词 → 冻结直达第 1 步；给白话描述 → 按 prompt-protocol.md 起草成前言+九段，呈确认后冻结；点名库卡 → 九段原文冻结（呈报时问一句要不要适配起草版）②没想好，按产品情况挑几套看图选 → 第 0 步选型（selection.md）③自己逛风格库 → 给 wiki 地址，选中回走 ① |
| 2 | **画多少** | 全量直接画完（推荐，页数=页面地图扩展逐页取）/ 先画几页看效果满意再铺开（你给页数授权）。裁剪场景占位屏由机检自动排除 |
| 3 | **过程盯多紧** | 标准：风格样张给你过一次目（强制），其余自动跑完看结果 / 盯紧：评审两道关结果也停下来呈报确认。答案锁进锁定单，流程不写死卡点 |

**配色不问用户**：唯一出处=风格提示词色彩段（写实值），原产物品牌色禁读。

## 锁定单（问完输出，字段固定）

```
✅ 配置已锁定
· 产物文件：<index.html 路径>（N 屏实测，端型 <mobile|tablet|desktop>）
· 供料四件实名：<逐件列出 docs/ 实际文件名>
· 风格来源：<wiki 卡 id | 用户提示词 | 选型选定 | 起草确认>
· 范围：全量 | 裁剪 N 页（授权原话）
· 节奏：标准 | 盯紧（评审两道关呈报与否）
· 现场盘点：rebuilt 残留=<无 | 已留档 rebuilt-prev-YYYYMMDD>；AGENTS.md=<无 | 在（注入内容按零接触对待）>
· 防锚定：执行会话零接触原产物——只读 docs/ 供料+风格提示词+精剪副本 sample-ref.html；创作链任务书按路径白名单（draw-rules 派工段）
```

锁定后进第 1 步。供料缺件先停（上报由上游补产，精剪副本缺失=上游准备动作）。中途变更（换对象/换风格/改范围）→ 重新出锁定单。
