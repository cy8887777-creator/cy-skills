# 比稿卡规格（specimen-card-spec）

> **【本包适配注记】** 本文自源选型技能全文复制，正文一字未改。**与 specimen-rules.md 的分工：本件=比稿卡**（第 0 步选型的多候选并排卡，selection.md ④ 触发）；specimen-rules.md=**定调样章卡**（第 1 步选中风格的单卡精修）——两种卡两种规格，按环节读对应件，不互替代。本包对应关系：①V0.1/开工文档 0.1=docs 供料（开工文档 1.0+页面地图扩展）；②`intake/用户输入.md`=供料用户输入文档；③"调 solo-img-line-cy-icon-provisioner"=本包 lucide 内置（铁律 6）；④"登记 1.0 §6 风格记录"环节本包无（换风无主技能装入），载体条标注仍齐全——palette.json（第 2 步）吃它；⑤"正式出图禁灰块"=本包第 3 步同口径；⑥本文落盘路径 `intake/specimens/<卡id>/`=本包 `rebuilt/preview/specimens/<卡id>/`（流程口径见 selection.md ④，以本包路径为准）。

比稿卡=带颜色带情绪的骨架图集，是用户三选一（或多选）的实物。**批评面来自内容仿真，情绪传达来自风格载体——两者必须分离**。

## 风格命名与呈现（去颜色化 + 来源显著）

- **风格以形态语言定义和命名**（组件形态/圆角/阴影/密度/层次/排版气质——如"活力形态/沉稳形态/工程终端形态"），**颜色不参与风格区分**：GUI 风格不绑色板，同形态配任何色板都成立。禁止用颜色命名候选（"暖阳黄/企业蓝/深青系"）；色盘是全部候选共用的约束，与风格定义正交；
- **自创卡必须显著标记**（origin=ai-generated）：候选呈报时与库卡分组/分段或带「AI 新创」角标——用户需要知道哪些是库里的现成资产（挑即可）、哪些是 AI 新造的（要多看一眼气质是否成立），禁止混排让来源不可见。

## 呈现品质（选型物料是给人读的）

卡头气质句、适配报告、档位呈现全部面向需求方：**描述用人话**（"像微信的克制感，但更暖"），编号档位（A/B/C、①②③）只做回复键——正文第一次出现就说人话，禁止让用户回看定义才懂。表格式批量呈报在纯文本宿主是合理形态；宿主支持交互组件时 ≤4 题优先弹点选卡。

## 卡结构（单卡，自上而下）

1. **卡头**：风格名 + 一句话气质 + 角标 `方案示意 · N/总数`（方案卡的脸，不是效果图的脸——预期标定靠它）；
2. **骨架图集主体（纯情绪色块）**：3-5 个代表页（AI 从 V0.1 挑最能拉开风格差异的页），按比例缩放并排。**手机框尺寸统一基准：252px 宽级别，4 张一排放得下不换行**（合集壳容器按四连排计——自设超宽尺寸实证过换行事故：286px 宽四张必溢出）；不同项目、不同代理的产出必须同基准，放一起才能比。**骨架区内零文字**——标题/正文/标签/按钮文案一律色块表达（层级靠色块深浅、宽窄、密度；"文字感"用细长条传达）。骨架区带内容=规格违规；
3. **载体样本条（四栏网格布局：色板｜字体阶梯+成文排版｜组件形态｜图标；标注必须齐全——样张不只是给人看，也是下游登记 1.0 §6 风格记录与编辑版转化的数据源）**：
   - **色板**：每块标注 中文名 + 色号 + 角色（页面底/主色/文字/强调/点缀…）；
   - **字体阶梯**：每级标注 用途 + 字号/字重（如 格标题 22/700、正文 14.5/400、数据 30/800——有数字展示场景的加数据级），真实样字渲染，并写明字体家族与回退栈；
   - **成文排版样本**：标题-正文-引用各一行真渲染，展示行距与读感——文字即产品的风格靠它补读感；
   - **组件形态**：按钮/卡片/输入框各一，按该风格的真实形态，每样例标注关键规格（圆角/描边/hover 行为等）；
   - **图标**：3-5 枚（**子代理调 solo-img-line-cy-icon-provisioner 检索的真库图标**——代理调用模式走简单档，按该风格图标气质选库；禁自绘、禁 emoji），标注 图标库名 + 线型/风格 + 描边宽度；
   - **底部信息行**：卡 id · 家族 · 图标库（许可）——来源与合规一行说清。

## 内容纪律（示意级，两防）

- **防扣字眼**：卡上文字**不含项目专名**——禁品牌词、项目名、真实文案；页面清单与行为叙述来自 0.1 §3 页面地图是合法输入（代表页本就按地图挑），不上卡的是项目专属名词与真实文案。骨架区零文字（见上），文字只出现在卡头标定区与载体样本条；
- **防偷懒**：禁 lorem、禁"商品标题/这里是文字"式空话占位（AI 后续真生成时才不会照抄）；
- 合法形态：骨架区=纯情绪色块（文字感的细长条）；**图片一律色块/渐变占位，禁找真图**（图片质量是被骂"不精致"的头号来源）——**色块占位仅限比稿卡场景**：正式出图（solo-ui-line-cy-style-to-hifi-gui）相反，照片位禁灰块、必须配贴合业务语境的真图；
- **图标口径**：骨架区内线性/形态图标**可保留**（图标=组件形态信号，不算文字）；带语义的完整 logo/徽章不留。

## 风格载体纪律（真实级）

- 色板=真值；字体=真家族真渲染；组件形态=按该风格的真实物理形态（圆角/描边/填充/密度）；图标=solo-img-line-cy-icon-provisioner 供给的真库 SVG（禁自绘仿制）；
- 骨架参数带风格基因：同一信息架构在本风格的骨架下自然呈现疏密/粒度/布局差异（生长公式：风格 × V0.1 = 布局）。

## 合集页壳

- 单文件 HTML（file:// 直开），多卡横向/网格并排，卡等宽，便于直接比较——**现成模板 templates/collection-shell.html**（iframe 卡槽=卡间样式隔离；两处必填：卡文件相对路径+卡实测高度，头部注释=用法）；
- 壳只做容器与标定，不含任何选择交互（选择在对话里说）；
- 壳可外挂**页名标签**（吸顶页名行，壳级统一样式）——骨架区内零文字后页面辨识靠结构+吸顶标签；页名标签行放在每张卡的上方（sticky 吸顶只有在卡体之前才吸得住，放卡后面吸不住），滚动长卡时页名恒可见；页名用**通俗页名**（商品列表/订单详情这类人话名，以卡内说明条为准），禁泛化名（"动态表单页"用户看不懂）；
- 模板给自创卡准备了「AI 新创」角标（卡槽头，`.slot-ai`）——自创卡记得带上，与库卡来源可辨；
- 卡片顺序与适配报告的编号一致。

## 生成流程（子代理任务书要点）

**本规格 = 验收边界，不是施工图纸。** 页面挑哪几张、每页布局怎么排、色块怎么组织——全部是子代理按生长公式（风格 × V0.1 = 布局）**自己生长**的自由，风格诠释的差异正是比稿的价值。任务书只装五样，禁携带布局级指令（页面清单的区块安排、每页布局、圆角/间距/缓动数值一律不写——写了就是主代理替子代理设计，比稿失效）：

1. **材料路径清单（只发路径，禁转述）**：开工文档 0.1（第一参考——业务权威）+ 盘问记录 `intake/用户输入.md`（第二参考——没进 0.1 正文的用户裁决原文：tab 结构/状态机/数据域口径在这，冲突时以 0.1 为准）+ 风格提示词副本 + 客户 VI 原件（色盘字体实值，子代理自己读图提取）+ 本规格——子代理全部自己读原文、自己挑代表页；主代理转述任何业务内容/色值=漂移源头，禁；
2. **风格身份**：卡 id + 气质锚点 + **提示词副本路径**（项目内 `specimens/<卡id>/prompt.md`，子代理必读的唯一风格定义；自创卡附自创描述——用户拍板的原样传递，不增不减）；
3. **硬约束**：色盘/字体以客户 VI 原件为准（子代理自己读图提取实值，主代理禁转写数值）+ 用户明示的项目边界（原样引用，禁加工）+ **通用边界条款**——"凡硬约束未覆盖的情形（语义色缺/字重缺/图标族缺/间距档不匹配……），自主选择最贴合风格气质的处理并上报疑点清单；禁止越出约束边界自作主张"；
4. **完成定义**：单卡 HTML 可渲染、**顺序钉死：DOM 自查先跑**（骨架区零文字/溢出/遮挡——零截图，修到干净）**再渲染实看**（视觉硬伤——形状崩坏/色调失衡/密度观感，DOM 拦不住的只在这层看，静态自查不替代实看）、载体条五节齐全**且逐项标注齐全（色板带名称/色号/角色，字体阶梯带用途/字号/字重与字体家族，组件带关键规格，图标带库名/线型/许可——缺标注=未完成）**。**任务书禁写"禁截图""由主代理统一浏览器检验"式条款**——它们会让子代理合法跳过实看；主代理统一检验只能作为其后的额外一道，不能替代；
5. **交接回执**：落盘路径 + 页面顺序 + 风格处理 + 疑点清单之外，必附**自设参数清单**——凡提示词与硬约束没写、子代理自己定的数值（边距/间距/密度/字号/比例等）逐条列出，让自定决策浮到水面供用户复核。

**判断顺序（动笔前）**：先从 V0.1 判断每页的信息组织与可用性（这页承载什么、用户怎么扫读），再以风格语言表达——禁"先翻提示词找布局规则再套业务"。提示词是气质材料不是布局图纸：倾向性描述（如"留白直排、避免卡片网格"）不是禁令；提示词中的组件规格有适用范围（如 cells 单行制式适用表单/设置分组行，不自动适用内容列表行），按本页真实内容判断适用性，塞不下改结构。

**风格参照进项目**（主代理前置动作）：候选定位后，主代理为每个候选建**一个风格一个目录** `intake/specimens/<卡id>/`，把该风格的提示词正本 **prompt.md**（九段合并版）复制进去，任务书只指项目内副本——子代理禁读项目外路径（wiki 目录变动不受影响，项目自包含）。**只复制 prompt.md，禁复制 card.md/cover.svg 等其余卡文件**：card.md 内嵌未适配的库原版提示词（含平台专属限定），子代理接触会被带偏；主代理适配所需的背景从 wiki 侧读，不进项目（防锚定同理：输入越聚焦，诠释越独立）。自创卡同构：`intake/specimens/<自创id>/prompt.md`。

**禁读已有 demo 卡**（防锚定，诠释独立生长）；demo 锚例（assets/demo-card/ 下）只供主进程对账用。子代理产出单卡，主进程拼合集页。

**样张落盘（一风格一目录，产出进自己目录，禁混放）**：每张比稿卡落 `intake/specimens/<卡id>/sample.html`——该风格的参照与产出同居一个目录，子代理只进出自己的目录、只碰自己的文件；主进程拼的合集页落 `intake/specimens/collection.html`。文件名固定 `sample.html`（目录已表风格，禁再加 `card-`/`sample-` 前缀撞名）。
