# 样章卡规则（第 1 步专用）

样章卡=带颜色带情绪的骨架图+风格载体样本，是用户定调的实物。**风格气质必须真渲染在卡上**——字体胖不胖、色带几层、材质在不在，用户第一眼见真章；只写进规范文档不算兑现。（形态出处：主管线比稿卡规格的项目内实践版，本文件自包含，无需查找外部文档。）

## 卡结构（单卡 HTML，自上而下）

1. **卡头**：风格名 + 一句话气质句（人话，如"像晒旧的旅行海报，圆润饱满"）+ 角标 `风格样章 · 定调用`；
2. **骨架图集主体（纯情绪色块）**：从页面行为叙述（docs/页面地图扩展）挑 3-5 个代表页（最能拉开风格差异的：有首页概念则首页必含，另配一张列表+一张详情类；执行会话禁读原产物——页面差异判断只依据行为叙述的文字），按比例缩放并排。**骨架区内零文字**——标题/正文/标签/按钮文案一律色块表达（层级靠色块深浅、宽窄、密度；"文字感"用细长条传达）。骨架区带文字=规格违规；例外：线性形态图标可保留（图标=组件形态信号），带语义的完整 logo/徽章不留。页名辨识靠吸顶页名标签（壳级标注，不属于骨架图集内容，不受零文字约束）；
3. **载体样本条（五节齐全，全部真渲染）**：
   - 色板真值 ×N（色块+色值标注）；
   - **字体阶梯真渲染**（标题/正文两级，大号真渲染——气质关键词在此兑现：提示词说"字要胖"，阶梯上就是胖体，禁用不胖的字体充数）；
   - 成文排版样本（标题-正文-引用各一行真渲染，展示行距与读感）；
   - 组件形态样例（按钮/卡片/输入框/筛选条各一，按该风格真实物理形态：圆角/描边/填充/密度）；
   - 图标 3-5 枚（内置 lucide 真库 SVG）+ **图形母题样本**（风格提示词声明的母题：波浪层数/拱形/太阳/彩虹弧等，按提示词要求的层数与形态真画）+ 材质质感样本（提示词声明的织物/木纹/陶器等，至少一处点缀呈现）。

## 风格载体纪律（真实级）

- 色板=真值；字体=真家族真装配真渲染（woff2 试装进卡，禁系统栈充数）；组件形态=该风格的真实物理形态；图标=包内 lucide 真 SVG（禁自绘、禁 emoji）；
- **生长公式：风格 × 行为叙述 = 骨架**——每台机的色块构成由该页行为叙述生长（叙述里有几个信息块/几个业务动作，骨架就长几个区块），禁凭想象填块、禁查模板库。**密度与信息量标尺**：每台机的区块数对齐该页行为叙述的条目数、填充率贴底无死空块、块间节奏疏密随风格——**逐台清点核验**（行为叙述 3 条信息块≠骨架 2 块=漏长，7 块=过度填充）；
- 骨架图集的页序=行为叙述清单顺序，页名吸顶标签用通俗页名（工单列表/提现记录这类人话，禁"动态表单页"式泛化名）。

## 内容纪律（两防）

- **防扣字眼**：卡上文字不含项目专名——禁品牌词、真实文案；骨架区本来就零文字，文字只出现在卡头与载体样本条；
- **防偷懒**：禁 lorem、禁"这里是文字"式空话占位；图片一律色块/渐变占位（样章场景）。

## 完成定义与顺序

1. 落盘 `rebuilt/preview/specimen/sample.html`（file:// 直开，零网络请求，字体 woff2 相对引用随卡）；
2. **DOM 自查先跑**（骨架区零文字/溢出/遮挡——修到干净）；
3. **骨架标尺核验**：逐台机清点——区块数=该页行为叙述条目数、填充率贴底无死空块、块间疏密随风格基因（此标尺源于实测：首版骨架凭想象填块被用户打回）；
4. **渲染实看**（形状崩坏/色调失衡/密度观感，DOM 拦不住的只在这层看）；
5. 对照风格提示词逐段自查：每一段气质主张在卡上有没有对应兑现物（字体段→字体阶梯、图形段→母题样本、材质段→质感样本）——**逐段对账**，缺哪段补哪段；
6. **常识照镜**（收尾）：导航落位/操作区位置/阅读顺序按常识过一遍——长完之后照，对不上不算缺陷，明显反常识的重长；
7. 交接：路径给用户 + 自设参数清单（提示词没写、自己定的数值逐条列出）+ 疑点清单。

## 精剪参照副本（用户定调后立即产，绘制环节的唯一样章参照）

用户定调后，复制样章卡为 `rebuilt/preview/specimen/sample-ref.html` 并**删掉骨架图集段**，只留：卡头 + 载体样本条五节（色板真值/字体阶梯/成文排版/组件形态/图标+母题+材质）。骨架图集只给用户定调用——**绘制环节禁看骨架图集**（看了骨架=照抄骨架布局，jiancewuyou 三轮照抄事故同源纪律）；绘制代理的输入清单里样章参照仅指 sample-ref.html，完整样章卡对绘制禁读。副本的字体/图片相对路径保持可渲染（删段后自检一遍 file:// 打开无断链）。
