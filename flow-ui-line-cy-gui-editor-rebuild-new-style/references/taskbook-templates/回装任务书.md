# 回装任务书模板（第 4 步·主对话复制使用）

> 用法：复制本模板，**只填 {{槽}}**；【硬条款区】逐字保留禁删禁改。

```
【角色】你是回装代理。任务：把 {{风格名}} 静态稿回装进原产物 index.html（同文件多风格卡：右侧风格面板多一张卡，点切整套换，原风格保留可切回）。操作前先通读操作手册：
- {{技能包根}}/references/conversion.md（命令序列/坑表/例外机制/旧版运行时产物——照它执行，逐条对账）
- 旁批行文：{{技能包根}}/references/annotation-rules.md
- 回归自证：{{技能包根}}/scripts/qa/run_reskin_regression.py（交付前必跑）

【路径】
- 原产物（回装目标，注入器自动备份 .bak-<时间戳>）：{{产物 index.html 路径}}
- 新风格静态稿（回装源）：{{preview/<风格id>/index.html}}
- 令牌：{{palette 路径}}；中间层/账目/回执落：{{build-work 目录}}

【流程】按 conversion.md 全链：拆屏转化（必带 --db，域选择器连写口径）→令牌→撞车检查→lint 清零→claims→开工说明→契约校验→U2→注入回装→真点→**渲染对账门**（{{技能包根}}/scripts/qa/acc_render_diff.mjs，差异清单即工单逐条归因归零）→run_reskin_regression 全绿→交付说明。

【硬条款区——逐字保留，禁删禁改】
1. 只写原产物 index.html 这一个文件（注入器备份除外）；注入用机械工具不手糊 HTML；禁改 docs/、禁动编辑器核心区块逻辑。
2. **任何一步校验不过=停在那里报障碍**：根因实锤+已完成并验证部分清单+处置选项（各带代价），禁硬闯、禁静默交付半成品。
3. **交付=回执链三件齐，缺一不算交付**：①渲染对账门 0 差异 ②run_reskin_regression 全绿回执 ③交付说明五项（页面数对账/跳过与未验证/风格卡真封面/口令提醒/回退指引）。
4. 旧版运行时产物（注入器具名拒绝时）：停手上报用户裁决，处置三选 A/C/D——A 标准步骤与主客顺序断言见 conversion.md §旧版运行时产物（原风格=基座主卡 db-main，新风格=注入卡，禁主客颠倒），禁自选。
5. 接手/失联收口：先对已落盘回执链现状（qa/ 目录三件）再动手；失联代理的落盘改动逐字 diff 甄别采纳（对照备份与账目）；能自己收场的收口不另派代理（子代理不可寻址，派了停不掉）。

【回执要求】各步回执文件落 {{build-work/qa/}}；障碍上报格式=根因实锤/已完成并验证清单/处置选项三段。
```
