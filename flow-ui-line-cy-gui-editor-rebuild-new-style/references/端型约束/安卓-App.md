# 端型约束 · 安卓 App（差异层，配合 _共用.md 读）

> 只装安卓独有的平台行为；通用规则见 `_共用.md`。**Material 的视觉主张（涟漪/FAB/组件形态/动效曲线/Roboto）不进本文件**——安卓 App 可以不是 Material 长相，页面视觉归风格提示词；只有系统渲染行为是硬线。

## 一、宿主/系统渲染清单（禁自绘，页面标注"系统渲染"留空间）

| 交互/界面 | 安卓真实形态 | 断言 |
|---|---|---|
| 运行时权限授权（定位/通知 Android 13+/相机/存储） | 系统权限弹窗（Material 样式由系统渲染） | 禁自绘授权 UI；页面只画触发入口 |
| 分享 | 系统分享面板（chooser） | 禁自绘分享面板 |
| 通知 | 系统通知栏/通知抽屉 | 通知本身不画；应用内消息中心另画 |
| 键盘 | 系统输入法（各家 IME 形态不一，输入区需避让+pan/resize 模式由开发定） | 输入区留键盘避让 |
| 系统 UI（设置/应用信息页） | 系统渲染 | 跳转入口行即可，禁画系统页内容 |

## 二、原生组件规范（带实值）

- **返回交互**：底部上滑手势（全面屏）或三键返回（传统导航）——**底部手势区≈24-48px 禁放可点元素**；无左缘返回手势（与 iOS 关键差异：页面内横向滑动不与返回冲突）
- **挖孔屏**：打孔位置**不固定**（左上/居中/右上因厂商而异）——避让按"顶部整条状态栏"口径，不按单侧
- **安全区**：顶部状态栏≈24-48px（机型碎片化）、底部手势区≈24-48px；**用 ≥系统推荐值口径，禁写死单一数值**
- **导航栏**：原生顶部应用栏 ≈56dp + 状态栏
- **触控目标**：≥48×48dp
- **底部 TabBar**：Material 惯例高度 56dp + 手势区——高度数值登记为开发对表项，视觉形态归风格提示词

## 三、生态行为边界

- **厂商碎片化**（安卓特有）：MIUI/EMUI/HarmonyOS-安卓帧 的权限管理/后台策略/推送通道（国内无 GCM，各厂商推送通道）行为不一——登记给开发，效果图不涉及
- **深色模式**：系统级切换，同 iOS 处理
- **应用商店合规**：隐私政策、权限用途说明（登记给开发）
- **推送**：国内厂商通道各异，通知在系统通知栏

## 四、注意登记

| 事项 | 说明 |
|---|---|
| 与 iOS 的返回差异 | 安卓无左缘滑返回——页面内横向滑动不受手势区约束（两端的横向滚动/滑动布局策略不同） |
| Material 误当硬线 | 涟漪/FAB/动效曲线是视觉主张非平台行为——用不用归风格提示词 |
| 挖孔位置随机型漂移 | 避让按顶部整条状态栏口径 |
| 厂商碎片化 | 行为差异登记给开发；效果图取主流行为（原生安卓口径） |
