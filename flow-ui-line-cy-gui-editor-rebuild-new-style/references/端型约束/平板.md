# 端型约束 · 平板（差异层，配合 _共用.md 读）

> 覆盖 iPad 与安卓平板的独有平台行为。手机端的规则（安全区/系统弹窗/返回手势）基础之上，平板的独有约束是**大屏与多任务**——核心一句话：**平板不是放大版手机**，布局要随尺寸/方向重构，不是等比缩放。

## 一、大屏布局规则（平板独有的硬线）

- **禁手机布局等比放大**：手机版页面拉宽到平板=布局违规（留白爆炸/单列拉长）。大屏必须**重构信息架构**：单列列表 → 列表-详情双栏（master-detail）、侧栏导航、多卡片网格
- **横竖屏两态都要成立**：横屏（如 1180×820）与竖屏（820×1180）各自有合理布局，非旋转缩放——效果图按需求方指定的方向画，另一态登记为开发注意
- **断点**：<600dp 手机形态 / 600-840dp 中屏（双栏起步）/ >840dp 大屏（多栏+侧栏）——Material 断点口径，数值登记为开发对表项，布局策略归画师按信息先行推导
- **键盘吸附**：分屏/键盘浮窗时输入区避让——比手机多"键盘占半屏"的场景

## 二、多任务/系统行为（平台独有）

| 交互/界面 | 真实形态 | 断言 |
|---|---|---|
| 分屏/浮窗（iPad Split View/Slide Over、安卓分屏） | 应用可与其他应用并列运行——页面在任意宽度下都要可用 | 布局禁写死像素宽，用比例/弹性 |
| 拖拽互导 | iPad 支持跨应用拖拽文本/图片 | 效果图不涉及，登记给开发 |
| 外接键盘/触控笔 | 物理键盘时 hover 类交互出现（iPadOS）| 桌面交互逻辑在平板+键盘场景部分成立 |
| 权限授权/分享/支付 | 同手机端系统弹窗 | 见对应端文件（iPad 归 iOS-App.md、安卓平板归 安卓-App.md） |

## 三、与手机端的规则继承关系

- 系统渲染清单/安全区/返回手势：**继承所在平台**（iPad → iOS-App.md；安卓平板 → 安卓-App.md）
- 本文件只追加**大屏+多任务**维度
- 触控目标 ≥44pt(iPad)/48dp(安卓平板) 同手机

## 四、注意登记

| 事项 | 说明 |
|---|---|
| 放大版手机布局 | 平板第一大坑——信息先行按"大屏的决定"倒推，不是按手机页拉宽 |
| 三态（竖/横/分屏） | 效果图按需求方指定态画；未画态登记为开发注意 |
| 双栏不是唯一解 | 大屏信息架构由画师按内容推导（双栏/侧栏/网格皆可），断点数值归开发对表 |
