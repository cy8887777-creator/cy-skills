# V06-⑤ 批量跑批细则（→ 主技能 references/batch-production.md）

> 状态：**已转正**（2026-11-10 用户拍板）——正式版在 `references/batch-production.md`，本稿留档。
> 定位：全量无编辑器出图（管线阶段 6）的细则。重在工作量，不重在流程——流程只有单页轻循环+收尾两检，一致性靠惯性三件套与链路制代理。

## 粮草清单（开跑前置，缺一则停）

1. 完整开工文档（已冻结，一字不改）
2. 设计资产与动效规范（阶段 4 成文）
3. 代表页精修稿（含源码——视觉基准）
4. 页面谱系清单（阶段 4 推演的全站页面结构+状态分支承载表）

## 派工原则

- 按业务链路/功能域分派：一个子代理负责一条完整链路，页面数由它自己推演
- **明确鼓励发散**：补充清单上没有的缺失页面（空态/异常分支/详情配套）——谱系清单是种子不是上限
- 禁固定页数切批；禁"清单有几页做几页"的机械执行
- 任务书只发四样粮草的路径+本链路范围，禁转写内容
- **落盘目录**：`pages/<链路名>/`，一代理只写自己目录，文件不交叉；每页一个独立 HTML（全内联），产物"合并"=全部跑完后壳子组装脚本一次动作，不做文件拼接

## 单页轻循环（比代表页少"定调"职责）

画 → 落盘 → 渲染实看抓硬伤（≤3 次）→ 调 solo-ui-line-X-unslop+motion **轻档**（方向已被代表页定调，跟着设计资产走，不重新发散 Direction）→ 对照代表页与资产自纠（缩远认亲戚，顺了就过）

## 防漂移三件套（惯性的物理来源）

1. 代表页源码 = 视觉基准：部件/版式/密度优先复用
2. 颜色/字体/圆角/部件只从设计资产取，禁重新发明
3. **动笔前必须先看代表页旧图**——不看旧图直接画的，抽验大概率出戏

## 收尾（全部链路跑完后）

1. 全量硬检：调外部走查技能（零截图：几何/溢出/遮挡/字号/间距/断图，退出码裁定）
2. 按批抽样感性自查：每批两三页认亲戚；出戏页回改，**连续出戏=该代理整批查**（根因通常是没看旧图或重新发明）
3. 附属文档更新：新增页面/变化登记（开工文档不动）

## 禁忌

- 禁改开工文档（变化只进附属文档）
- 禁跳过"看旧图"直接动笔
- 禁在批量里重新探索风格方向（方向已由代表页定调）
- **禁参照其他代理的跑批中间产物**——惯性锚点固定=代表页精修稿+设计资产两样；互相抄最新页=传话游戏，偏差滚雪球放大
- 禁逐条乱序修复（硬检问题按根因聚类：共享层→模板级→单页）

## 附：任务书模板（每链路一份，派一个子代理）

写法三原则：只发路径不发内容（转写必漂移）；第一动作写死=先看旧图（不写死必直接开画，惯性就断）；页面数绝不写死（写了必机械执行，空态异常全漏）。

```
【角色】你是「XX链路」的绘制代理。画法照代表页，禁止自由发挥风格。

【粮草】（自己读原文，禁等我转写）
1. 开工文档：<路径>（已冻结，只读，禁改一字）
2. 设计资产与动效规范：<路径>（颜色/字体/圆角/部件只从这里取，禁重新发明）
3. 代表页精修稿：<路径>（视觉基准——你的页面要和它是同一个产品）
4. 页面谱系清单：<路径>（种子不是上限，本链路相关的页以它为起点）

【本链路范围】一句话圈定，例：师傅端接单链路——从新订单进来到完成结算的全部页面。

【落盘目录】pages/<链路名>/，只写自己目录；每页一个独立 HTML（CSS/JS 全内联）。

【第一动作（不做完禁动笔）】
打开代表页渲染看一遍 + 读它的源码，知道部件长什么样、密度多大、怎么留白。

【然后推演页面清单】
这条链路哪些页面必须存在：主流程页 + 每步的空态/错误态 + 详情配套页。
清单不交审，自己推演自己画，鼓励补谱系清单上没有的缺失页。

【每页循环】
画（部件/版式/密度复用代表页的）→ 立即落盘 →
渲染实看抓硬伤（溢出/遮挡/对齐，最多 3 轮）→ 调 solo-ui-line-X-unslop + motion 轻档精修 →
缩远了看，跟代表页像同一个产品就过。

【边界】
- 图标调 solo-img-line-cy-icon-provisioner，禁 emoji
- 画面禁"示例/未接入"字样，模拟数据要像真的
- 画的过程中发现功能要变化/新增：记进附属文档 <路径>，开工文档一个字不动
- 禁看其他代理正在画的页，你唯一的参照物就是代表页和资产

【回执】
落盘清单：每页一行（路径 + 这是什么页）+ 未决问题如实列出（禁藏）
```
