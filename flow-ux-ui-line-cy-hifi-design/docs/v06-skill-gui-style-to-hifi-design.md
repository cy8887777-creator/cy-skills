# GUI 风格 → 高保真设计项目

把一份风格提示词和业务材料，画成一包高保真设计稿：每个页面都是能直接看、直接评的精修效果图，装在带页面树的预览壳里。本技能沉淀的不是"写 HTML"，是一套**先定调再生长、页页过双技能、风格靠感性自查守门**的绘制方法。

## 铁律（always-on）

1. **第一性文档**：开工先落盘两份文档到项目目录——`风格提示词.md`（原文+来源标注；用户没给则起草：风格库挑卡/按业务品类写/参考图反提，起草经用户确认后落盘）与 `用户输入.md`（业务材料原样归档或引原件路径）。两份是一切依据，原样保存禁转写摘要；派工只发路径不发全文。落盘后冻结，变化只进附属记录。
2. **风格提示词唯一权威**：一切视觉决定从它推导；它和通用审美冲突时它赢；提示词没写的=自由发挥区，只受负面清单约束。
3. **画布像真产品**：零"示例/未接入/示意"制作字样；模拟数据自洽像真（禁 [X]、123456）；不伪造业务成功、客户评价、产品指标。
4. **图标纪律**：供给第一优先调 solo-img-line-cy-icon-provisioner 技能（本地图标库+Iconify 兜底）；禁 emoji 当图标（零容忍）；形态必须贴合风格族，一套一线宽。
5. **产物形态**：单文件 HTML、CSS/JS 全内联、无外部字体/CDN；照片与大型插画走可访问外链图源（禁 base64 大图、禁 SVG 手绘充大插画），仅图标与小型插画用 inline SVG。
6. **先落盘**：每页写完立即落盘，防上下文耗尽零产出。
7. **渲染实看每页 ≤3 次**；无独立评审——solo-ui-line-X-unslop+motion 双技能一体精修就是质量工序。
8. **用户喊停=冻结**：按现状交付，未决问题如实进交付说明，禁止"再修一处"。

## 工作流（设计师实践，不是状态机）

### 认材料
读风格提示词+样张（如有）+业务材料；缺关键信息集中问一次。业务链路在心里过一遍：起点→终点→每个分支出口，哪些页面必须存在——这是页面生长的种子，不写成清单文档。

### Direction（动手前的内心锚，不产出文档）
从风格提示词推导：产品做什么给谁用；性格两三个具体词（禁"简洁/现代/高级/精致"万金油词）；属于哪个世界（材质/光线/场景）；哪 1-2 处允许撒丰富度（Moments）；一个只有它有的 Signature 细节。风格提示词已有声明的段（色彩/字体/组件形态/材质/图标/动效基调）逐段照办，未声明的段从这里推导。

### 代表页（定调卡点）
按业务链路挑 1-3 页最能代表风格与主流程的页面，全精度画：
写码 → 落盘 → 渲染实看（≤3 次，只抓硬伤：溢出/遮挡/对齐/断图）→ solo-ui-line-X-unslop 九遍精修（间距→颜色→图标→文案→字体→布局→细节→视觉→动效，方向从风格提示词推导，负面清单是硬边界）→ motion 动效 → 感性风格自查（样张+提示词在眼前，看图凭直觉答"像不像这个风格的亲戚、哪块出戏"；变种合法，判据=识别性）→ **交用户定调**。
不过不铺量；用户增删的代表页升级进本循环。

### 自由生长（页面长出来）
从业务链路推演页面谱系：每个状态与异常分支都有页面承载（空态/错误态/详情配套）。
按业务链路/功能域分派子代理：一个代理负责一条完整链路，页面数由它自己推演；**明确鼓励发散**补充清单上没有的缺失页面。每页同一个循环：画→落盘→实看硬伤→双技能一体精修→感性自查。
功能逻辑旁批不在本技能范围（后置旁批技能按用户手法补写）；资产登记里留"每页画了什么"设计要点当喂料。
壳子页面树/机型切换随画随刷新（重跑安全）。

### 收尾
1. 全量硬检：调外部走查技能（零截图：几何/溢出/遮挡/字号/间距刻度/断图，退出码裁定）
2. 按批抽样感性自查：每批两三页认亲戚；出戏页回改，连续出戏=该代理整批全查
3. **设计资产与动效规范成文**：可复用部件/模式/动效用法登记成文——下游完善文档、批量惯性、回流接续的粮草
4. 交付：壳子预览包路径 + 交付说明（未验证项如实标）

## 壳子（预览容器）

交付物装在编辑/预览器壳子的 **draft 档**：左侧页面树+机型切换保留，右侧批注面板保留（内容由后置旁批技能补写），编辑入口隐藏、绑定弹窗延后。接线见主技能壳子 draft 档说明。
