# 批量跑批细则（阶段6 · 全量出图）

> 定位：全量无编辑器出图（管线阶段 6）的细则。重在工作量，不重在流程——流程只有单页轻循环+收尾两检，一致性靠惯性三件套与链路制代理。主技能 SKILL.md 阶段 6 只留骨架，本文件是唯一细则。
> 定案背景：令牌锁定随编辑器直出线退役；一致性不靠数值表，靠代表页源码+设计资产+先看旧图的惯性。

## 粮草清单（开跑前置，缺一则停）

1. 完整开工文档（1.0，已冻结，一字不改）
2. 设计资产与动效规范（阶段 4 成文）
3. 代表页主文件（风格 HTML，含源码——视觉基准）
4. 页面地图扩展（design/页面地图扩展.md——全站页面地图，0.1 主线的画师扩展版）
5. 端型约束（solo-ui-line-cy-style-to-hifi-gui/references/端型约束/：_共用.md + 端型差异文件）
6. 盘问记录（intake/用户输入.md——没进开工文档正文的用户裁决原文：tab 结构/状态机细节/数据域口径在这；与开工文档冲突时以开工文档为准）

## 派工原则

- 按业务链路/功能域分派：一个子代理负责一条完整链路，页面数由它自己推演
- **明确鼓励发散**：补充清单上没有的缺失页面（空态/异常分支/详情配套）——页面地图扩展是种子不是上限
- 禁固定页数切批；禁"清单有几页做几页"的机械执行
- 任务书只发六样粮草的路径+本链路范围，禁转写内容
- **落盘目录**：`fragments/<链路名>/`，一代理只写自己目录，文件不交叉，目录名用中文（与页面树口径一致）；每代理产出**页面片段**（每页一个 section 块文件，最终由主对话合并进 `<风格id>/<风格id>.html`——复制粘贴级动作，非构建）。**禁把不同风格的页面塞进同一个文件**。**片段内资产引用按合并后位置书写**（`assets/...` 相对路径，与 `<风格id>/<风格id>.html` 同目录基准——写对合并即接续，写错合并即断链）；图片存本风格 `assets/images/<链路名>-*`（链路前缀防并发覆盖）
- **并发批次 ≤4**：一批回执齐了再派下一批——并发拉满会撞网关限流全批覆没。**派发模式（铁律）：一律后台模式（run_in_background）——主会话保持可对话，用户插话不杀代理；回执靠完成通知回收，禁前台阻塞等待。断点续跑**：重跑先盘点 `fragments/` 现状只补缺页；回执没来的代理按死掉处理，按目录现状重派
- **首链拦截**：第一条链路完成→主代理抽验（看图+读字）通过→再放后续链路；此后每条链路回执时顺手抽一页认亲戚，不等收尾——第一条链路系统性跑偏没人拦，几十页返工是最大的浪费

## 单页轻循环（比代表页少"定调"职责）

画（**从已有页面块起步**：复制 `<风格id>/<风格id>.html` 主文件/已合并页面块的部件与样式写法，只写本页内容——学皮不抄骨）→ 落盘 → **DOM 自查先跑**（溢出/遮挡/字号/跳转死链——自跑脚本零截图，修到干净）→ 渲染实看抓视觉硬伤（≤3 次，视口 mobile 375/390/430 / 桌面 1440）→ 调 solo-ui-line-X-unslop **Polish 模式**（**仅 Light slop→Polish 分支免确认直改；判出 Heavy slop / No slop = 停下回主线报裁决**；动效本阶段不做）→ 对照代表页与资产自纠（缩远认亲戚，顺了就过）

**轻档定义**：跳过 Direction 重新发散（方向已被代表页定调，跟着设计资产走）；solo-ui-line-X-unslop 按 Polish 模式**免确认直改**（不等用户逐页点头——跑批场景方向已锁定，逐页确认=流程卡死），只执行与版式/密度/细节相关的修整遍次；动效本阶段不做=不加新动效（不加 solo-ux-line-X-add-motion-design；unslop 自身删坏动效的 pass 照跑）。

## 防漂移三件套（惯性的物理来源）

1. 代表页源码 = 视觉基准：**部件/密度/质感优先复用**（学皮）——**版式不抄**：每页版式从本页业务内容长出来，与代表页长得全等=照抄违规（除非内容结构真相同）
2. 颜色/字体/圆角/部件只从设计资产取，禁重新发明
3. **动笔前必须先看代表页旧图**——不看旧图直接画的，抽验大概率出戏

> 抽验一句话判两头：**像同一个产品，但不是同一张图的复印件**——部件对不上=没看旧图（漂移）；版式全等=照抄（偷懒）。

## 收尾（铺量完成后按序跑，全部轻量；次序=矩阵随批走 → 导航分组 → 减法精简（剃完才硬检，硬检覆盖剃后版本）→ 盲校终检 → 硬检 → 抽样 → 盲测 → 地图核对）

1. **功能覆盖矩阵（每批交付必附，没矩阵不验收——随批走，非收尾一次性）**：独立只读审计（没参与制作的代理）拿功能点断言清单（开工文档+盘问记录提取）逐条在产物里找承载证据，产出**双向矩阵**——文档有→稿无=缺功能（硬伤必修）；稿有→文档无=画师自主补充（好的吸收进页面地图沉淀，坏的清掉）。页面地图吸收口径：**可补业务/用户场景，界面元素不补**（业务语言进地图，控件语言归画师）。**每个用户操作追加操作真实性三问**（对照端型约束文件）：这个操作在端型生态里存在吗？操作者是谁（用户/平台/宿主）？业务流哪一步有出处？——三问答不出=语义越界（实例："微信已绑定"收款渠道），从产物中清除。
2. **导航分组（全部片段合并完即做）**：全部片段合并进产物后，按开工文档页面地图的**导航结构**（底栏菜单/一级导航归属）整理页面分组与顺序——产物页序=导航序；编辑器版转化按此结构分目录继承（editor-conversion.md --groups）。
3. **减法精简（导航分组后、收尾硬检前——剃完才硬检，硬检覆盖剃后版本）**：主对话（非链路子代理）调 solo-ui-line-cy-design-occam-razor 对全站页面做减法纪律与独立盲评——删页面内重复与啰嗦表达；其 SKILL 所称「终审」=本清单第 5 项收尾硬检；剃改记录与盲评结论登记进七段对账表，「未独立评审」须如实注明
4. **文字盲校（收尾检查类最先跑，铺量完成即跑，一次；阶段4 收口已首跑过——两跑制见 style-selfcheck 文字层）**：提取全部页面文字派只读字的校对（不看图），挑错别字/病句/前后术语不一致/数字矛盾；顺带机械实值对照——提示词与开工文档写明的色值/圆角/字重逐个对照 CSS。**最最最轻量级，不升级不扩展**；错漏按页小批量派回修（协议见 solo-ui-line-cy-style-to-hifi-gui references/style-selfcheck.md 文字层）
5. 全量硬检：调外部走查技能（零截图：几何/溢出/遮挡/字号/间距/断图，退出码裁定——**跳转死链不在其机械层**，由第 5a 项专项核查承载；错误页>0 即 exit 2，读台账「引擎错误」节归因）；5a. **死链专项**：grep 全部 data-go 目标页 id 对产物页清单逐个核对（画师 style-selfcheck 死链断言同口径），悬空=必修；PC/平板端型产物给 walkthrough 显式传 `--viewport`
6. 按批抽样感性自查：每批两三页认亲戚；出戏页回改，**连续出戏=该代理整批查**（根因通常是没看旧图或重新发明）
7. 盲测抽样 + 审美评审抽样：抽样页截图混入交付前三方盲测（协议见 solo-ui-line-cy-style-to-hifi-gui references/style-selfcheck.md）——铺量页的风格归属由不知情第三方裁；**审美评审与盲测抽样同批同页跑**（成熟水准锚逐页挑观感差距，协议同文件审美评审节）
8. 新页核对页面地图扩展已补齐（来源=链路名+日期）；功能要变的上报裁决

## 禁忌

- 禁改开工文档（功能要变→上报裁决，裁决后按裁决执行）
- 禁跳过"看旧图"直接动笔
- 禁在批量里重新探索风格方向（方向已由代表页定调）
- **禁参照其他代理的跑批中间产物**——惯性锚点固定=代表页主文件+设计资产两样；互相抄最新页=传话游戏，偏差滚雪球放大
- 禁逐条乱序修复（硬检问题按根因聚类：共享层→模板级→单页）
