## 四、每组件三道验收门（缺一不收）

1. **模板门**：HTML 模板含 data-block/data-eid 占位（%E），双击可改字；
2. **令牌门**：样式全接令牌（`var(--…,原值)`），`python scripts/verify_component_css.py` PASS，新裸色/裸圆角零容忍；
3. **编辑器门**：注册进 CL.kinds（k+ic+label+PAL 模板），插入→选中→拖拽→改尺寸全链在 playwright 冒烟里过一遍；并在瑞士+黏土两风格下切换对比，外观随包变。

## 五、纪律

- 参考枚举只当**清单核对表**，模板形态按我们的骨架/令牌体系写，禁抄 ant/element 的 DOM 和样式值；
- 分批合入：B 档一批做完跑一轮全量回归（test_editor 16 断言 + verify_namespace + 面板插一圈截图）再进 C 档；
- 文档同步：CL.kinds 扩了以后，SKILL.md 的组件面板描述、component-pack-spec.md 的「精选 vs 全量」分工口径同步更新。
