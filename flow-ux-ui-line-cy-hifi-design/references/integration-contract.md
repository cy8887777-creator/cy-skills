# 技能间集成契约（integration-contract）

> **定位**：主线 flow-ux-ui-line-cy-hifi-design 与协作技能之间的**接口唯一正本**——输入清单/输出契约/能力边界/协议指针/同步规则全在本文件，两侧 SKILL.md 的接口段只留指针。改任一侧接口：**先改本文件 → 跑 validate.py 集成断言 → 再改两侧文本**。
> **模式信号**：主线任务书带「**管线模式**」标识 = 按本契约执行；无标识 = 各技能原生独立模式，本契约不适用（技能自身流程/触发/产物条款不受本文件约束）。
> **协议附件**：**跑批链路子代理任务书必附「协议页」**（守门缺省协议+自动模式行为+七段对账对接，模板在主线 references/batch-production.md）；主对话直派的阶段2/3 子代理可选（主对话自持上下文）。技能侧统一条件句：任务书附协议页时以协议页为准，无协议页按原生流程。

## 通用协议（对全部协作技能生效）

- **守门缺省协议**：交互式默认；用户明示自动模式时，每个用户确认点 = 输出待确认包（裁什么/依据/推荐）+ 标「未确认·自动通过」+ 继续，**禁静默放行禁跳段**；全部自动通过项进交付说明与七段对账表。
- **能力引用锚定**：主线对协作能力的引用以本契约登记的边界为准，禁超出登记范围声明（登记过的短板照实说）。

## picker · solo-ui-line-cy-gui-style-picker（阶段3，强依赖）

- **输入（主线必给）**：开工文档 0.1 路径、盘问记录路径、客户 VI 原件路径（用户有 VI 必收；无 VI = 明确声明，色盘走库卡并在 selection-result 标注「无 VI」）。
- **输出**：`intake/selection-result.json`（字段语义见 picker references/selection-contract.md）+ 风格提示词定稿 → **`intake/风格提示词.md` 是唯一下游权威**（拍板定稿含微调抄录入档；specimens 副本拍板后只归档不引用——禁双权威）。
- **能力边界**：选型结果零机械校验（坏 JSON/缺文件到阶段5 装入 §6 才暴露）——主线阶段5 装 §6 前**自验 JSON 可解析**；比稿卡零机械资产，同方案自检（毙 AI 默认脸）是主线阶段3 守门，picker 独立使用无此关。
- **同步锚点**：比稿卡落盘路径 = 工程根 `specimens/<卡id>/`（两侧文本同口径；改动两边同步+改本行）。

## 画师 · solo-ui-line-cy-style-to-hifi-gui（阶段4，强依赖）

- **输入（主线必给，六样）**：开工文档 0.1/盘问记录/业务材料路径 + 风格提示词路径 + 风格参照副本 `specimens/<卡id>/style-ref.html` + 端型约束两条路径（该技能 references/端型约束/ 下 _共用.md + 端型差异文件）。
- **输出**：`<风格id>/<风格id>.html` + `<风格id>/assets/`；`design/页面地图扩展.md`；`design/设计资产与动效规范.md` 成文素材（画师成文+主对话整理归位）。
- **回执结构（五项，两侧同步，正本=本行）**：①渲染截图路径清单 ②自设参数清单 ③自查记录 ④**落盘清单**（每页一行：路径+是什么页）⑤未决问题。
- **能力边界**：收口四样欠账（四层自查/文字盲校/压力测试/审美评审+盲测，定义见其 references/style-selfcheck.md）**零机械拦截**，靠主线铁律8+七段对账表；文字盲校两跑（阶段4 收口首跑+阶段6 终检）；评审者独立性（非画师本人/非主对话/评审互不兼任）无机制核验，派发时主对话自查。

## extract · solo-ui-line-cy-design-system-extract（阶段5，弱依赖）

- **输入**：全部代表页源码路径。
- **输出**：三构造（design-system.html/system-rules.md/system-rules.json）落 `<项目>/design system/out/`——**主线只消费取值节**，誊抄进 `design/设计资产与动效规范.md`；部件清单（源码位置引用）与动效节 extract **不产**，主线自产（谁产表见 start-doc.md）。
- **能力边界**：缺位时主线读源码手编取值节+交付说明登记降级；产物根在主线工程目录契约树之外，誊抄后原目录保留作证据；写盘前「写吧/落盘」停等——自动模式按协议页转待确认包。

## unslop · solo-ui-line-X-unslop（阶段4/6，强依赖）

- **调用口径**：**仅 Light slop → Polish 分支**免确认直改，范围=版式/密度/细节白名单；**Heavy slop / No slop 判定 = 停下回主线报裁决**，禁自行走全流程（主线轻档未授权这两分支）。
- **能力边界**：动效 pass 9（删坏动效 animate-pulse/transition-all）**照跑**——主线「动效本阶段不做」指不加新动效，清坏动效不算加；渲染预算两套口径（主线实看 ≤3 + unslop Check ≤3）各自独立计。

## walkthrough · solo-ui-line-cy-ui-walkthrough（阶段4/6 收尾硬检，强依赖）

- **调用**：`node scripts/batch.mjs <url> <root> <out> [--caliber x.json] [--viewport 390x844,1440x900]`。
- **退出码三态**：0=干净｜1=严重问题｜**2=引擎故障（错误页>0 即 2）**——主线读退出码前必看台账「引擎错误」节。
- **能力边界**：机械层只覆盖几何/溢出/遮挡/触控/对比度/断图/字号/间距等确定性硬伤；**跳转死链不在机械层**（仅观感层场景5 涉及，不进退出码）——**主线收尾死链核查另派**（画师 style-selfcheck 死链断言 / 专项 data-go grep），batch-production 硬检清单已标注承载方式；字号 11px 豁免线已修（2026-11-24）；PC/平板须显式传 --viewport。

## occam-razor · solo-ui-line-cy-design-occam-razor（阶段6 减法，弱依赖）

- **位次定案**：铺量合并+导航分组之后、**收尾硬检之前**跑（硬检覆盖剃后版本）；其 SKILL 所称「终审」= 收尾全量硬检。
- **执行者**：主对话（非链路子代理——减法作用全站合并文件）。
- **能力边界**：零脚本零退出码，盲评派发/两轮收敛全靠自觉——「剃而不评」靠七段对账表登记拦；其"未独立评审须注明"是合法出口，登记即可。

## icon-provisioner · solo-img-line-cy-icon-provisioner（阶段3/4/6 子代理自调，弱依赖）

- **调用**：模式 B 代理调用——语义清单+风格族+交付形态三字段必给；规格可选（默认 24px/currentColor/2px，交付单注明）。

## page-annotation · solo-doc-line-cy-page-annotation（附加B，不进 doctor 探测，选用才调）

- **输入**：开工文档（**对账权威**）+ 产物预览包（壳已预置批注面板+把手）+ 业务材料。
- **输出**：各页 `section.screen` 内 `aside.anno`（放置口径见其 SKILL 边界节——放 body 级=面板静默空）+ 待核清单 + 缺口清单。
- **能力边界**：骨架校验只查"每页旁批存在"，查不出放错位——主线附加B 验收含 aside 位置抽查；产物没画的功能点按开工文档登记缺口，禁粉饰。

## 同步规则（唯一正本纪律）

1. 本契约 = 接口类事实唯一权威；两侧 SKILL.md 接口段只留指针，禁另立口径。
2. 改接口流程：改本文件 → `python scripts/validate.py`（集成断言）→ 改两侧文本 → 断言复核。
3. **集成断言锚点（validate.py 校验三样）**：①八个协作技能 SKILL.md 各含「协议页」条件句 ②主线 batch-production 与画师 SKILL 两侧回执均含「落盘清单」（五项同数）③本文件存在且含「管线模式」「协议页」锚词。
