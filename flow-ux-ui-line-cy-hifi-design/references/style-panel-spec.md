# 风格槽面板规格（style-panel-spec）· 现行版

> **V06 归属：附加A（转化可编辑版）专用**——编辑器直出线已随 V06 退役，本文件仅在阶段7 转化线使用；主流程（阶段1-6）不消费本文件。

style-chooser.js（右侧抽屉面板）的实现规格。定案源：docs/skin-module-idea.md「风格槽面板」节（现行版=用户草图定稿 + 右抽屉/配色全角色跟随两次追加定案）。本文档随实现同步更新，不写未实现的设想。

## 一、数据源与降级链

1. **正式源=受控块**：STYLE-REGISTRY（族分组）/ STYLE-PACK packs（卡片）/ COMPONENT-PACK（组件面板，本规格不含）；
2. **降级链**：无受控块/解析失败 → 内置九槽预设（P30 构建期强制内联注入，恒在位——面板不得空转）；面板**不出现数据源/降级等内部字样**（不标注来源；`StylePanel.info()` 可程序化查询）；
3. state 持久化延续 `prototype-style-state` 协议（packId/paletteId/domBaseId/original/effective/custom/material…；material 字段与 setMaterial 代码保留=能力在、无 UI 入口——材质阴影是风格内置，不做用户可配置开关）。

## 二、UI 结构（右侧抽屉 · 双页签）

- **形态=右侧抽屉**（非模态 aside，`workspace-runtime-ui` 标记保留供导出清理）：
  - 打开：`html[data-sp-open]` 把画布右缘推到抽屉边、批注栏让位、手机预览完整可见；
  - 宽度：左缘 grip 拖宽 280–620px，localStorage `edSpDrawerWidth` 记住；窄=风格卡一行一张，拖宽一行两张（auto-fill）；
  - 关闭：Esc / 关闭按钮 / 再点入口=开关；关闭后画布回基线、批注栏恢复。
- **底栏「恢复原方案」**：低调文字按钮——恢复语义双轨：有交付初始风格（--active-pack 注入 initialPackId）=回交付时的风格整套；无=回产物原始基线。state 记 original/initialPackId，按下即 scheduleSave 标脏。
- **Tab1「已生成的可选风格」**：按 REGISTRY families **族分组**（族头=风格组N）；
  - 卡片内容：截图缩略（构建期 pack 截帧，缺省降级色板条）+ 风格名 + 一句话介绍（identity.mood）+ **「风格令牌」人话特征词行**（主色名/圆角档/字体/密度档——密度取包的 `density` 参数，缺省按间距推断；禁键名数值）+ **配色版胶囊平铺**（每粒=3 色块，勾打在当前应用的那粒胶囊上，只有当前卡有勾）；
  - 卡片右上角不放勾；跨族无 DOM 的包带「需重新生成」角标，点击走出口提示。
- **Tab2「更多风格方向」**（2026-11-21 定稿：竖向时间线四步弹窗）：点击 Tab2 **不切页**，`showModal` 居中模态弹窗（✕/遮罩点击/「我知道了」三种关闭）。引导句（换风格会按新风格重画全部页面，跑完本产物内就多一套可切换的新风格——原风格保留，随时切回）+ 时间线四步（左竖线贯穿节点圆圈，末步后线终止）：
  - ① **打开风格库**——风格库 wiki 里浏览全部风格方向；外链 design-style-wiki.pages.dev（「打开风格库 →」）
  - ② **选风格、复制提示词**——挑一个心仪的风格，在它的风格卡上复制完整提示词（每张卡自带）
  - ③ **下载安装技能**——下载技能包，放进**本产物所在的文件夹**，放好即安装完成；「下载换风格技能」按钮（RESKIN_SKILL_URL 常量：空=灰显「即将上线」，填 URL 即跳转，发布位置归 wiki 项目方）
  - ④ **执行技能，完成替换**——打开 AI 编程工具，项目空间选到本产物所在文件夹，启用「换风格技能」（启用方式见技能包内说明），把复制的提示词交给它，跑完即得到新风格的编辑器版本
  - 底部附注（只想换个配色？关闭弹窗回上一页，用「配色版」色块秒换主题色——页面形态不变）
  - 定案要义：四步按**客户动作链**切（每步一个成果：库打开→提示词到手→技能装好→替换完成），不按系统物件切；步骤是**体系级方法论**（重绘正道的客户交付路径），写死壳内、零项目绑定，所有产物共用；URL 级变化走 RESKIN_SKILL_URL 钩子。原内置假卡列表/提示词复制/旧下载按钮已撤除。

## 三、切换行为（按切换距离分档）

| 距离 | 行为 | 实现 |
|---|---|---|
| 色板级 | palettes 切换 | 根变量全角色重算（见下）+ L1 重烘（hero/按钮文字随配色更新） |
| 族内切包 | 换 member | L1 tokens + L2 l2Overrides + L3 iconSet sprite 全套应用（skin 三层） |
| 跨族（产物内已有多风格） | 屏集合整套切换 | v2 屏集合组：按 `data-style-id` 屏集显隐 + 左树按新风格整套重建 + curId 按页序重映射（切卡不丢页位）——机制正本见 multi-style-spec §二 |
| 跨族（产物内没有） | 禁直接切 | Tab2 出口提示重新生成——**产物内不长新族** |

**换配色=全角色换色（paletteColors 推算引擎）**：
- `swatches` 四槽语义 [0]主色 [1]底色 [2]文字 [3]表面；palette 可带显式 `hero`/`line`/`muted` 字段（写了全用写的）；
- 未写的推算：line/muted 沿包「底色×文字」连线按包原值位置重映射（包特征色不在线上→保留包值，瑞士硬黑边不丢）；浅衬底 soft=配色主色极淡色；hero 按包 hero 来历跟随（缺省/主色系→配色主色；中性色→配色文字色；独立色→保留包值）；按钮文字按配色主色亮度定深浅；
- 暗色组恒取包值（暗底必须配浅文字，不做自动反推）；
- applyPalette 落色后必须 syncLayers 重烘 L1（hero/`--style-primary-text` 烘在 override 节点里，只写根变量不更新它们）。

## 四、工程纪律

1. 面板 UI 全部壳 UI 域——命名空间守 namespace-spec 四域（ed- 前缀；free-editor 系耦合类豁免）；
2. STYLE_OWNED_VARS 皮肤域协议不变（13 个 owned 变量名单不动；palette 推算不新增根变量，hero/primary-text 烘在 L1）。这 13 个只是颜色根变量——形态参数（间距/字号/字重/行高/圆角/阴影/控件高度/动效）、语义色和扩展参数都写进按包作用域的 L1 覆盖节点，各键去向见正本表 assets/token-keys.json 的 emits；
3. 面板代码经 upgrade_html.py 随 /*FREE_EDITOR_START*/ 大块整体替换升级（STYLE_CHOOSER_START 为块内标记）；受控块数据本体走 migrate 路线（K2 范式）；
4. **组件段写死值门禁**：seed 组件段的裸色/裸圆角必须接 `var(令牌,原值)` 或在 chooser 换肤规则表内——`scripts/verify_component_css.py` 按 CSS 规则块扫，白名单只留语义例外（状态色/手机机身/开关轨道等），已接入 formal_gate。

## 五、口令分级（C 方案，2026-11-23 定案）

分级语义：**换肤=查看级，编辑=口令级**——客户拿到产物不输口令即可换风格/换配色看效果（面板是"看的工具"）；改内容、改布局、动结构仍要口令解锁。

1. **免口令五 API**（`window.StylePanel` 导出）：`applyPack` / `applyPalette` / `setMaterial` / `restorePreset` / `restoreOriginal`——换肤面板全部动作入口均不校验口令，未解锁产物可直接切换风格、配色、材质与恢复基线；
2. **仍锁定的口**：`applyStyleConfig`（微调提交口，内部走 `editorAllowed`）与全部编辑入口（改字/拖拽/页面管理/组件插入/保存导出）——未解锁时各自弹口令引导，能力不丢；
3. **口令框标记**：解锁对话框 `<dialog id="editorGate" data-editor-gate="1">`——脚本定位与测试钩子用标记，不做样式钩子；
4. **browse 态入口定位**（术语档：browse 态=`body.ed-ui-browse`，aka 预览态）：换肤入口 `#btnStyle` 绝对定位画布右上（`right:88px` 垂直居中）；编辑入口 `#btnEdit`（"✎ 去编辑"）贴文件名左侧（工具组 `order:-1`，口令验证后进编辑界面）——换肤与编辑两入口在 browse 态并存分立（换风包侧镜像记载见 multi-style-spec §八）；
5. 前提不变：面板打开本身免口令（`StylePanel.open`），解锁一次本会话内全量放行（`editorUnlocked` 短路）。

## 六、验收口径

- 三档切换实测：色板切换**逐角色**对比（不只按钮——横幅/边框/次要文字/浅衬底全要动，特征色保留）；族内切包三层全应用；
- 组件跟随：每风格下全部包组件插一圈再切换，逐类对比 computed style（"插一圈→切换→逐类对比"范式；参考实现见工程验收脚本 accept_123.cjs，技能包外）；
- 抽屉：推画布/拖宽记宽/1-2 列/Esc/批注栏恢复实测；
- 跨族显隐：构建含双 domBase 的测试产物，切换后页面 DOM 显隐正确、编辑器 data-eid 仍可编辑；
- 降级链：剥离受控块的产物打开面板=九槽降级可用；
- 口令分级实测：未解锁产物直接 applyPack 切风格成功、applyStyleConfig 弹口令框、编辑入口逐一被拦；browse 态换肤入口在画布右上可见可点；
- state 回读：刷新后选择状态还原；verify_namespace / test_editor / verify_blocks / verify_component_css 全绿（新断言随实现补）。
