# AI编程验证迭代

## 任务目标
- 本 Skill 用于：解决AI编程中常见的"假完成"问题，确保每次代码修改都经过真实验证
- 能力包含：页面可访问性验证、基础结构检查、功能实现反思引导、迭代修复流程
- 触发条件：用户要求编程、修改前端代码、实现新功能，或发现AI声称完成但实际未完成时

## 前置准备
- 依赖说明：scripts脚本所需的依赖包及版本
  ```
  requests==2.31.0
  ```

## 核心流程

### 修改后验证（强制执行）

每次修改代码后，**必须**执行以下验证流程，不得跳过：

#### 步骤1：启动开发服务器
- 确保开发服务器正在运行
- 记录服务器地址（通常是 `http://localhost:3000` 或 `http://localhost:5173`）
- 如果服务器未启动，执行启动命令（如 `npm run dev` 或 `yarn dev`）

#### 步骤2：运行验证脚本
调用 `scripts/verify_page.py` 检查页面基础状态：

```bash
python scripts/verify_page.py --url <页面地址>
```

参数说明：
- `--url`：目标页面的完整地址（必需）

输出内容：
- HTTP状态码（期望：200）
- 响应时间
- HTML基础结构检查结果
- 潜在问题提示

#### 步骤3：查看验证报告
解析脚本输出的JSON报告，关注以下指标：
- `accessible`：页面是否可访问（true/false）
- `status_code`：HTTP状态码
- `has_html_structure`：是否包含基础HTML结构
- `issues`：发现的问题列表

### 反思与迭代（关键环节）

#### 步骤4：对照检查清单反思
阅读 `references/verification-checklist.md`，逐项检查：

**基础验证（必须通过）**：
- [ ] 页面可以正常访问（HTTP 200）
- [ ] 页面有完整的HTML结构
- [ ] 浏览器控制台无致命错误（红字报错）

**功能验证（根据需求）**：
- [ ] 修改的代码是否正确引用（import路径、组件名称）
- [ ] 新增的逻辑是否被正确调用（生命周期、事件绑定）
- [ ] 数据流是否正确传递（props、state、API响应）

**逻辑验证（深度检查）**：
- [ ] 代码逻辑是否符合需求描述
- [ ] 是否遗漏了边界情况处理
- [ ] 是否存在明显的逻辑漏洞

#### 步骤5：问题修复
如果验证未通过或反思发现疑点：
1. **定位问题根源**：根据验证报告中的 `issues` 字段
2. **制定修复方案**：明确修改哪些文件的哪些代码
3. **执行修复**：修改代码
4. **重新验证**：返回步骤2，再次运行验证脚本
5. **循环迭代**：直到所有验证项通过

### 完成标准

只有满足以下**所有条件**，才能声称"已完成"：
1. ✅ 验证脚本返回 `accessible: true`
2. ✅ 浏览器控制台无致命错误
3. ✅ 功能需求的所有检查项都已通过
4. ✅ 至少完成一轮"修改-验证-反思"循环

## 注意事项

### 禁止行为
- ❌ 修改代码后直接声称"已完成"，未执行验证
- ❌ 验证失败后忽略问题，继续下一步工作
- ❌ 只修改代码不检查是否被正确引用
- ❌ 假设"应该没问题"，不进行实际测试

### 强制行为
- ✅ 每次修改后必须运行验证脚本
- ✅ 验证失败必须修复并重新验证
- ✅ 反思时必须对照检查清单逐项确认
- ✅ 所有检查项通过后才能确认完成

### 常见假完成模式（警惕）
1. **文件修改了但未引用**：创建了组件但忘记在父组件中import
2. **逻辑写了但未触发**：定义了函数但未绑定到事件
3. **样式改了但未生效**：CSS选择器错误或被覆盖
4. **数据有了但未渲染**：API数据获取成功但未赋值到state

## 使用示例

### 场景：修改按钮点击事件

**用户需求**：点击按钮后弹出提示框

**错误做法**：
```
AI: "我已修改了Button组件，添加了onClick事件，完成了！"
（实际未验证按钮是否真的能触发事件）
```

**正确做法**：
```
AI: 
1. 修改Button组件代码
2. 运行验证脚本：python scripts/verify_page.py --url http://localhost:3000
3. 查看报告：accessible: true，无报错
4. 对照清单反思：
   - onClick事件是否正确绑定？✅
   - 提示框组件是否已引入？✅
   - 是否测试过点击？需要用户确认
5. 告知用户："代码已修改并验证通过，请在浏览器中点击按钮测试功能"
```
