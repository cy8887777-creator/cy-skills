## 4. 页面细化

### 4.1 登录页

**功能定位**：用户进入系统的入口

**交互流程**：
1. 输入账号密码
2. 点击登录
3. 验证通过跳转首页

**状态定义**：
- 默认态：空表单
- 错误态：提示错误信息
- 加载态：登录按钮显示loading

## 5. 交互流程

### 用户登录流程

```
1. 用户打开登录页
2. 输入账号密码
3. 点击登录按钮
4. 系统验证账号密码
5. 验证成功跳转首页
6. 验证失败提示错误
```

## 6. 接口设计

### 6.1 统一规范

**鉴权机制**：Token放在Header，Authorization: Bearer {token}

**错误码**：
| 错误码 | 说明 |
|-------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 未登录 |

### 6.2 接口详情

**登录接口**

| 接口名称 | 方法 | 路径 |
|---------|------|------|
| 用户登录 | POST | /api/login |

**请求**：
```
POST /api/login
Content-Type: application/json

{
  "username": "string",
  "password": "string"
}
```

**响应**：
```json
{
  "code": 0,
  "data": {
    "token": "string",
    "userId": "string"
  }
}
```
