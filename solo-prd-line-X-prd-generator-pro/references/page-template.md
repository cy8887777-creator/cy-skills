## [页面名称]

**所属终端**：Web端 / 移动端
**功能定位**：一句话说明

### 页面概述

| 属性 | 说明 |
|-----|------|
| 入口 | 从哪进入 |
| 出口 | 操作后跳转 |
| 刷新 | 刷新机制 |

### 区块布局

| 区块 | 作用 | 数据 |
|-----|------|------|
| 顶部栏 | 导航 | 静态 |

| 元素 | 操作 | 行为 |
|------|------|------|
| 按钮A | 点击 | 提交表单 |

| 状态 | 显示 |
|-----|------|
| 默认态 | 正常数据 |
| 加载态 | Loading |
| 空数据态 | 空状态插画 |
| 错误态 | 错误提示+重试 |

**主流程**：进入 → 填写 → 提交 → 成功
**分支**：校验失败 → 提示错误
**异常**：网络错误 → 重试
