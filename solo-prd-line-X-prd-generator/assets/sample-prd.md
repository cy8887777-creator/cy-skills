## 4. 页面细化

### 4.1 Web端页面细化

#### 4.1.1 首页

**所属终端**：Web端

**功能定位**：展示系统核心业务数据，提供快速入口

**承载功能**：数据概览

**入口来源**：登录成功后直接进入

**出口去向**：
- 点击数据卡片 → 跳转对应详情页
- 点击快捷入口 → 跳转对应功能页

---

**页面区块布局**：

| 区块名称 | 类型 | 作用 | 数据来源 | 动态/静态 |
|---------|------|------|---------|----------|
| 顶部栏 | 导航 | 品牌Logo、全局搜索、用户信息 | 静态 | 静态 |
| 侧边导航 | 导航 | 功能菜单 | 静态 | 静态 |
| 数据概览区 | 内容 | 展示关键业务指标 | 接口获取 | 动态 |
| 快捷入口区 | 内容 | 常用功能快捷入口 | 静态 | 静态 |
| 最近操作区 | 内容 | 最近的操作记录 | 接口获取 | 动态 |

---

**元素与交互**：

| 元素 | 类型 | 交互行为 | 跳转目标 |
|------|------|---------|---------|
| 品牌Logo | 图片 | 点击 | 首页 |
| 全局搜索框 | 输入框 | 输入关键词，回车搜索 | 搜索结果页 |
| 用户头像 | 按钮 | 点击 | 下拉菜单（个人中心/退出） |
| 数据卡片 | 卡片 | 点击 | 对应详情页 |
| 快捷入口图标 | 按钮 | 点击 | 对应功能页 |

---

**状态定义**：

| 状态 | 显示内容 | 触发条件 |
|-----|---------|---------|
| 默认态 | 正常加载数据 | 数据正常返回 |
| 加载态 | 骨架屏 | 接口加载中 |
| 空数据态 | 空状态插画+"暂无数据" | 无数据返回 |
| 错误态 | 错误提示+"刷新重试" | 接口调用失败 |

---

**完整交互闭环**：

```
主流程：
  进入首页 → 加载数据 → 显示数据概览 → 用户浏览 → 点击数据卡片 → 跳转详情页

分支流程：
  - 有数据 → 显示数据卡片
  - 无数据 → 显示空状态

异常流程：
  - 接口超时 → 显示"数据加载超时，点击刷新"
  - 网络断开 → 显示"网络连接失败"
```

---

**快捷操作（键盘）**：

| 快捷键 | 功能 |
|-------|------|
| Ctrl+K | 聚焦搜索框 |

| 筛选区域 | 表单 | 条件筛选 | 静态 | 静态 |
| 数据表格 | 列表 | 业务数据展示 | 接口获取 | 动态 |
| 分页器 | 组件 | 分页控制 | 静态 | 静态 |

---

**元素与交互**：

| 元素 | 类型 | 交互行为 |
|------|------|---------|
| 新建按钮 | 按钮 | 点击 → 跳转新建业务页 |
| 筛选条件 | 下拉/输入 | 选择/输入 → 触发筛选 |
| 搜索框 | 输入框 | 输入关键词 → 实时搜索 |
| 列表项 | 表格行 | 点击 → 跳转详情页 |
| 分页器 | 组件 | 点击页码 → 切换分页 |

---

**状态定义**：

| 状态 | 显示内容 | 触发条件 |
|-----|---------|---------|
| 默认态 | 数据列表+分页 | 数据正常返回 |
| 加载态 | 表格骨架屏 | 接口加载中 |
| 空数据态 | 空状态插画+"暂无数据" | 返回空数组 |
| 错误态 | 错误提示+"重试" | 接口调用失败 |
| 筛选无结果 | 提示+"未找到匹配数据" | 筛选后无数据 |

---

**完整交互闭环**：

```
主流程：
  进入列表页 → 加载数据 → 显示列表 → 用户浏览 → 点击列表项 → 跳转详情页

分支流程：
  - 输入搜索词 → 实时搜索 → 显示结果
  - 选择筛选条件 → 刷新列表
  - 点击分页 → 加载对应页数据

异常流程：
  - 加载失败 → 显示错误+重试按钮
  - 搜索无结果 → 显示"未找到相关数据"
```

### 5.2 用户用例详情

#### UC-01：登录系统

**角色**：所有角色

**目标**：安全登录系统

**价值**：获取系统访问权限

**步骤**：
1. 输入用户名和密码
2. 点击"登录"按钮
3. 系统验证账号密码
4. 验证通过，跳转首页

**分支**：
- 密码错误 → 提示"用户名或密码错误"
- 账号不存在 → 提示"账号不存在"
- 账号已被禁用 → 提示"账号已被禁用"

**异常**：
- 网络断开 → 提示"网络连接失败，请检查网络"
- 请求超时 → 提示"请求超时，请重试"

---

#### UC-02：查看业务列表

**角色**：普通用户

**目标**：浏览和管理业务数据

**价值**：快速找到需要处理的业务

**步骤**：
1. 进入业务列表页
2. 系统加载业务列表数据
3. 用户浏览列表
4. 用户可进行筛选、搜索、分页操作

**分支**：
- 有数据 → 显示业务列表
- 无数据 → 显示空状态
- 搜索有结果 → 显示搜索结果
- 搜索无结果 → 显示"未找到匹配数据"

**异常**：
- 加载失败 → 显示错误+重试按钮
- 网络超时 → 显示超时提示

---

#### UC-03：新建业务

**角色**：普通用户

**目标**：创建新的业务记录

**价值**：系统业务数据完整性

**步骤**：
1. 点击"新建"按钮
2. 进入新建业务表单页
3. 填写业务相关信息
4. 点击"保存"按钮
5. 系统保存数据
6. 保存成功，跳转业务详情页

**分支**：
- 表单校验通过 → 保存数据

- 保存成功 → 跳转详情页
- 保存失败 → 提示失败原因

**异常**：
- 网络断开 → 提示"网络连接失败"
- 保存失败 → 提示错误原因，可重试
- 数据冲突 → 提示"数据已存在"

## 6. 接口设计

### 6.1 统一规范

#### 6.1.1 鉴权机制

- Token放在请求Header：`Authorization: Bearer {token}`
- Token有效期：7天
- 刷新机制：使用refresh_token换新token

#### 6.1.2 统一错误码

| 错误码 | 说明 | 处理方式 |
|-------|------|---------|
| 0 | 成功 | - |
| 1001 | 参数错误 | 提示具体参数 |
| 1002 | 未登录 | 跳转登录页 |
| 1003 | 无权限 | 提示无权限 |
| 2001 | 数据不存在 | 提示数据不存在 |
| 5000 | 服务器错误 | 提示稍后重试 |

#### 6.1.3 分页规范

- 默认每页条数：10
- 最大每页条数：100
- 默认排序：按createTime倒序

#### 6.1.4 幂等性

- POST请求使用唯一请求ID（X-Request-ID）
- 重复提交返回原结果

## 10. 开放平台与三方对接

### 10.1 三方对接概述

| 对接方 | 对接方式 | 对接内容 |
|-------|---------|---------|
| 微信 | API | 微信登录、分享 |
| 支付宝 | SDK | 支付功能 |

### 10.2 对接时序图

#### 微信授权登录

```
1. 用户点击"微信登录"
2. 前端调用后端获取授权链接
3. 后端请求微信获取授权链接
4. 后端返回授权链接给前端
5. 前端跳转微信授权页
6. 用户在微信授权
7. 微信回调后端code
8. 后端用code换token
9. 后端创建本地会话
10. 返回登录成功给前端
11. 前端跳转首页
```

#### 支付宝支付

```
1. 用户选择支付宝支付
2. 前端调用后端获取支付参数
3. 后端请求支付宝获取支付参数
4. 后端返回支付参数给前端
5. 前端调用支付宝SDK
6. 用户在支付宝完成支付
7. 支付宝回调后端异步通知
8. 后端更新订单状态
9. 后端通知前端支付结果
10. 前端显示支付结果
```

### 10.3 数据流向

#### 微信登录数据流向

```
微信用户 → 微信授权页 → 授权code → 我们的后端 → 用code换token → 创建本地会话 → 返回登录成功
```

#### 支付宝支付数据流向

```
用户选择支付 → 前端获取支付参数 → 后端请求支付宝 → 返回支付参数 → 前端调起支付 → 用户完成支付 → 支付宝回调后端 → 更新订单状态
```
