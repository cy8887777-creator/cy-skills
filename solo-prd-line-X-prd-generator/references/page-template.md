# 页面细化模板

用于PRD第4章"页面细化"，每个页面使用以下模板进行细化描述。

---

## [页面名称]

**所属终端**：Web端-集团管理员 / Web端-工程师 / 移动App / 移动端H5 / 付费H5

**功能定位**：一句话说明该页面在系统中的作用

**承载功能**：该页面承载的核心功能（从功能页面清单索引而来）

### 页面概述

| 属性 | 说明 |
|-----|------|
| 入口来源 | 从哪个页面跳转进入，或通过什么动作触发 |
| 出口去向 | 主要操作后可能跳转到哪些页面 |
| 刷新机制 | 页面数据刷新条件（下拉刷新/自动刷新/手动刷新） |

### 状态定义

#### 列表类页面状态

| 状态 | 显示内容 | 触发条件 |
|-----|---------|---------|
| 默认态 | 正常数据列表 | 数据正常返回 |
| 加载态 | 骨架屏/Loading动画 | 请求发出未返回 |
| 空数据态 | 空状态插画+提示文字 | 返回空数组 |
| 错误态 | 错误提示+重试按钮 | 请求失败 |

#### 表单类页面状态

| 状态 | 显示内容 | 触发条件 |
|-----|---------|---------|
| 默认态 | 空表单/预填数据 | 页面加载完成 |
| 编辑态 | 输入框可编辑 | 用户点击编辑 |
| 提交中态 | 提交按钮显示loading | 表单提交中 |
| 提交成功态 | 成功提示，跳转页面 | 提交成功返回 |
| 提交失败态 | 错误提示 | 提交失败返回 |

#### 状态流转图

```
空数据态 → 加载态 → 默认态
              ↓
           错误态 → 重试 → 加载态
              ↓
         提交中态 → 成功/失败
```

### 完整交互闭环

#### 主流程（Happy Path）

```
步骤1：用户进入页面
  ↓
步骤2：页面加载，显示loading态
  ↓
步骤3：接口返回数据，显示默认态
  ↓
步骤4：用户浏览内容
  ↓
步骤5a：用户点击操作A → 行为描述 → 结果
  ↓
步骤5b：用户点击操作B → 行为描述 → 结果
  ↓
步骤6：操作完成，流程结束
```

#### 分支流程

| 条件 | 路径 |
|-----|------|
| 条件A满足 | 路径X：... |
| 条件B满足 | 路径Y：... |
| 列表有数据 | 显示数据 |
| 列表无数据 | 显示空数据态 |

#### 异常流程

| 异常情况 | 处理方式 | 恢复路径 |
|---------|---------|---------|
| 网络请求失败 | 显示错误态+重试按钮 | 点击重试 → 加载态 → 默认态 |
| 数据加载超时 | 显示超时提示 | 点击刷新 → 加载态 |
| 表单校验失败 | 显示字段错误提示 | 用户修改 → 重新提交 |
| 提交失败 | 显示失败原因 | 点击重试/取消 |

#### 完整闭环示例

```
【登录页】交互闭环

入口：启动App → 登录页
出口：
  - 登录成功 → 首页
  - 忘记密码 → 密码重置页
  - 注册账号 → 注册页

主流程：
  输入手机号 → 输入密码 → 点击登录 → loading → 跳转首页

分支流程：
  - 手机号格式错误 → 提示"手机号格式不正确"
  - 密码错误 → 提示"用户名或密码错误"
  - 账号不存在 → 提示"账号不存在"

异常流程：
  - 网络断开 → 提示"网络连接失败，请检查网络"
  - 请求超时 → 提示"请求超时，请重试"
  - 登录被禁用 → 提示"账号已被禁用"

闭环验证：
  用户成功登录后进入首页，首页是稳定状态，流程结束
```

### 页面跳转关系

```
[当前页面]
    │
    ├── 操作A → [页面X]
    │         - 参数：id=123
    │         - 携带数据：当前页选中的数据
    │
    ├── 操作B → [页面Y]
    │         - 参数：无
    │         - 携带数据：无
    │
    └── 操作C → [H5页面]
              - 参数：url=https://...
              - 携带数据：无
```
