# solo-ue-line-cy-lofi-prototype-rebuild-hifi-gui 分步规范（spec）

> SKILL.md 八步流程的操作细则。全部条目来自 v2 实验会话实证（出处见 pitfalls.md 对应章节）。配套脚本在 `scripts/`。

## §1 基底选择与依赖核查（流程第 1、3 步）

- **基底=墨刀导出包的转换产物**（solo-ue-line-cy-mockingbot-html 产物：375×812、每节点 div+行内 style、`[idx]` 注释、z-index=idx）。墨刀原始「演示模式.html」是运行时渲染，静态抓不到内容，禁用
- **复制前验证资源依赖两处**：①`img src=` ②`<style>` 块内 `url()`——两处都要查外部图数量，只有 1 张外部图+其余内嵌 svg/纯 CSS 的页面复制过去零路径断裂
- **复制后先通读盘点再动手**：通读全文按区盘点替换点（状态栏/顶栏/入口区/按钮/底栏…），心里有数才写脚本。大文件分段读（643 行也分 3 次 Read），3.6MB 级先 grep 定位行号再 offset 局部读
- **上游引号截断 bug 顺手修**：style 属性内 font-family 带未转义双引号（`"Microsoft YaHei"`）会把属性拦腰截断，font-family 之后的声明全失效且无报错——换字体栈时先 grep 原始字节确认，替换字体栈时一并修掉
- **基底结构心智模型**（写脚本前必须建立）：
  - 所有 data-idx 节点**平级 absolute**、互不嵌套（挂 .stage 或 body）→ 推论一：overflow:hidden 加在某一层裁不到平级兄弟层；推论二：要裁切/父子动效必须构造真父子（跑马灯=窗口层 +overflow:hidden，文字层挪进去成真子元素挂 `@keyframes` 动画，`white-space:pre`）
  - height 写死在 style 里，框高≠内容折行高——scrollWidth 断言通过即无真溢出，勿误判
  - 空容器层与视觉层分清（底栏 309 空容器、310 才是 svg 层）——替换前先 `grep -B1` 看清层级
  - 透明热区占位节点存在（elementFromPoint 命中≠视觉遮挡）
  - `body{padding:24px}` 是墨刀展示壳，stage 原点不在 (0,0)
- **旧节点 display:none 隐藏不删**（保留可回溯性，none 数进 grep 自检）
- **阿语 RTL 镜像**：`x_en = 375 − x_ar − w`；星序 EN 左→右=实/实/空

## §2 素材判定（流程第 2 步）

- **nodeId 反查法=语义判定主力**：素材文件名 `3236-2267` ↔ Figma 节点 `3236:2267`，查 Design System `*/figma-node.raw.json` 的 name+完整父链定语义。工具：`python scripts/inspect-node.py <raw.json> --nid 3236:2267,... [--find 关键词]`（正查语义 + 按 name 反搜 nid）。要点：
  - nid 不能猜；反查要多轮递进；语义名与导出文件差一位（1622/1626 ↔ 1623/1627）也要验证后定映射
  - 打目标节点的**完整父链**（带真实 nid）才落定；Alt_V3 节点名全是泛化 Object，沿 id 往前找父级 Frame name 链
- **PIL ASCII 判形只做辅助**（`inspect-shape.py`）：会错（80×80 六枚曾全族误判礼花，raw.json 挖到 Diamond III/Gold I/Silver II 才翻案）。**语义=nodeId 反查+判形双确认才可记档**——错一次进档案连环放大（096 凭观感记档「段位徽章」实为双剑交叉，沿错档案越换越乱）
- **判 alpha 镂空定结构**：中心透明=环形头像框（不是头像，拿去裁切填充=「头像框里套头像框？？？」）；alpha 实心=盘（头像压上层露边当装饰）
- **sprite 先算单枚格位**再缩放引用（360×360 三枚竖排=单枚 180×180，直接缩 44 宽只露第一枚左缘）
- **同语义多形态看 bbox 选形**：fire 有横幅版与竖火苗版，横幅塞 24×24 压成扁条
- **整帧导出 svg 看 viewBox 内容占比**：Nav item 整帧 56×56 图标只占中心 30×30，CSS 缩到 30 显示后真实图标仅 16px——按原尺寸显示
- **客户 svg 直引前查着色机制**：`head -c 600`+`grep stroke`；固定色（如 #2C2C3A 浅底设计）→ 读原 svg 文本换 currentColor 后内联（形状保客户原套、颜色随容器色板）
- **manifest.md 是语义权威+使用约束索引，但会滞后**：用户重组目录后 manifest 没同步是常态——引用前以实际目录为准；tag/称号族（闪电/火箭/火苗+底条）标「禁挪功能位」
- **底栏入口集等多页共用元素要多页交叉验证**：对比首页与大厅页同位图标选中色；墨刀真值可能漏画（位 4 漏画实为消息）——AI 错搬 Figma Nav 组件的 Chat/Shop 是实锤事故
- **找用户新放素材看 mtime**：`ls -lt 生成素材/ | head`；`find 素材库 -newermt "时间"`；manifest.md mtime 变化=用户刚动过库
- **盘点 svg/webp 也要翻**不能只扫 png；无扩展名素材编号本身是目录（墨刀 uploads 真实结构 `18400/184007095/v2_tku4bm.png`），批量修正用 sed -E 精确捕获组
- **图标缺口分两类记录**：①客户库没导出→近义替代+交付时明说 ②3D 生成缺→中文清单交用户+2D 着色占位。真丢失入口退回 2D 占位等素材入库，不硬找替代
- **同血缘优先**：缺口补全从同库同血缘素材抽（如消息图标从聊天页产物抽同库信封），原样内嵌原版 svg（已验证视觉）染色即用，不是找相似素材

## §3 逐类替换规则（流程第 4 步）

- **顺序=字体→色板→按钮→卡片→图标**；每类一段独立 transform 脚本（`transform-tpl.py` 复制改名）+一次校验；一把全换=出错无法定位
- **换字体**：字体语义按页判定——英文页规范就是 Inter/Poppins，Tajawal 是阿语 RTL 阶段字体（只出现在阿语排版页）；外部审查说「没换 X 字体」先核实 raw.json 计数再回应。换后 verify 必加 scrollWidth vs clientWidth 对比（文字变宽必然折行）
- **换色板**：旧色值逐个 grep 清零；纯色查 backgroundColor 不只 backgroundImage（两属性都要断言）；亮度判背景素材可否上（顶亮 210/底亮 243=浅色可上，不违背浅色口径）
- **换按钮**：组件规范优先于惯性，差异大直接重建而非改样式（底栏先只换圆角被纠正，反查 Components 页 Nav item 规范后整体重建）；两源尺寸冲突先验倍图假设（比值≠倍率=非倍图）再看共同内核（外框含呼吸 vs 只画内容条），最终以用户视觉验收为准
- **换图标**：
  - swap_to_3d 保 z-index=idx 层序；先特定节点后全局（防全局规则误伤已特调节点）
  - 成对层同步隐藏旧 2D 层（漏藏=2D/3D 叠影实锤三起）
  - 格子/容器类图标**顶满不留呼吸感**（32×32 居中留 8px 被打回，改 48×48 顶满贴边）
  - 尺寸档位化：按钮图标 32 高档 / tab 24 / 星 12；混档被点名。按钮图标按墨刀素材原大显示，放不下放宽按钮不缩图标
  - 实色满幅 vs PNG 自带透明边有视觉差：同尺寸自绘显大一圈；rotate 后包围盒变大（48→≈54）四角戳出格子→内层收尺寸居中
- **换卡片**：规范陈列态外框≠真机效果，用户视觉验收>规范字面值（底栏 359×80 组件外框被两轮说大，改回墨刀内容条 343×56，样式基因保留 Figma）
- **墨刀残留垃圾清理**：蓝箭头角标（grep `#298DF8`）、place_holder 占位剪影、放错位的图标（设置位实为店面图标）；角标坐标贴图标右上角半叠，不按容器顶算
- **每轮改版版本独立**：v2a/v2b/… 各自独立可重跑脚本落 .claude-tmp，出错不连坐；产物只改一个 index.html，git 是总退路；净变更字符数回显做量化记录

## §4 对齐计算（流程第 5 步）

- **参照物=视觉主体中心，不是相邻文字**（切换箭头与「Ludo」文字齐平错 43px，应与大 logo 中心垂直居中）
- **行内多个不等高元素底对齐**；中心线对齐量化到 0.5px；多元素联合中心对齐（文字+星星+徽章+按钮三线中心对齐）
- **改动前量余量算可行性**（按钮内文字右缘 vs 按钮右缘，余量够才缩放）
- **字号平衡三查：字号比+基线+间距**（Lv. 12px vs 23 16px 差 2 倍+基线错位+几何居中但视觉分离 7.8px 三病齐发）；字号梯度有讲究（标签 12:数值 16:辅助 10）
- **组件改尺寸必查下方邻居联动让位**：按 y 阈值圈节点组批量位移（「某区间内 y≥N 的全组 -12」），先算 y 区间重叠再动
- **对齐以锚点边为准**：右缘对齐不是 x 对齐（素材宽窄不一时）
- **档位化≠数字齐**：高度统一档但宽随素材宽高比；横形素材特例保视觉重量同档
- **8pt 节奏微调+注释标原值**（「调整自原型 xx 值」）；微调=直接改内联 left/top/width 数值（绝对定位骨架优势：互不牵连）
- **「宽度不齐」查三层嵌套**别只查最外层（外框对齐但内层小卡居中 302 宽，观感不齐）
- **墨刀魔数边距先验算再当真值**（52/40 实为居中推导值）
- **组件常识零容忍**：经验条左圆角右胶囊（底轨 7px 填充 4px 圆角没同步）这类错误直接怒斥
- **几何断言坐标系统一**：CDP rect 一律相对 .stage 原点算（body padding 漂移 24/48px）；断言 key 用英文

## §5 验证交付（流程第 6-8 步）

- **三层验证链**：①grep 静态自检（3D 直引数/currentColor 数/旧色零残留/none 数；「跑完必须 grep 目标词残留，退出码 0 不算数」）②CDP DOM 断言（Runtime.evaluate 渲染后）③PIL ASCII 判形走查。**禁用视觉模型做测试**——截图只落盘供人工验收；视觉模型报告须逐条 DOM 反查甄别（6 条报障甄别后仅 2 真的实锤）
- **probe-clip 三通道清零**：A 裁切 / A2 img 越盒 / B 越出 stage / C 文字溢出；唯一合法豁免=跑马灯文字层嵌在 overflow 窗口内自身 bbox 越界（滚动原理）
- **验证视口锁 423×900**（>画布 375+两侧 padding）：视口 375 时滚动条+padding 把 stage flex 压到 312 宽，截图判形全作废——这是验证环境问题不是页面问题；headless 默认 800×600 截不到 stage
- **「挂上了」≠「生效了」**：动画双采样实测（两次采样 transform 差值对得上理论速度才算真滚）；verify 只断言自己改过的层，结构性/兄弟层问题测不出——结构改动加针对性探针（问真实父级/div 平衡/clip 扫描）；静态扫 HTML 不可靠（多行 svg 干扰闭合判断），问浏览器真实父级
- **断言纪律**：
  - verify 是活文档，随改版只增不减（旧断言是防回归资产）；跑前先核对选择器真实性（grep data-idx 唯一存在）
  - 断言红了**先验断言自身**（两次红都是断言算式错、页面其实对：flex 取整 ±1 放宽、中心点 vs 左上角搞混）
  - 查色双属性（backgroundColor+backgroundImage）；资源 404 断言是第一道关卡（顺带兜住相对路径深度坑）
  - CDP evaluate 返回双层 `{result:{result:{value}}}`，少取一层=undefined；失败必打印 exceptionDetails
- **审查会话报告处理姿势**（用户会用另一条线会话审查本线产物）：先并行核查硬事实，再逐条「已修/误判驳回/待拍板」，不全盘接受
- **缺口清单是持续交付物**：用户生成素材落 `生成素材/` 后说「你继续」→ 直引替换循环
- **交付 Figma 走 MHTML**：html2figma 插件只传单文件丢相对路径素材；Chrome/Edge 打开（file:// 可）等图片全加载→Ctrl+S「单一文件 MHTML」；保存前必须确认图片全加载（MHTML 只打包当时已加载资源）；备选 zip（根级就是 html+文件夹）
- **收口**：拍板口径当场落 memory/决策记录；index.html 头部版本注释逐轮更新（审计线+断更恢复资料）；实验产物用户定性前不 git 提交；.gitignore 防误 add 大体积未定稿目录
