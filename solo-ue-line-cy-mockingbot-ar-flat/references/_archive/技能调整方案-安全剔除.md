# 墨刀 → 阿语平铺版 · 技能调整方案（安全剔除 / 跳过手机版）

> 状态：方案待回测验证，验证通过后再统一改 `extract_en.mjs` / `gen_ar_flat.mjs` / `spec.md` / `SKILL.md`。
> 回测页：**Ludo对战首页 / Ludo Battle Home**。

## 0. 背景与问题
- 当前管线：墨刀导出 zip → Chrome CDP 提取（`extract_en.mjs`）→ 生成平铺版（`gen_ar_flat.mjs`）。
- 三大问题（蓝闪/丢元素/遮盖）修复后，PM 对「丢元素」不认可：稀疏页（Stage_00/04）塌空，疑是过滤把可见按钮框一起删了。
- 复盘：当前 gen 用「整节点删除」剔除黄块/蓝闪：
  - `gen_ar_flat.mjs` L82：无文本 + 橙系 `rgba(255,140,25)` bg/bc → `return`（整删）
  - L84：`InteractionMarker` 类 → `return`（整删）
  - L107：`#298DF8` SVG → `return`（整删）
- **根因假设**：若墨刀把交互指示色烘焙进按钮容器自身（矩形元素同时是热区），整删会连可见框一起删 → 丢元素 bug，**非原型固有特征**。

## 1. 页面结构事实（PM 确认）
按钮 = 矩形框（底，含 bg / 边框 / 阴影）+ 文本（标签）+ 交互链接（顶层，黄块 `rgba(255,140,25)` / 蓝闪 `#298DF8`）。
- 交付只需**平铺版（页面）**，不需要手机版预览。
- 读到的本就是 375 宽单页（artboard），可直接进平铺，**跳过手机版中间产物**。

## 2. 调整方案：两阶段 / 安全剔除 / 跳过手机版

### 2.1 提取阶段 = 保真全留快照
- `en_nodes.json` 保留 **每一个 visible 节点**（矩形 / 文本 / SVG / 指示层），**不删任何东西**。
- 这是可审计的完整快照，后续所有处理都在它之上，提取阶段零丢失。

### 2.2 平铺生成阶段 = 安全剔除（后处理）
- 直接从 `en_nodes.json` 生成平铺版（RTL 镜像 + 矩阵平铺），**无需手机版中间产物**。
- 剔除 = **隐藏纯指示层**，不是删除节点：
  - **黄块**：`rgba(255,140,25,*)` 且 自身无文本子节点 且 非承载品牌填充的容器 → `opacity:0`（保留几何位）。
  - **蓝闪**：`#298DF8` SVG / `InteractionMarker` 类 → `opacity:0`。
  - **安全规则（关键）**：若匹配节点**同时**带真实视觉属性（品牌 bg、边框、阴影、或有文本子节点）→ 仅中和指示色，保留容器与子元素，**绝不整删**。

### 2.3 与旧方案差异
| 项 | 旧（当前） | 新（方案） |
|---|---|---|
| 手机版 | 可选中间产物 | 跳过，平铺直接由提取数据生成 |
| 剔除方式 | 整节点删除（`return`） | 隐藏纯指示层（`opacity:0`）+ 容器安全判定 |
| 丢元素风险 | 高（可能删到可见容器） | 低（仅隐藏无内容的指示层） |
