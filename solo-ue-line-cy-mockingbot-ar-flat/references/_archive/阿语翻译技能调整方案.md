## 1. 已固化规则（只读 · 详见 `spec.md`）

这些已成定论，**不在本次决策范围**，列出仅为避免重复讨论：

- **语言源优先级**（PM 拍板）：读取/翻译一律找英文页面 → 英文板判据是 CJK **最少**（非 CJK=0）→ 英文板里漏翻的中文**直接 CN→AR**，不回译英文 → 术语对照表优先级最高。
- **只用 `index.html`**：标注模式(`inspect`) / 总览模式(`read_only`) 会污染提取。
- **数字用 1234 西阿拉伯数字**，品牌名/游戏拉丁名保留原文。
- **高度不设限**、**平铺列数自适应无上限**、**无 `<script>`**。

### 1.1 翻译与镜像规范（PM 2026-09-01 19:00 补充 · 三条）

> PM 原话：「1、如果一个组合（父级）只有图片、div，就不需要镜像，可以直接镜像组合；2、如果文字翻译后太长，优先考虑精简翻译，如果精简不了就考虑换行展示，然后元素、父级做高度适配；3、我把刚才未镜像版导入墨刀，发现还有部分是'母版'格式，后续要尽量避免使用。」

#### 规范 1 · 组合级镜像（纯图形组合整体翻，不逐子元素翻）

| 项 | 内容 |
|---|---|
| **规则** | 若一个组合（父级子树）内**只有图片 / div / SVG 等图形元素，不含任何文本节点** → **整体镜像该组合一次**，不再逐个子元素计算镜像 |
| **反例** | 组合内**含文本** → 必须逐子元素镜像坐标，文本节点靠 `dir=rtl` 保持阅读方向（若整体翻会把文字也翻反） |
| **为什么** | ① 图形元素无"阅读方向"，整体翻与逐子翻视觉等价，但计算更少；② 避免深层嵌套的坐标累积误差；③ 方向性图标（箭头等）随整体翻，符合 RTL 习惯 |
| **实现要点** | 提取阶段给节点打 `hasText` 子树标记（子树内是否存在文本节点）→ 生成时：`hasText=false` 的组合 → 父节点 `transform:scaleX(-1)` 一次搞定，子坐标原样输出 |
| **状态** | ⬜ 待实现（当前实现是**所有节点逐层镜像**，结果正确但非最优） |

#### 规范 2 · 译文过长：精简优先，换行次之

| 优先级 | 处理 | 说明 |
|---|---|---|
| **① 首选** | **精简翻译** | 阿语常比英文长。译文超宽时**先改译文**（换更短的同义表达、去掉冗余冠词），不动画面 |
| **② 次选** | **换行展示** | 精简不了才换行。此时必须做**高度适配**：<br>· 文本元素：`white-space:normal`（可换行）+ `height:auto` + `min-height:max(原h, fs×1.4)`<br>· **父级容器同步增高**（父 `height:auto` + `min-height`），否则会把下面内容顶开或裁掉 |
| **③ 检测** | 超宽判定 | 估算 `译文宽度 ≈ 字符数 × 字号 × 0.55`（阿语系数，待校准）；超出原宽 105% → 触发上述流程并**输出告警清单**供人工复核 |
| **状态** | ⬜ 待实现（当前 `white-space:pre-wrap` 不换行 + `min-height` 防裁切，未做超宽检测与父级增高） |

#### 规范 3 · 设计侧避免使用「母版 / Master」（PM 二次强调）

| 项 | 内容 |
|---|---|
| **事实** | PM 将未镜像版导入墨刀后，发现**仍有部分页面是「母版」格式** → 印证此前判断 |
| **规则** | 设计侧统一用**「组合」**，**禁止用「母版 / Master」** |
| **危害** | 母版导入墨刀后只能整体替换、**无法拆到元素级**（手机号登录页曾有此问题）；组合可元素级编辑 |
| **提取侧应对** | 遇「某页结构明显异于同模块其他页」（元素抱团、无法拆到元素级、坐标异常集中）→ **先怀疑原设计用了母版**，回报 PM 而不是硬解 |
| **状态** | ✅ 规范已确立，需在交付给设计侧时**再次强调**（首次提于 `spec.md` §8，已复发） |
