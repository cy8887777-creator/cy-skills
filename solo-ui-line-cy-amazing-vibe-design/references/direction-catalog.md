## 1. 种子解读规则 ◇

种子：8–64 位字母数字串，字母表顺序为 `A–Z`（位序 0–25）、`a–z`（26–51）、`0–9`（52–61）。

| 维度 | 子模式（计算方法） | 取值表 |
| --- | --- | --- |
| 主色相 | 全部字符编码之和 mod 360 | 0°–359° |
| 配色关系 | 数字字符个数 mod 5 | 单色 / 互补 / 类似色 / 三分色 / 分裂互补 |
| 明度基调 | 大写个数 ≥ 小写个数？ | 是 → 暗调；否 → 亮调 |
| 版式原型 | 首字符位序 mod 7 | 编辑大标题 / 不对称网格 / 中心海报 / 目录索引 / 便当网格 / 终端打印 / 横向色带 |
| 字体气质 | 末字符位序 mod 5 | 衬线展示 / 怪诞无衬线 / 等宽 / 窄体 / 圆体 |
| 圆角 | 元音字母（aeiouAEIOU）个数 mod 4 | 直角 0 / 微圆 4px / 圆润 12px / 胶囊 |
| 密度 | 首个数字出现的位置（从 1 计） | ≤ 8 → 紧凑；9–20 → 均衡；> 20 或无数字 → 疏朗 |
| 母题 | 第 9–16 位子串的 FNV-1a 哈希 mod 8 | 网格线 / 点阵 / 巨型数字 / 斜纹 / 正圆 / 票据齿孔 / 等高线 / 套准十字 |
| 文案语气 | 相邻字符“类别切换”次数（大写 / 小写 / 数字）mod 4 | 冷静克制 / 俏皮 / 宣言式 / 技术精确 |
| 强调剂量 | 所有数字之和 mod 3 | 点缀 / 适中 / 大胆色块 |
| 特殊模式 | 存在长度 ≥ 3 的回文子串？否则数字之和是质数？ | 镜像布局 / 竖排书脊 / 无 |

### 1.1 判断修正

种子给出的是灵感，不是枷锁。以下组合按规则自动修正（并在解读中注明），以体现“运用判断让它好看”：◆ / ◇

| 组合 | 修正 | 理由 |
| --- | --- | --- |
| 版式 = 终端打印 | 正文统一为等宽字体 | 终端语境下比例字体会破坏网格感 |
| 版式 = 终端打印 且 圆角 = 胶囊 | 圆角改为直角 | 胶囊形与终端美学冲突 |

### 1.2 配色生成

| 角色 | 亮调 | 暗调 |
| --- | --- | --- |
| 背景 | `oklch(0.975 0.012 H)` | `oklch(0.17 0.02 H)` |
| 次级面 | `oklch(0.935 0.022 H)` | `oklch(0.24 0.03 H)` |
| 正文 | `oklch(0.24 0.03 H)` | `oklch(0.95 0.015 H)` |
| 次要文字 | `oklch(0.46 0.03 H)` | `oklch(0.74 0.03 H)` |
| 主强调 | `oklch(0.52 0.15 H′)` | `oklch(0.78 0.15 H′)` |

`H` 为主色相；`H′` 由配色关系决定（单色 = H，互补 = H+180，类似色 = H+32，三分色 = H+120，分裂互补 = H+150）。这组明度保证正文与强调色对比度不低于 4.5:1。

## 3. 碰撞法（A × B）◇

把两个不相关的方向组合，往往能得到“听起来很糟、做出来很妙”的结果（呼应原文：“如果你觉得这绝对行不通，那就走对了路”）。

| 组合 | 可能的样子 |
| --- | --- |
| 工业控制面板 × 植物标本馆 | 金属面板上的标本标签卡；旋钮刻度改为生长周期 |
| 铁路时刻表 × 黑胶唱片封套 | 曲目表即时刻表；A/B 面即上下行 |
| 建筑蓝图 × 孔版印刷 | 双色套印的施工图；错版成为母题 |
| 天文观测 × 食品包装 | 营养成分表式的星表；星等即“含量” |

使用方法：

1. 从目录中随机抽取两个方向（可用种子决定）；
2. 写出“A 的结构 + B 的材质”或“A 的数据形式 + B 的色彩”两种映射；
3. 用灵感阶梯第 2 步（品味批注）锐化后再交给代理。
