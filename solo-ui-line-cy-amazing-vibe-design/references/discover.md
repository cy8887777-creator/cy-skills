> 目标：在空白画布前先广后深，找到**超越平均水平**的大胆方向，并写成一份可执行的设计简报。

设计中最难的时刻，是面对拥有无限可能的空白屏幕。应对它的最好方式是**先广后深**——而 AI 恰好是探索大量方向的出色工具，前提是把它推出舒适区：要大胆、要多样、要冒险。◆

---

## 1. 产出与退出条件

| 项目 | 要求 |
| --- | --- |
| 产出 | 3–4 个差异显著的方向样稿；1 份设计简报（[`templates/design-brief.md`](../templates/design-brief.md)） |
| 退出条件 | 用户选定 1 个方向（简报"想象 / 避免 / 取而代之"已对齐） |
| 记录 | 种子、解读过程、被否决的方向与原因写入设计记录 |

## 2. 技法 A：种子字符串（String Seed of Thought）

### 2.1 原理 ◆

模型无法主动随机，只能预测最可能的词元。若要多样性，就必须**从模型外部**引入随机性。String Seed of Thought（Sakana AI 发表）的做法是：让 AI 先生成一串随机字符串，再以它作为设计灵感。这样，模型每次都在做真正不同的决定。

原文对比实验中，同一个提示交给四个 Claude Code 实例：

| 提示方式 | 结果 |
| --- | --- |
| “为我的效率应用做落地页” | 几乎每次都是紫色渐变、左文右图、同一结构 |
| 追加“独一无二、每个决定完全随机” | 有变化但不多样：同配色、同结构、同样牵强的陶艺隐喻 |
| 种子字符串流程 | 配色、字体、想法明显不同；每次运行都独一无二 |

### 2.2 标准步骤 ◆

1. 用 **shell 脚本**生成一串长的随机字母数字串；
2. 基于字符串定义创意方向（配色、版式、字体等）——**透过表面寻找子模式、特殊数字和一切能激发灵感的东西**；
3. 运用判断把方向落地，并让它好看；
4. 不要在设计中暴露这串字符，它只用于灵感。

### 2.3 生成命令

```
# 推荐：本技能脚本（同时输出解读结果）
node scripts/seed.mjs

# macOS / Linux
LC_ALL=C tr -dc 'A-Za-z0-9' </dev/urandom | head -c 32; echo

# Windows PowerShell
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 32 | ForEach-Object { [char]$_ })
```

### 2.4 如何“读”一串种子 ◇

由浅入深分四层：

| 层次 | 观察什么 | 可映射到 |
| --- | --- | --- |
| 表面 | 首尾字符、字符位序、字符编码之和 | 主色相、版式原型、字体气质 |
| 子模式 | 数字个数与位置、大小写节奏、字符类别切换次数、重复字符 | 配色关系、密度、语气 |
| 特殊数字 | 质数、回文、对称、连续序列 | “彩蛋”式的规则突破（镜像布局、竖排标题） |
| 联想 | 字母形状、读音、像什么 | 母题、隐喻、命名 |

示例（规则详见 [`direction-catalog.md`](direction-catalog.md) 第 1 节）：

| 维度 | 子模式 | 取值 |
| --- | --- | --- |
| 主色相 | 全部字符编码之和 2871 → mod 360 | 351° |
| 配色关系 | 数字字符 9 个 → mod 5 = 4 | 分裂互补 |
| 版式原型 | 首字符位序 36 → mod 7 = 1 | 不对称网格 |
| 特殊模式 | 发现回文子串 “a7a” | 镜像布局 |

### 2.5 规范

- **必须**由脚本或系统熵生成种子；模型“想出来”的字符串不是随机的。◆
- **必须**把种子当作灵感，而不是逐字规则；最终以“好看、可用”为准，允许判断修正。◆
- **禁止**让种子字符出现在设计中。◆
- **应当**记录种子与解读过程，以便复现或回溯。◇
- **可以**固化解读规则（便于团队复现），也可以让模型自由联想（多样性更高）。◇

## 3. 技法 B：野心简报（Ambitious, specific prompts）

### 3.1 原理 ◆

另一种强推力是让提示**更具体、更大胆**。清晰的愿景让模型有据可依，而不是临场编造。找到独特点子的最好方式，是把**你自己的品味**带进来：先想象一个灵感源——一款电子游戏、一种室内设计潮流、一件艺术装置——再描述它应如何影响 AI 的输出。

### 3.2 简报公式 ◇

```
[产品与页面] + [跨领域灵感源] + [映射方式：灵感如何落到界面] + [功能约束：它仍须作为 X 工作]
```

### 3.3 原文示例 ◆

1. “做一个落地页，采用大胆的**像素艺术**主题和惊艳的图形。每个分区都像电子游戏的一帧截图，但整体仍然能作为落地页工作。”
2. “做一个落地页，设定在一座**等距视角的、活着的 3D 城市**里，不同功能以街区或建筑来表现。”
3. “做一个落地页，采用**激进的不对称布局、不协和的配色与字体、令人不适的负空间**。打破所有规则，但依然要好看。”

### 3.4 灵感源清单 ◇

| 领域 | 可借用的东西 |
| --- | --- |
| 电子游戏 | 像素、HUD、关卡地图、存档界面、成就系统 |
| 室内与家具 | 材质、灯光、侘寂、中古现代、工业风 |
| 艺术装置 | 光、空间、互动、尺度反差 |
| 印刷与出版 | 报纸版式、孔版印刷、杂志拼贴、博物馆展签 |
| 工业设计 | 控制面板、仪表、旋钮、合成器 |
| 交通与标识 | 时刻表、翻牌显示、导视系统、登机牌 |
| 科学与制图 | 等高线、星图、实验记录、蓝图 |

## 4. 技法 C：灵感阶梯（Ideation ladder）

难点在于想出原创点子。直接向 AI 要点子，只会得到人人都能得到的平均点子。原文的三步系统：◆

### 第 1 步 · 广而浅

```
我想为我的产品找到一种大胆、独特的设计语言。请尽可能多地列出点子，
每个配一句简短的高层描述。要广，不要深。
```

### 第 2 步 · 用品味批注锐化

挑一个方向，用自己的品味写批注。原文“工业控制面板”示例：

```
工业控制面板：
- 我想象的是触感强的东西：清脆、令人满足的按键，好听的声音。
- 起初我想到卡通化或拟物化，但这感觉很俗。避免这些。
- 取而代之，我想要一致的组件和一些小细节，点到为止，不过火。
- 灰色渐变会很无聊，需要更多质感。也许可以加入一些颜色，同时保留控制面板的感觉？
请根据我的品味把这个方向锐化。
```

批注的四种句式：

| 句式 | 作用 |
| --- | --- |
| 我想象… | 给出感官目标（触感、声音、节奏、场景） |
| 我原以为…但这显得…，避免… | 划出边界，排除俗套 |
| 取而代之… | 指出替代路径 |
| …会很无聊，需要更多… | 指出缺口 |

### 第 3 步 · 压缩成 POC 提示

```
能否写一段简洁的提示，让 AI 代理据此构建一个初始概念验证页面？
```

> 关键：如果只是把 AI 生成的点子贴回 AI，很难得到独特的结果——任何人都能做同样的事。**只有主动掌舵设计方向，你才能做出只有你做得出的东西。** ◆

## 5. 技法 D：大胆试错与失败提示库 ◆

- 不要害怕尝试听起来很糟的点子。如果你在想“这绝对行不通”，那你就走对了路。代理常常会让你意外，你会发现自己低估了它。
- 如果确实不行，扔掉结果、换个方向。
- **保存那些行不通的提示**，新模型发布时重测——这样你才知道自己是否充分利用了最新模型的能力。

失败提示记录格式（写入设计记录第 7 节）：

| 提示摘要 | 模型与日期 | 失败表现 | 重测计划 |
| --- | --- | --- | --- |
| 等距 3D 城市落地页 | 模型 A · 2026-03 | 建筑透视错乱 | 下一代模型发布后重测 |

## 6. 方向评估与收敛 ◇

从 3–4 个方向中选 1 个时，用下表打分（1–5 分），总分最高且无“1 分项”者胜出：

| 维度 | 问题 |
| --- | --- |
| 契合度 | 是否契合产品气质与受众？ |
| 独特性 | 与默认模板（紫色渐变、左文右图）的差异有多大？ |
| 可执行性 | 现有模型与素材工具能否执行到位？ |
| 可延展性 | 能否延展到其他页面与组件？ |
| 可用性风险 | 是否会威胁对比度、可读性或操作效率？（分越高风险越低） |

## 7. 阶段规范汇总

| 级别 | 条目 |
| --- | --- |
| 必须 | 外部生成种子；先广后深（≥ 3 个方向）；种子不外显；简报经用户确认 |
| 应当 | 使用跨领域灵感源；广而浅地要点子；用四类批注注入品味；记录种子与解读 |
| 可以 | 尝试“听起来很糟”的点子；组合两个不相关的领域（A × B）；固化解读规则 |
| 避免 | 以形容词代替灵感源（“现代、简洁、高级”）；把 AI 点子原样喂回 AI；只探索一个方向就开工 |

## 8. 常见失败与排查

| 症状 | 可能原因 | 对策 |
| --- | --- | --- |
| 所有方向仍是紫色 / 左文右图 | 种子由模型“想象”，或未真正使用种子 | 用脚本生成；要求列出解读过程 |
| 方向很怪但不可用 | 缺少功能约束 | 在简报中写明“它仍须作为 X 工作” |
| 点子都很平均 | 直接要“好点子” | 改用灵感阶梯：广而浅 → 批注 → 压缩 |
| 用户说不出想要什么 | 缺少参照 | 给出 3–4 个样稿，请用户批注“喜欢 / 不喜欢 / 为什么” |
| 方向之间差别不大 | 解读只用了表面层 | 加入子模式与特殊数字层；换一批种子 |
