# 评审子代理调用规范

> 主会话视角：怎么调评审子代理、传什么、不传什么、怎么解析输出。

## 评审角色

**评审者 = 看截图的设计师 agent**（大模型，独立上下文）。

- 用 Claude Code **Agent 工具**，调 `general-purpose` 子代理
- 任务书（子代理实际看到的提示词）在 `templates/judge-prompt.md`
- 评审者**只看截图 + 评审提示 + 美学简报**，**不看代码**、**不知道停止阈值**、**不知道评分历史**、**不知道之前轮次**

## 调用接口

```
Agent(
  subagent_type="general-purpose",
  prompt=<templates/judge-prompt.md 全文> +
         "\n\n---\n\n" +
         "## 本轮输入\n" +
         "截图：<path/to/r{n}-1440.png>\n" +
         "基准图：<path/to/ref-{a,b}.png>（可选）\n" +
         "评审提示版本：P6@<哈希或日期>\n" +
         "轮次：第 N 轮",
  description="评审第 N 轮：<方向简述>"
)
```

## 必传 / 必不传

| 信息 | 必传？ | 说明 |
|---|---|---|
| 当前截图 | ✓ 必传 | 必传，是评审唯一对象 |
| 评审提示 P6 全文 | ✓ 必传 | 每轮必须**字字相同**（不变） |
| 基准图 | 可选 | 强烈推荐；声明为"情绪板/基准，不是临摹目标" |
| 简报 / 设计方向 | ✓ 必传 | 让评审知道"该设计追求什么美学" |
| 评分历史 | ✗ 不传 | 防"前一版 7.4 所以这版至少给 7.5"的锚定 |
| 停止阈值（9/10） | ✗ 不传 | 子代理不该知道何时停 |
| 代码 / 实现细节 | ✗ 不传 | 评审只看结果 |
| 之前轮次的 gaps | ✗ 不传 | 防止"按上轮建议评分" |

## 输出解析

子代理按 P6 模板返回 JSON：

```json
{
  "aesthetic": "暗调工业控制面板：触感、克制、单一信号橙",
  "studio_vision": "顶级工作室会让控制面板的物理质感成为唯一主角...",
  "gaps": [
    { "area": "结构", "issue": "仍是左文右图模板",
      "fix": "改为非对称网格，让面板图像跨两栏", "severity": "高" }
  ],
  "score": 7.4
}
```

主会话要做：
1. **解析 JSON**——失败则视为评审失败，整轮重派
2. **写到 `<output_dir>/DESIGN-RECORD.md` 第 3 节**——轮次、评分、gaps 摘要
3. **按 gaps 改代码**——一次改全部 high/medium 项
4. **不重做**评审独立判断——不因为分数低就重派

## 轮次与停止

| 触发 | 处置 |
|---|---|
| 评分 ≥ 9.0 | 停止汇报用户，标注"评审达标" |
| 连续 2 轮提升 < 0.3 | 停止，上报用户（停滞检测） |
| 轮次达 5 | 强制停止，汇报当前最佳 |
| 用户说"停" | 立即冻结，按当前最佳交付 |
| 评分 < 6 持续 3 轮 | 停止并上报（方向可能有问题） |

**禁止**：
- 同一轮多次调用同种子代理（取中位数应在 references/define.md 第 9 节约定，**单次调用不取中位**）
- 评分 < 阈值时改评审提示（提示固定，不能为了让分高改提示）
- 在评审提示里加停止阈值

## 失败处置

- Agent 调用报错 → 重试 1 次，仍错则上报
- JSON 解析失败 → **整轮重派**（评审失败 = 本轮无结果）——**重派时提示词不变**（铁律 3 冻结），**不修改**任何措辞
- 评审 timeout → 重试 1 次，仍 timeout 则按当前最佳版本交付
- 评审者输出"未达"但**无明确 gaps**（笼统差评）→ 整轮重派，要求具体差距
- 评审者输出 gaps 但**严重度全 minor** → 仍视为有效评审，**实现者按 minor 改后**进入下一轮
