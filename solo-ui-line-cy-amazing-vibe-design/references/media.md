> 目标：用图像、视频与着色器替代“代码图形”，让设计展现超越表面的投入。

编码代理热爱写代码，却很少使用图像。它们倾向于用简单的代码替代品——渐变、形状和基础图案——而这些恰恰是 AI 生成设计最明显的痕迹。有的代理内置了图像工具却很少用；有的没有，但只要给一个 API 密钥，就能轻松调用 OpenAI 或 Gemini 生成图像。◆

---

## 1. 判断：哪里需要真实素材 ◇

| 位置 | 代码替代品（痕迹） | 推荐素材 |
| --- | --- | --- |
| 英雄区主视觉 | 渐变光斑、3D blob、几何拼贴 | 产品渲染、场景摄影、概念插画 |
| 分区插图 | 图标 + 渐变圆底 | 风格统一的插画组 |
| 背景质感 | 噪点渐变、满屏毛玻璃 | 真实材质图（纸、金属、织物）+ 克制叠加 |
| 动态焦点 | 无限旋转的 CSS 形状 | 抠像后的循环视频 |
| 页面过渡 | 淡入上移 | 关键帧插值过渡（随滚动擦洗） |

## 2. 图像生成

### 2.1 原文做法 ◆

```
这个设计太朴素了。用图像生成增加个性。考虑把着色器或 3D 效果与图像结合，
做出更有意思的视觉。
（图像生成使用此 API 密钥：只在本地使用，不要存入代码或产品。）
在浏览器中逐帧验证效果是否正确。
```

图像与效果能迅速增加个性，并让设计不那么明显像 AI 生成——因为它们展示了超越表面的投入。

### 2.2 图像提示的构成 ◇

| 要素 | 示例（工业控制面板方向） |
| --- | --- |
| 主体 | 触感强烈的工业控制面板 |
| 材质 | 哑光石墨灰粉末涂层金属，细腻颗粒 |
| 光线 | 左上方柔和定向棚拍光，边缘细微反光 |
| 构图 | 面板占右侧三分之二，**左侧三分之一留空给标题** |
| 色彩 | 绑定方向令牌：信号橙、奶油白、炭黑 |
| 禁止项 | 无文字、无字母、无 logo、无人物 |
| 画幅 | 与版式槽位一致（如 3:2） |

### 2.3 与着色器 / 3D 结合 ◇

- 视差、位移贴图、颗粒、光线扫过等效果应以真实图像为底，而不是以渐变为底；
- 动画只改变 `transform` 与 `opacity`，时长 ≤ 320ms（循环动效除外），并跟随系统的减少动效偏好；
- 成组素材保持一致：固定风格描述词，以首张图为参考做图像编辑，而不是每张独立生成。

## 3. 视频生成

视频生成是**设计层决策**（和"用 CSS 动画 vs 用 Lottie vs 用视频"一样，由设计意图决定）——**实现者**写代码时按需调用当前环境可用的视频生成能力。

**探查到环境有生图/视频能力时**（例：本机 solo-img-line-cy-bailian-image-gen，已验证，百炼 Token Plan）：
- 模型：`wan3.0-video`（已实测 5 秒 / 480P 约 92 秒出 mp4）
- 端点：`/api/v1/services/aigc/video-generation/video-synthesis`（异步，X-DashScope-Async: enable）
- 调用：`python ~/.claude/skills/solo-img-line-cy-bailian-image-gen/gen_image.py --video "<prompt>" --duration 5 --resolution 480P --no-audio`
- 视频 URL 24 小时内有效，脚本自动下载转存

> 无 solo-img-line-cy-bailian-image-gen 的环境：fal.ai 等聚合平台是备选；都没有则视频环节降级（CSS 动画/Lottie 替代或占位）并如实告知。

### 3.1 技法 A：循环素材 + 抠像 ◆

1. 生成一段**纯色背景**的循环片段；
2. 用色度键（类似绿幕）抠除背景；复杂情形使用**视频蒙版模型**（video matting）；
3. 得到的动画可以叠加在界面任意位置，而不会看起来像一段视频。

**玻璃折射技巧**：要得到可信的玻璃折射效果，先把玻璃渲染在**页面背景色**之上（把折射效果烘焙进去），再用视频蒙版模型去除背景。这比代码能做到的丰富得多：焦散反射、玻璃折射与复杂的物理运动。

> 静态图的同类技巧：在纯黑背景上生成发光 / 透明物体，叠加到深色页面时使用 `mix-blend-mode: screen`，黑色即被“抠掉”。◇

### 3.2 技法 B：关键帧过渡 ◆

许多视频模型除文本生成视频外，还能在**两张关键帧图像之间插值**。因此可以拿两张产品静帧生成过渡片段：

- 在用户执行操作（如切换到另一屏）时播放；
- 或随手势（滚动、滑动）**逐帧擦洗**。

原文示例（行李箱演示页）：初始帧由图像生成得到；视频从该帧动画到下一状态；**用上一段视频的最后一帧作为下一段的起始帧**，保证无缝衔接；随用户滚动依次擦洗各段过渡。应选择物理表现与一致性强的视频模型。

### 3.3 工程要点 ◇

| 事项 | 做法 |
| --- | --- |
| 首屏性能 | 提供海报帧（poster）；`preload="metadata"`；视口外暂停（IntersectionObserver） |
| 自动播放 | 循环素材使用 `muted playsinline loop`；不得自动播放有声视频 |
| 减少动效 | 用户偏好减少动效时显示静态海报帧 |
| 透明视频 | Chrome / Firefox 使用 WebM（VP9 alpha），Safari 使用带 alpha 的 HEVC；不支持时回退到图像序列或 canvas 色度键 |
| 滚动擦洗 | 推荐导出为图像序列并绘制到 canvas；若直接设置 `video.currentTime`，需以极短关键帧间隔编码（如 `-g 1`）以保证流畅寻帧 |
| 体积预算 | 单个循环片段建议 ≤ 2MB；图像使用现代格式并按显示尺寸输出 |

## 4. 接入方式 ◆

**实现者写到需要图/视频的地方，才探查当前环境的生图/视频能力**（禁动工前预探查）：探查到则按下表调用（例：本机 solo-img-line-cy-bailian-image-gen）；探查不到则降级（fal.ai 等聚合平台/外链图库/占位）并如实告知。

| 实现者的环境 | 接入方式 |
| --- | --- |
| **探查到生图能力（例：本机 solo-img-line-cy-bailian-image-gen）** | 调 `python ~/.claude/skills/solo-img-line-cy-bailian-image-gen/gen_image.py "<prompt>"`（已验证 qwen-image-3.0-pro / wan2.7-image-pro） |
| 同上，调视频 | 加 `--video --duration 5 --resolution 480P`（已验证 wan3.0-video，约 90s 出 mp4） |
| 同上，改图 | 加 `--image <本地图>`（I2I，qwen-image-3.0-pro 强制） |
| **无 solo-img-line-cy-bailian-image-gen** | fal.ai 等聚合平台备选 / 外链图库 / 占位并告知 |
| 其他代理（Codex、Antigravity 等） | 原文中的备选，本技能**不强制支持**；如需，参考原文各代理的内置图像工具 |

## 5. 密钥卫生 ◆

1. **为代理单独创建密钥**，并设置严格的消费上限——即便泄露或被误用，成本也可控，且可随时吊销而不影响其他工作；
2. 不要反复把密钥粘贴进对话：

```
创建一个被 git 忽略的文件 .env.agents，把这个 API 密钥存进去；
并在 AGENTS.md / CLAUDE.md 中给自己留言：这些密钥仅供开发期间使用，绝不能随产品发布。
```

3. 密钥**禁止**写入源代码、提交记录、构建产物或前端包。

## 6. 版权与合规 ◇

- 确认所用模型的生成内容使用条款，记录模型名称与日期；
- 避免生成可识别的真实人物、商标与受版权保护的角色；
- 在设计记录的素材清单中登记：来源、模型、提示、许可、用途、尺寸。

---

## 7. 无密钥时的降级方案 ◇

| 方案 | 适用 | 注意 |
| --- | --- | --- |
| 有意图的 SVG 插画 | 图标化、几何化方向 | 必须服务于方向母题，而不是默认 blob |
| 授权图库摄影 | 写实场景 | 统一调色，避免“图库感” |
| WebGL / CSS 着色器 + 真实纹理 | 抽象质感 | 以真实纹理图为底，控制性能 |
| 排版即视觉 | 编辑型、报纸型方向 | 以字号反差、网格与留白承担视觉重量 |

## 8. 规范汇总

| 级别 | 条目 |
| --- | --- |
| 必须 | 主视觉不得只靠代码图形；密钥独立限额且不进入产物；在浏览器中逐帧验证 |
| 应当 | 图像与着色器 / 3D 结合；构图为文字留白；色彩绑定方向令牌；成组素材保持一致；登记素材清单 |
| 可以 | 抠像循环视频；关键帧过渡与滚动擦洗；聚合平台自动选模型；以“页面背景色”预渲染玻璃折射 |
| 避免 | 渐变光斑、3D blob、满屏毛玻璃；未压缩的大体积素材；自动播放有声视频；忽略减少动效偏好 |
