> 简报的价值在于**品味批注**——明确的"避免"往往比"想要"更能塑造结果。

| 字段 | 内容 |

| 字段 | 内容 |
| --- | --- |
| 方向名称 | {例：工业控制面板} |

## 3. 品味批注（必填前三项）

| 句式 | 内容 |
| --- | --- |
| 我想象的感觉 | {感官目标：触感、声音、节奏、温度、场景} |

| 取而代之 | {替代路径：例"一致的组件 + 点到为止的小细节"} |
| 还缺什么 | {缺口：例"需要更多质感，可以加入一点颜色"} |

| 类型 | 内容 |
