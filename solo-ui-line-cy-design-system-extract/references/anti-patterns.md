# 反模式（anti-patterns）

> **两类**：（1）**15 条历史矛盾**——子代理审查时发现的已有规范内部冲突，提取时必须按本文件裁决落地
> （2）**12 条禁令**——任何项目产出的"自查清单"，违反即返工

---

## A · 15 条历史矛盾裁决

| # | 矛盾条文 | 裁决 | 应用位置 |
|---|---|---|---|
| 1 | 输入框圆角 sm（v1）vs md（v1.1） | **md**（与按钮一致） | radius 章 + Input 组件 |
| 2 | 弹层动效 250ms（Do）vs 400ms（Motion 章） | **400ms slow 档** | Motion 章 + Modal 组件 |
| 3 | 字重"只用两档 400/600"vs 标题用 700 | **三档 400/600/700**，display/title 700 | Type 章 |
| 4 | 正文行高 1.6–1.75（原则）vs 1.5（行高 24） | **1.6** | Type 章 + body token |
| 5 | 按钮解剖"高 34px 内边距 7px 20px"vs 实现 7px 18px | **7px 18px**（=行高 20 + 内边距 7×2 + 描边 2 = 36） | Button 组件 |
| 6 | "只许引用语义层"vs 文档自身用 gray-300 描边 | **增加 --input-border-default 组件层 token** | 语义层 + 组件层 |
| 7 | "同一视图可见字号 ≤3 档"无边界 | **同一内容区块 ≤3 档，组件内文字不计** | Type 章 + Do/Don't |
| 8 | "不要用加粗弥补层级缺失"vs "标题用字重+字号双重强化" | **同 3：display/title 700 是字重+字号同步升级，非弥补** | Type 章 |
| 9 | "长篇正文禁用 secondary"无量化 | **连续段落 ≥3 行** | Semantic 章 text-secondary |
| 10 | 间距"全部 4 的倍数"vs 按钮 7px 18px | **页面布局间距取档；组件内部尺寸按组件规格（豁免）** | Spacing 章 |
| 11 | "全局统一左上光源"vs shadow x 偏移为 0 | **顶部光源（x 偏移恒为 0）** | Shadow 章 |
| 12 | "Token 总数"口径 32 / 28 / 48 不统一 | **统一为 4 段相加 = 85**（演示版） | 全局口径 |
| 13 | "一视图一主按钮"未定义视图 | **同一内容区块 / 同一弹窗** | Button 组件 |
| 14 | "高危操作不用文字按钮"无替代 | **必须用 danger 变体** | Button 组件 |
| 15 | "颜色+图标/文字双通道"vs 图标未定义 | **图标体系独立成章**（§10） | Icons 章 |

**裁决纪律**：本表 = 权威；任何子代理或新代码出现与本表冲突 → 以本表为准。

## B · 12 条禁令（产出前自查）

| # | 禁令 | 自验方法 |
|---|---|---|
| 1 | 禁裸 hex / 裸值——一切取自 token 表 | 全文搜 `#\w{6}\b` + 间距/字号裸数字（除 token 定义处） |
| 2 | 布局间距禁魔法数字（非 4 的倍数） | 全文扫 `margin\|padding\|gap.*\d+px`，非 4 倍数即命中 |
| 3 | 禁颜色作唯一信息载体（WCAG 1.4.1） | 检查状态表达：颜色 + 图标/文字至少 2 通道 |
| 4 | 禁一视图双 primary 按钮 | 视觉盘点组件清单，统计同视图 primary 出现次数 |
| 5 | 禁阶梯外字号 | 字号取自 6 档 token，禁 15/17/19/20/24/26 |
| 6 | 禁阴影 + 描边双重强化 | 同一卡片不应同时有 shadow 和粗描边 |
| 7 | 禁彩色阴影 / 发光效果 | shadow 值统一 rgba(24,24,27, *) |
| 8 | 禁 x 偏移阴影 | shadow 第一个数值必为 0 |
| 9 | 禁循环装饰动画 | 动画必须对应状态变化；加载指示除外 |
| 10 | 禁混用图标来源 / 描边粗细 | 同一视图图标全部取自 `assets/icons/` |
| 11 | 禁 z-index 自造数值 | z-index 取自 5 档 token |
| 12 | 禁静默禁用 | 禁用元素必须配原因（aria-disabled + title） |

**自检脚本扫描顺序**：

```
1. 裸 hex：md + HTML 全文（除 token 定义表格内）
2. 裸数字：margin/padding/width/height/font-size 取非 token 值
3. 多 primary：JS 遍历 + 视觉盘点报告
4. 阶梯外字号：取 font-size 值对照 6 档 token
5. 阴影异常：取 box-shadow 值，检查 x 偏移 = 0 + 透明度色值
6. z-index 异常：取 z-index 值对照 5 档 token
7. 图标来源：扫 <img src> / <svg>，非 assets/icons/ 路径即命中
```
