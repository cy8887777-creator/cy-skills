# 分级判据与主力圈定（strategy-rules）

## 策略判据（②盘点产出建议，③PRD 后按结构影响终审）

| 策略 | 判据（多数信号同时满足 → 精绘；系统组件可全覆盖 → 直写） |
|---|---|
| 精绘 | 位图素材 ≥3 **且** 浮层 ≥2 **且** 视觉复杂度高（地图/画布/照片流/立体拟物/不规则布局）——**单一信号不触发** |
| 直写 | 系统组件可全覆盖（表单/列表/设置/协议/纯文字页） |

**精绘配额（2026-09-30 用户定）**：全量盘点后按复杂度画像降序排列，
**精绘上限 10**（可在③PRD gate 调整）——超出部分降直写并补
"源图参照"字段（写码时可对照源图区域，不做像素还原）。
依据：首轮实跑精绘命中 33/83（判据用"或"逻辑过宽），用户配额砍至 10。

弹窗：命名「弹-」前缀或图内容为覆盖层 → `type: 弹窗` + 宿主页关联。
长图：h/w > 2.2 → `long_page: true`（画布全高、允许纵向滚动）。

## 页面圈定（⑤⑦⑧三站的执行顺序依据）

圈定规则（按序判定）：
1. **典型页（⑤）**：全项目复杂度降序 top 2-3 张（最难/最具代表性
   形态，无论是否 tabbar 页——如地图页/首页）。开荒：无模具可用，
   边做边为⑥提取设计系统提供素材；
2. **主力页（⑦）**：排除典型页后——**tabbar 直达页必为主力**
   （底部导航的 4-5 个主页面——应用门面）；**高频使用页必为主力**
   （主流程核心：详情/列表主页/AI 交互主页面/IM）；其余按盘点
   复杂度评估：复杂度高档（位图≥3 或浮层≥2）→ 主力；
3. **铺量页（⑧）**：非典型页非主力页。铺量结对流水 = 布局文档 +
   tokens + 组件库直写（不做完整标注/校准/单页 verify——DoD 为
   build + 对照 + 结对裁判通过）。

## 降级后置（难页逃生门）

连续 2 轮不达标的页：标记 `降级后置`（降保真版本先过，或留白），
不卡流水线；难页集中最后专项攻坚。 适用：⑦主力页与⑧铺量均适用。
