## 0. 使用方式（给 AI 的指令）

1. 生成 / 修改任何 UI 之前，**先读完本文件**，所有视觉决策从 §5 token 表取值。
2. 表中不存在的值 = 禁止使用（不得自造颜色、字号、间距、圆角、阴影）。
3. 遇到规则未覆盖的场景：按 §1 价值观裁决，并把缺口记录回本文件。
4. 本文件与 HTML 版冲突时，以本文件为准（md 是规则的权威源）。

## 1. 价值观（冲突裁决顺序）

一致 Consistent > 明确 Explicit > 高效 Efficient > 可生长 Scalable

- 两条规则冲突时，选更符合靠前价值观的方案。
- 任何新规则必须能追溯到这里，否则不立。

## 2. 布局规则

- **骨架**：Topbar 56px + Sider 220px（可折叠 64px）+ Content。内容型页面 max-width 1200px 居中；工具型可全宽。
- **栅格**：Web 12 列 / Pad 8 列 / 移动 4 列，栏距 `--space-6`。
- **断点**：`sm` <768（单列、Sider 变抽屉、表格降级卡片）｜ `md` 768–1199（2 列）｜ `lg` 1200–1919（标准 12 列）｜ `xl` ≥1920（内容限宽居中）。
- 禁止内容区外再嵌套限宽容器；禁止 999/9999 式魔法 z-index。

## 3. 多端差异规则

| 维度 | Web | Pad | 移动 |
|---|---|---|---|
| hover | 必须提供 | 可能失效，信息须可由点按获得 | 不存在，用 active 替代 |
| 触控目标 | ≥24px | ≥40px | **≥44px（硬性）** |
| 导航 | 顶栏 + 侧栏 | 侧栏随断点 | 底部 Tab ≤5 项 |
| 弹层 | 居中 Modal | 居中 Modal | 底部 Drawer / 全屏 |
| 正文下限 | 14px | 14px | 14px |

- 禁止 JS 嗅探设备，只用断点与媒体查询。
- hover 承载的关键信息，移动端必须有替代入口。

## 4. 设计要求（跨场景组装规则）

> 两层：概念性要求定方向（跨页面类型普遍成立），具体要求给做法（本系统沉淀）。页面骨架见 §2 布局。

### 概念性要求（理念层）

1. **信息密度与呼吸感按页面任务平衡**——聚焦型页面敢留白、立重心；列表型页面保密度、立节奏。
2. **视觉层级必须与信息层级一致**——重要的更大更醒目，次要的退后。
3. **一致性优先于个性**——同场景永远同样式。

### 具体要求（本系统沉淀）

#### 具体要求（本系统沉淀 · 流程级组合）


- **form_validation**：失焦校验单字段、提交全量校验、禁输入中逐字报错
- **loading_strategy**：结构可预期→skeleton；结构未知或<1s→spinner；页面级→顶部细进度条
- **danger_action**：必过 Modal 二次确认 + danger 按钮 + 后果与恢复说明

## 7. 图标与素材

**图标（本地化）**：
- 存放：`assets/icons/line/<name>.svg` 与 `assets/icons/fill/<name>.svg`，形状同名成对；kebab-case 语义命名。
- 引用：内联 SVG 优先（`currentColor` 随文字变色）；禁在 SVG 内写死色值。
- 尺寸只用 `--icon-sm/md/lg` 三档；同一页面只用一套风格（默认线性，选中态可面型）。
- 缺图标时用生成提示词母版（见 HTML §12 PROMPT 块），生成后必须 16px 可辨 + 与现有图标并排风格一致，任一不过即重生成。
- 外部图标库只取 SVG 源码落盘重命名，不保留外链依赖。

**素材资产**：
- 分类五类：placeholders / empty / illustrations / photos / brand，各归其目录。
- 命名 `<语义名>-<宽x高>.<ext>`；每枚资产登记进 `assets/manifest.md`（名称/尺寸/来源/可复用场景）。
- 复用优先：先查 manifest，确无再新增；尺寸变体从母版派生，不存多份副本。
- 提取时连带记录来源截图编号，便于溯源。

## 8. 设计禁令（产出前逐条自查）

### 概念性禁令（理念层）

1. **禁把信息撑得太满**——布局要有呼吸感，间距留足，页面要有清晰主次。
2. **禁为留白牺牲信息密度**——列表页每行信息必须完整可扫。（与上条成对：两头都是极端）
3. **禁让用户思考「这是什么」**——元素含义必须自明；图标必配文字标签。
4. **禁一屏多主任务**——一屏一个主行动；浏览列表页禁塞竞争性 CTA。

### 具体禁令（产出前逐条自查）

1. 禁裸 hex / 裸值——一切取自 token 表。
2. 布局间距禁魔法数字（非 4 的倍数）。
3. 禁颜色作唯一信息载体（WCAG 1.4.1）。
4. 禁一视图双 primary 按钮。
5. 禁阶梯外字号；正文禁加粗替代标题层级。
6. 禁阴影 + 描边双重强化；禁彩色阴影；禁 x 偏移阴影。
7. 禁循环装饰动画；无状态变化不加动效。
8. 禁混用图标来源；禁 SVG 内写死色值；禁拉伸变形。
9. 禁 div 充当按钮；禁移除 outline 而无替代。
10. 禁高危操作无二次确认。
11. 禁 z-index 自造数值。
12. 禁静默禁用——禁用必须附原因。


### 无障碍红线（自「无障碍验收」章归位）

1. **状态不只靠颜色**——信息不得仅靠颜色传达（状态配图标/文字）；自查：转灰度看信息是否仍完整。
2. **键盘可达**——可操作元素 Tab 可达、焦点可见（--focus-ring）、Modal 内 Esc 关闭；自查：拔鼠标走完流程。
3. **可读名称**——图标按钮必带 aria-label、图片有 alt、控件有 label；自查：开屏幕阅读器听一遍。
4. **减弱动效**——尊重 prefers-reduced-motion（动效章提供了实现代码）。
5. **禁 div 充当按钮**——无键盘语义；禁移除焦点描边而不提供替代。

对比度验收（归颜色章）：正文 ≥ 4.5:1；大字（≥18px 粗体）≥ 3:1；UI 部件描边 ≥ 3:1——取色器测前景/背景比对 WCAG 表。
