# 产物目录结构与预览壳

## 产物目录结构

```
<工程目录>/
├── intake/                # 风格提示词.md + 用户输入.md + 开工文档.md
├── design/                # 页面地图扩展.md + 设计资产与动效规范.md（交付物，文件名固定）
├── <风格id>/              # 每风格一个目录（直接产出，不跑 build）
│   ├── <风格id>.html      #   风格 HTML（全部页面+页面列表导航）
│   └── assets/            #   本风格资产：fonts/ + images/ + icons/（相对路径按 html 同目录书写）
│       └── fonts/         #   真字体 woff2（主代理开工前统一备好，许可文件随包）
├── fragments/             # （跑批时）各链路代理的页面片段——片段内资产引用按合并后位置书写——跑完由主对话合并进 <风格id>/<风格id>.html
├── shots/                 # 渲染实看截图（回执证据，按风格/链路分子目录）
└── 风格目录.html           # 多风格时的链接聚合页（纯静态，列各风格目录链接）
```

单风格：一个 `<风格id>/` 目录。多风格：N 个风格目录 + 一个目录页。**交付=整个 `<风格id>/` 目录打包**（html+assets 同居，整目录搬走不断链）。

## 预览壳模板

`templates/preview-shell.html`（本技能 templates/）——**左侧页面列表 + 手机框画布**，纯静态不跑 build，视觉对齐编辑器预览形态（转化时换编辑器壳，观感延续）。用法见文件头注释：

- 加一页 = 复制整段 `<section class="screen">`（含 `.device.mobile > .viewport` 两层壳），改 data-screen（英文 id）/data-name（中文），页面内容写在 `.viewport` 里，当前页加 `on`；
- 侧栏每页一个列表项 `<button class="pg-item" data-go="英文id">中文名</button>`，当前页的加 `on`；
- 页面随画随加：加一个 section + 加一个列表项。

**转化衔接**：页面结构 `section > .device > .viewport` 与编辑器壳**同构**（device 参数同源：375×812 / 圆角 34 / 机身边框 10px / 刘海）——附加A 转化时页面块直接进编辑器壳，壳的视觉同款，客户观感延续。桌面端项目用 `.device.desktop`（1200×800）。

## 设计稿阶段不跑 build

build.py（编辑器组装、页面树门禁、口令注入）是**编辑器/转化线**的活。设计稿阶段的"合并"只有两种，都是复制粘贴级：

1. 多风格目录页（纯静态链接聚合，各风格目录一行一个链接即可）；
2. 跑批片段合并进 `<风格id>/<风格id>.html` 主文件（主对话动作，见主技能 references/batch-production.md；**片段内资产引用按合并后位置（`<风格id>/` 内）书写**）。

## 资产细则（铁律 5/8 的操作口径，正本在这）

- **零网络请求口径**：产物运行期禁 CDN/绝对 URL/外链图（离线完整可看）；生产期联网下载图片是允许的制作动作，下载落 assets。
- **资产相对路径**：按 html 同目录位置书写——图片 `assets/images/`、字体 `assets/fonts/<风格id>-*`、单图标文件 `assets/icons/`。
- **图标 file:// 陷阱**：sprite 必须**内联**进 html——file:// 下 `<use href="外部文件#id">` 被浏览器静默拦截（图标整批不显示且无报错）；单图标文件必须 `<img>` 引用，禁 `<use>` 外链。
- **禁 base64 内嵌大资产**：单文件 base64 膨胀 33% 且编辑器转化还要反解；小图标 sprite 内联除外。
- **字体装配**：品牌字体按风格提示词/客户 VI 指定取**真字体 woff2**（只装免费商用/开源许可字体，许可文件随包）；主代理开工前统一备好（并发画师只引用不下载，防写冲突；独立使用 gui 时本技能即主代理）；下载不可得=停下上报，禁静默回退。
- **图片供给链（用到才走，禁开工前预探查）**：画到具体页面确需照片/插画位时——先线上找贴合业务语境的图片/插画（下载进 assets/images）→ 线上没有合适的 → 才探查生图能力兜底（技能/CLI/API 皆算，有则生成原图存 assets/images，无需压缩转码；探查不到则给生图提示词包并如实告知）；开工前禁预探查生图技能与生图 token，探查发生在哪步、为什么，如实写进交付说明；图片来源如实写进交付说明。

## 预览口径

`<风格id>/` 目录内 html+assets **file:// 直开即完整预览**（页面列表+切换在 html 里，字体/图片/图标经相对路径从 assets/ 加载——file:// 下相对路径资源加载不受限制），不存在"降级预览"。图标 sprite 内联的陷阱见上方资产细则。
