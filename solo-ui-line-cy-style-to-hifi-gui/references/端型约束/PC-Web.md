# 端型约束 · PC-Web（差异层，配合 _共用.md 读）

> 覆盖桌面浏览器/桌面 Web 应用（含管理后台）的独有平台行为。视觉归风格提示词（后台可以长任何风格）；本文件只装桌面平台行为。**管理后台的"侧栏+表格"布局惯例不进本文件**——那是品类惯例，归画师按信息先行推导。

## 一、浏览器宿主行为（平台渲染，页面适配即可）

| 交互/界面 | 浏览器真实形态 | 断言 |
|---|---|---|
| 滚动条 | 各浏览器原生滚动条（占宽 15-17px 或悬浮式）——页面宽度计算需计入；样式可用 CSS 自定义但跨浏览器不一致 | 布局禁因滚动条出现/消失而横跳（`scrollbar-gutter` 语义，登记给开发） |
| 通知权限 | 浏览器 Notification API 授权提示（浏览器渲染） | 禁自绘通知权限 UI；入口行即可 |
| 文件下载 | 浏览器下载管理 | 页面只画下载入口，禁画下载进度弹窗（浏览器有） |
| 新标签页跳转 | target=_blank 由用户控制 | 站内流转默认当前页；外链才开新标签 |
| 右键菜单 | 浏览器原生右键 | 禁用右键=用户体验减分项，非必要不做 |

## 二、桌面平台规范（带实值）

- **无 safe-area/刘海**：但有浏览器 UI（地址栏/标签页）——视口即页面边界，无系统装饰避让
- **hover 是一等交互**：可点元素必须有 hover 反馈（桌面漏 hover=可点性不可见）；纯触控交互（长按/滑动删）在桌面需给替代（显式按钮）
- **键盘是一等输入**：快捷键、Tab 焦点顺序、Enter 提交——表单页登记键盘流；焦点可见性（focus ring）禁移除（无障碍+键盘用户）
- **分辨率基准**：1440×900 常规基准（管线代表页口径），断点登记给开发（1280/1440/1920）；**最小可用宽度**必须成立（1280 下不横爆）
- **文字选择/复制**：Web 页面默认可选中——故意禁选（user-select:none）只用于纯交互控件
- **光标语义**：可点=pointer、可编辑=text、禁用=not-allowed——光标反馈与可点性一致

## 三、生态行为边界

- **零网络请求约束照旧**：本管线的产物口径（离线可看）不受 PC-Web 端型影响——CDN/外链照禁
- **浏览器兼容范围**：需求方未指定时按现代 Chromium 口径（效果图单一口径）；兼容范围登记给开发
- **弹窗语义**：确认/警告用页面内对话框（模态），不用浏览器原生 alert/confirm（原生样式不可控且阻塞线程——真机习惯也是页面内模态）
- **打印**：管理后台常有打印需求（打印样式登记给开发，效果图不涉及）

## 四、注意登记

| 事项 | 说明 |
|---|---|
| 手机习惯搬到桌面 | 禁长按/滑动删/抽屉导航当唯一入口——桌面给显式替代 |
| 桌面习惯搬到手机 | 反向同理（两端各自读各端文件） |
| 品类惯例越界 | 后台侧栏/表格布局是品类惯例归画师推导，本文件不规定布局 |
| 断点写死 | 断点数值登记给开发，效果图按 1440 基准画 |
