# 端型约束 · iOS App（差异层，配合 _共用.md 读）

> 只装 iOS 独有的平台行为；通用规则见 `_共用.md`。视觉语言（HIG 的组件形态/动效/字体主张）不进本文件——iOS App 可以不长 HIG 的样子，页面视觉归风格提示词。

## 一、宿主/系统渲染清单（禁自绘，页面标注"系统渲染"留空间）

| 交互/界面 | iOS 真实形态 | 断言 |
|---|---|---|
| 权限授权（定位/通知/相机/相册） | 系统弹窗（设置里可改，应用内无自定义形态） | 禁自绘授权 UI；页面只画触发入口 |
| 分享 | 系统分享面板（share sheet） | 禁自绘分享面板；页面只画分享入口 |
| 应用内支付 | 系统支付弹层（App Store 审核硬线：实物服务勿用 IAP，虚拟服务必须 IAP） | 效果图只画价格与入口，支付弹层标注"系统渲染" |
| 推送通知 | 系统通知中心，不在应用内复现 | 通知本身不画；应用内消息中心另画 |
| 键盘 | 系统键盘（输入框聚焦自动顶起，页面需避让） | 输入区底部留键盘避让 |

## 二、原生组件规范（带实值）

- **安全区**：顶部≈47-59px（灵动岛/刘海机型）、底部 home indicator≈34px——页面内容与操作禁入
- **灵动岛/挖孔屏**：顶部居中（iPhone 14 Pro 后）或左上角挖孔（旧机型）——壳体模板渲染，页面避让
- **返回交互**：屏幕左缘右滑返回手势 + 导航栏左上返回按钮——左缘手势区（≈20-30px）禁放可点元素
- **导航栏**：原生 ≈44px + 状态栏；大标题模式（iOS 惯例，可自绘变体）
- **底部操作条**：距底部 ≥34px 避让 home indicator
- **触控目标**：≥44×44pt
- **字体缩放**：Dynamic Type（用户调大系统字号页面跟随）——效果图固定字号，登记为开发注意项

## 三、生态行为边界

- **深色模式**：系统级切换——效果图单色态登记为范围声明，Token 重映射留给开发
- **推送通知**：一次/永久授权，通知在系统通知中心
- **App Store 审核硬线**（登记给开发，效果图不涉及）：隐私清单、账号删除入口（有账号体系必须提供）
- **iPad 多任务**：分屏/浮窗（见 平板.md）
- **左滑返回与页面内横向滚动冲突**：横向滚动组件距左缘留系统手势缓冲

## 四、注意登记

| 事项 | 说明 |
|---|---|
| 灵动岛误报 | 评审/自查别把灵动岛当页面控件（壳体渲染区，见 _共用.md 分工表） |
| 安全区数字随机型漂移 | 避让用"≥系统推荐值"口径，不写死单一数值 |
| HIG 与风格冲突 | HIG 的视觉主张不约束页面视觉；只有系统渲染行为是硬线 |
