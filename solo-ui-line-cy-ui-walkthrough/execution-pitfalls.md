# execution-pitfalls · 执行层踩坑记录（负面参考）

> **定位**：solo-ui-line-cy-ui-walkthrough 在真实执行中踩过的坑与绕行方案。它不评价技能本身；正式修入引擎/文档的条目会移入「已修复」节。
> **用法**：启动执行前扫一遍「⚠ 高危速览」（≤10 行）；执行中撞到同款症状，按关键词搜正文条目。
> **条目格式**：症状 → 根因 → 规避（实测做法）→ 状态（`可规避`＝执行者照做即可；`待修引擎`＝绕行无效或只能兜底，含 file:line 定位）→ 首踩日期。
> **纪律**：坑修进正式文档/引擎后移入「已修复」；本档不无限膨胀。`.dsh` 技能树是指向 `.claude` 的符号链接，本档落 `.claude` 根即双根可见。

## ⚠ 高危速览（只收费时/废案级）

1. Chrome 在 DSH 沙箱下必死（crashpad 自杀）→ 用 Edge：`$env:DSH_DESIGN_BROWSER` 指向 msedge.exe
2. 浏览器起不来时 batch.mjs 每页干等 25s——**首页失败立即熔断**，别烧全量
3. ~~全错误页会以 **exit 0** 收场~~ **已修（2026-11-24）**：batch.mjs 错误页>0 即 exit 2，引擎故障不再吞成"干净"
4. 750/2× 镜像树禁用 390 视口扫描——只扫 1x 主检面
5. 修复派发禁按页面竖切多代理——脚本层 + 1~2 个判断代理 + 专项微修
6. 工单发**成品改动清单**，别发修法配方
7. 镜像树同步（px×2）是脚本活，禁让代理手抄
8. ~~11px 会以 REAL/medium 出现（分类分支失效）~~ **已修（2026-11-24）**：classify 字号判据已覆盖引擎句式「文本小于 N px」，11px 豁免线恢复生效
9. focus-visible 探针盲区：修完照样报 high——走豁免，别反复修
10. compare 的「新引入」有假阳性（worst offender 换键）——人工甄别再定性
11. 观感/仲裁层 P1 进不了复验闭环，compare 会假标「已修复」——铁律 3 已加限定，台账仍需人工确认

## 一 环境与引擎启动

### 1. Chrome 在 DSH 沙箱下自终止（首踩 2026-10-21）· `可规避`
- 症状：逐页报 `无头浏览器未在 25000ms 内开放调试端口 … fetch failed`
- 根因：DSH 沙箱拒绝 crashpad 的 OpenProcess（0x5）→ Chrome 打印 `crash server failed to launch, self-terminating` 后自杀；且 Node `spawn()` 出的浏览器进程被以 STATUS_BREAKPOINT(0x80000003) 终止，加不加 `--disable-crashpad` 都一样；`Start-Process`（ShellExecute 路径）对浏览器 exe 放行、对 node.exe 拒绝
- 规避：换 Edge——`$env:DSH_DESIGN_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'`（Edge 对 cache 目录的 ACL 告警非致命，DevTools 端口正常）。提权 danger-full-access 后 Chrome 也能跑，但默认 Edge 最稳
- 状态：可规避；诱因是 cdp.js:29-40 候选固定 Chrome 优先且不试活

### 2. 浏览器故障烧穿全量（25s × N 页空转）（首踩 2026-10-21）· `已进文档＋待修引擎`
- 症状：120 页逐页报引擎错误，约 50 分钟空转，产出全错误台账
- 根因：batch.mjs 逐页 capturePage，launchTimeoutMs=25_000（cdp.js:313），首页失败不熔断
- 规避：批量前先跑单页冒烟；已写进 SKILL.md 执行纪律「引擎熔断」——首错即停
- 状态：熔断逻辑本体待修引擎（batch.mjs 主循环：首页引擎错误 → 立即 exit 2）

### 3. 引擎故障被吞成 exit 0（首踩 2026-10-21）· `已修复`
- 症状：假使带故障跑完全量，会"干净"退出——环境故障与真没问题同码，违反「完成由退出码裁定」
- 根因：batch.mjs 引擎错误页 push `error` 且 findings=[]，汇总/退出码只看 p1
- 修复（2026-11-24）：batch.mjs 退出码改三态——错误页>0 即 exit 2（引擎故障），p1>0 即 exit 1，否则 0；任何错误页都算漏检缺口，偶发超时重跑区分，守门宁严勿松
- 状态：已修复（batch.mjs 汇总段）

### 4. 引擎候选固定顺序、无试活降级（首踩 2026-10-21）· `待修引擎`
- 症状：Chrome 不可用时全量失败，需人工指定 Edge
- 根因：cdp.js:29-40 BROWSER_CANDIDATES 按序取第一个**存在**的 exe，不试活
- 规避：`DSH_DESIGN_BROWSER` 显式指定可用浏览器
- 状态：待修引擎（候选试活 + 自动降级）

## 二 扫描与探针

### 5. 双尺寸镜像树全量假溢出（首踩 2026-10-21）· `已进文档`
- 症状：若扫 750/2× 树，几乎每页报横向溢出（内容 750 > 视口 390）
- 根因：batch.mjs 硬编码 viewport 390×844；2× 导出镜像不是为 390 视口准备的
- 规避：只扫 1x 主检面树（375/）；镜像树作为**修复镜像**（px×2 同步），报告头显式声明。已写进 scenarios.md 路由表
- 状态：已进文档（scenarios.md §输入形态路由）

### 6. 11px 字号豁免分支失效（首踩 2026-10-21）· `已进文档＋待修引擎`
- 症状：53 条 11px 文本以 tier=REAL/severity=medium 出现，与 calibration「字号豁免线：11px 豁免」矛盾
- 根因：batch.mjs classify 的字号分支 `/字号/.test(msg)` 匹配 message，而引擎 message 是「N 处文本小于 12px，最小 11px」——不含"字号"二字，分支永不命中（checks.js typography/font-size-floor 的 message 措辞）
- 规避：仲裁层按校准规则兜底判豁免；severity=medium 不进 P1，**不卡退出码**
- 状态：已进文档（calibration.md 引擎现状口径）；机制修复待引擎（对齐 message 措辞或按 id 判断）

### 7. focus-visible 探针盲区（首踩 2026-10-21）· `已进文档＋待修引擎`
- 症状：16 个表单页补了 `:focus-visible` 焦点环后复验**仍然报 high**，怎么修都消不掉
- 根因：collect.js §焦点可见性只把「含 outline:none 的规则」（≤10 条）放进样本（:554-577），checks.js:646 在样本里找 focus-visible 字样——**替代规则永远不在样本里**
- 规避：给修完仍报的页面按「焦点环替代」规则豁免（exemptions.json 加 `{rule:"焦点可见"}`）；别反复改页面
- 状态：已进文档（calibration.md 引擎现状口径）；探针修正待引擎（样本应含全部规则或按计算样式判）

### 8. image-alt 双条件自相矛盾（首踩 2026-10-21）· `已进文档＋待修引擎`
- 症状：图片明明 `alt=""`（装饰合规），仍报「缺 alt 的图片」high
- 根因：collect.js 图片段（:326-337）要求 `role="presentation"` 或 `aria-hidden="true"` 才认装饰；expected 文案却写着「装饰图 alt="" 或 role="presentation"」——判据与文案不一致
- 规避：给空 alt 装饰图补 `role="presentation"`（机械、零视觉影响），一次脚本全站清
- 状态：已进文档（calibration.md 引擎现状口径）；口径统一待引擎

### 9. 对比度 finding 整页打包，豁免粒度被迫粗放（首踩 2026-10-21）· `待修引擎`
- 症状：一页的对比度 finding 把 N 处 offender 混在一条里——真问题（灰字）与豁免类（渐变按钮/品牌蓝/tint 标签）绑死
- 根因：checks.js a11y/color-contrast 每页汇总一条（count + 样例）；豁免匹配对 finding 整条 JSON 做子串匹配 → 一条 offender 命中即整条豁免，**可能掩盖同包真问题**
- 规避：顺序依赖——先修真问题（灰/橙），让豁免类成为复验残留，再由豁免清单收割；报告中声明该风险
- 状态：待修引擎（offender 分条或分桶出 finding）

### 10. 扫描串行、无重试（首踩 2026-10-21）· `待修引擎`
- 症状：120 页串行 ~8 分钟；偶发失败无重试
- 根因：batch.mjs 单循环顺序处理
- 规避：接受（一次走查内可容忍）；别为此改并发引入新风险
- 状态：待修引擎（页级并发 + 失败重试一次）
