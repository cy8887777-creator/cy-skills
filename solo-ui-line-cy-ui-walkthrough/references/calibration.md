# 校准规则 · 误报豁免 · 判级口径

> 探针报的是**症状**，不一定是**结论**。每条问题过一遍校准规则：命中豁免 → 记入豁免清单（一行一条理由）；未命中 → 进真问题分级。
> 豁免不是删除——落 exemptions.json 留痕，越用越准。

## 校准规则（按规则名索引）

| 规则 | 现象特征 | 判定 | 处置 |
|---|---|---|---|
| 渐变底误报 | 对比度问题的元素底色为 CSS 渐变——检查器只读纯色背景，渐变读作透明 → 误报白底白字 | **误报** | 豁免（自动识别依赖证据含令牌名，缺省由观感评审抽样兜底）；渐变令牌清单由项目 config.gradient_tokens 注入 |
| 间距口径 | 间距网格类问题（"N 种间距值 M 种非整数倍"） | **静默校准**：刻度按契约刻度表判定（无契约用事实基线众数），不合网格的照报，合法档不报 | 不询问用户；异常众数本身作为发现上报 |
| 焦点环替代 | 焦点类问题引用共享输入样式——共享样式已有焦点阴影环替代（检查器只认描边类焦点样式） | **误报** | 豁免；页面级无任何替代的仍算真问题 |
| 祖先遮挡 | 元素被**祖先**元素"遮挡" | **误报**：祖孙包含关系非遮挡 | 直接豁免 |
| 屏幕外面板 | 移出可视区的面板元素被扫到（如注释面板） | **误报**：已移出可视区 | 取证按 config.hide_selectors 注入过滤预防；残留即豁免 |
| 字号豁免线 | 字号 11px | **豁免**：契约「11px 仅限短提示/角标」 | 正文连续大段 11px 仍报 P1 |
| 触控建议档 | 触控目标 22-44px | P2（平台建议档）；**<22px 才是 P1 硬线**（常识线，静默校验） | 无需口径回填 |
| 图底对比度 | 对比度问题的底色为**图片** | 无法机械判定 | 转观感评审层（AI 看图复核） |
| 静态子元素压角 | 命中测试排除祖孙关系后残留的"几何合法视觉怪" | 非探针误报，但也非确定性缺陷 | 观感评审层兜底；无观感层时标注"未复核" |

## 语义色契约冲突（升级项，不属页面缺陷）

若契约规定状态标签「同色浅底 + 同色文字」配方，该配方普遍不达无障碍对比标准（中间亮度语义色压浅色底，对比度天然不足）——**契约层冲突，非页面实现错误**。处置：① 不改页面；② 报告单列"契约冲突升级项"；③ 引导契约引入同色相加深档，标签/文字类改用；④ 品牌色文字可按品牌立场豁免挂账。具体色值与加深档由**项目契约记录**，本技能不持有任何项目色值。

## 归并规则（防同证据多判据重复报）

同一元素同一属性只出一条问题：主判据定级，副判据结论并注（如"节奏失控，且值 13px 不在刻度"）。引擎曾出现"同一选择器在补丁里重复 8 次"——按选择器全局归并。

## 豁免清单格式（exemptions.json）

```json
{ "selector": "div.示例卡片 i.示例图标", "rule": "contrast",
  "why": "渐变底误报（命中项目 config.gradient_tokens）", "date": "2026-10-20", "by": "首轮走查" }
```

探针复跑时读取：命中豁免的问题降级为提示并保留在报告中（不静默消失——豁免也要可审计）。

## 引擎现状口径（design-audit 当前版本实测；引擎修复后删除对应条目）

- **~~11px 字号豁免的机制现状~~ 已修（2026-11-24）**：原 batch.mjs classify 字号分支只匹配「字号」字样，引擎 message 为「N 处文本小于 12px」不含该词 → 分支失效。现已扩为 `/字号|文本小于 N px|typography/i`，11px 豁免线恢复生效；引擎修复 typography 判名后本条可删
- **焦点环探针盲区**：collect.js 焦点可见性采样只收集含 `outline:none` 的规则（≤10 条），`:focus-visible` 替代规则永远不在样本 → 焦点类恒报 high。页面已注入替代环的一律豁免（collect.js ／ checks.js a11y/focus-visible）
- **image-alt 双条件**：`alt=""` 必须搭配 `role="presentation"`（或 `aria-hidden="true"`）才被认作装饰图，否则报缺 alt（collect.js 图片段）。给空 alt 装饰图补 role 即消

## 分级三轨映射（唯一口径，别处不得另立）

| 引擎 severity | 台账/报告级别 | 对账等式用语 |
|---|---|---|
| blocker / P0 | P0 | 阻断 |
| high | P1 | 严重 |
| medium | P2 | 建议 |
| low / info | P3 | 建议（宽义） |
