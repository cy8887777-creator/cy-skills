# 判据体系 · 机械探针 + 观感复核

## 机械探针 13 组（脚本判读，全部可数字出证）

| 组 | 查什么 | 判据 |
|---|---|---|
| 布局几何 | 横向滚动、元素越界、页面溢出 | 文档宽大于视口；右缘超出视口的元素按超出量排序 |
| 遮挡 | 非祖孙元素相交、文本被盖 | 相交面积达标且中心命中非祖先元素 |
| 触控目标 | 交互元素 <22px（硬）/ <44px（建议） | 枚举链接/按钮/输入类元素量尺寸 |
| 对比度 | 文字 vs 有效背景不足 | 计算样式取色算比值；渐变/图底转观感层 |
| 字号 | 正文 <12px、说明 <11px | 字号分布 + 过小清单 |
| 行高/行长 | 行高 <1.3、行长偏离 45-75 字符实测 | checkTypography |
| 间距刻度 | 同层间距偏离契约刻度/事实基线众数 | checkSpacing |
| 色彩 | 文本色种数 >8 | checkColorPalette |
| 资源 | 断图、404、字体加载失败 | 请求监听 + naturalWidth |
| 报错 | 控制台错误级输出 | 每页收集 |
| 层级 | 魔法层叠值（契约只许三档）、层错乱 | 枚举层叠值对照档位 |
| 换行 | 孤字掉行、标点顶行首、长串撑破 | 行矩形分析 |
| 布局跳动CLS | 图片无宽高预留 | checkImages |

## 观感复核层（模型逐屏，标准档起）

**观感层任务书（首选）**：`references/observation-rubric.md`（收编自 refactoring-ui-skill，MIT 署名）——七视角固定因果序扫查（层级→布局间距→排版→色彩→深度→图像→收尾），finding 挂规则 ID（§x.x），字段映射与本地化条款见文件头。**派发形态：页间并行 × 视角串行**（≤30 页/片，一次性子代理；禁止视角间并行——因果失效产假 finding）。任务书缺失 → 降级用下方维度清单，并在报告声明。

**开查前置：审美定调三立场**（写进报告头，判定全引用它）：
1. 边界立场：弱边界（发丝线/微差底色）还是强边界（实卡/投影）？弱边界≠无边界，两端都判
2. 色彩立场：强调色唯一？语义色成体系？
3. 密度立场：内容型（密）还是营销型（疏）？

**逐屏维度清单（判定引用中文维度名）**：
- 色彩：强调色贯穿、语义色不混用、深底对比
- 排印：阶梯可辨、字重层级、孤字换行
- 空间：刻度节奏、留白层级、组间分隔
- 容器：档位一致、卡套卡不超过两层、承载语义可说明
- 图像：图标成套、占位有设计感
- 构图：首屏重心、行动点CTA 唯一、扫描路径、空态引导
- 交互：状态完备、反馈一致、操作闭环、导航去向、键盘可达
- 技术卫生：控制台、路由实测、响应式抽检

每条观感问题：级别 + 维度名（如"空间·留白失衡"）+ 截图证据 + 修法方向。

## 观感取证规程（三步，兑现零截图铁律的临时目录条款）

1. **截图**：用会话的页面取证工具（design_capture）把可疑页截图输出到**系统临时目录**（如 `%TEMP%/ui-walkthrough-shots/`），一批一清——**必须显式传 outputDir 参数**，此类工具默认落工作区（如 `.design-audit/`），一步疏忽即破零截图铁律
   - **批量按分片落盘**：先 `node scripts/shard-pages.mjs <页面根> <out目录> [片大小]` 出分片（shards.json + shard-status.json），截图按 `shots/<片号>/<页面相对路径>.png` 落盘——子代理按片领取，截图↔页面对应关系以 shards.json 为准
   - **断点续跑**：shard-status.json 记录各片状态（未派发/派出/完成/中断）；中断后只补非「完成」片，截图已存在的片跳过重拍
2. **判定**：模型逐张读图，按观感层任务书（observation-rubric.md，七视角因果序挂规则号；缺失降级维度清单）逐项判，产出观感问题（级别 + 维度名 + 截图路径 + 修法方向）
3. **清理**：该批判定完成**即删临时截图**——临时目录不留底，交付目录不出现

会话不具备截图/读图能力时，观感评审层跳过并在报告声明降级。
