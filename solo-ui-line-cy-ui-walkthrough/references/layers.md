# 六层探查体系 · 场景路由

> **[已废弃 2026-10-21]** 本档内容已收编：场景路由与约束 → scenarios.md（含品牌横滑/懒加载勿报、需登录降级等），已知探针局限 → calibration.md（含静态子元素压角由观感层兜底）。本文件保留仅作历史参考，**勿据其执行**——与 scenarios.md 冲突时以后者为准。

## 总则

- 层与层可组合；**每层独立产出问题片段**，汇总进同一台账
- 脚本机检永远先跑——它是地基，也是其他层的取数器
- 模型判断集中在台账仲裁阶段（定性/误报裁决/审美），不散落各层

## 场景路由表（什么输入 → 什么层组合 → 什么约束）

| 场景 | 层组合 | 约束/降级 |
|---|---|---|
| 静态 HTML 批量原型 | 脚本机检全套 + 读证归因 | 零前置；390 视口 |
| SPA / 异步渲染 | 脚本机检（须等待渲染）+ 空壳检测 | 元素 <20 = 疑似未挂载，标记后读源码归因 |
| 本地路径带 query 参数 | 脚本机检经本地静态服务 | 路径解析不认 query → 起本地静态服务走 http |
| dev server / URL | 脚本机检 + 读证归因 | 直接取证 |
| 需登录的页面 | 交互旅程存储态 / 种子账号 | 拿不到会话 → 降级组件级审计并声明 |
| 深色模式站点 | 脚本机检双主题 | 深浅各跑一遍，对比度/遮挡双份 |
| admin / PC 布局 | 脚本机检 ≥1280 视口 | **禁用 390 手机视口出结论**（无效功） |
| 品牌横滑 / 轮播 / 懒加载 | 脚本机检 + 观感评审 | 渐隐遮罩/部分渲染为有意设计，勿报 |
| canvas / WebGL 内容 | 声明不支持 | 页面探针看不见画布内部 |
| 小程序包 | 声明不支持（一期） | 需小程序自动化工具，独立工具链 |
| React Native / Flutter | 声明不支持 | 无网页文档结构，需原生框架工具 |

## 已知探针局限（产生校准规则的原因，细则见 calibration.md，报告须声明）

1. 渐变底对比度：检查器读不到渐变底色 → 白字误报白底（规则：渐变底误报；令牌清单由项目配置注入）
2. 静态子元素压角：命中测试排除祖孙关系——"几何合法视觉怪"由观感评审层兜
3. 焦点环替代：检查器只认描边类焦点样式，共享样式的阴影环替代会误报（规则：焦点环替代）
4. 间距口径：契约刻度表或事实基线众数，静默判定（规则：间距口径）
5. 屏幕外元素（移出的面板）会被扫到——取证按配置的隐藏选择器过滤
