# 启动引导 · 欢迎话术与提问流程

## 启动欢迎（技能触发后先输出此块，再进提问）

```
🧭 UI 走查就绪

这是一个界面走查技能：从视觉美观、布局规范、文案内容、可访问性几个维度，
批量审查各类 HTML 页面。深度可调、场景灵活。

两种用法：
· 本地项目（目录/工程）：查改闭环——扫完出报告，你确认后派发修复，修完自动复验
· 线上网址：仅走查出报告（不是你的源码，改不了）

流程一句话：脚本全量扫描 + AI 识图评估 → 逐条定性 → 报告给你确认 → （本地项目）派发修复 → 自动复验。

把目录或网址发我就开始；查多深、耗时多少，选项里会标。
```

> **表述分工（勿互改）**：欢迎语讲审查**维度**（美观/布局/文案/可访问性）；SKILL.md 的 description 讲**触发与典型缺陷清单**（溢出/遮挡/对比度…）。两处各自成立——欢迎语面向用户讲能力维度，description 面向模型讲触发匹配。

## 合并简问规则

触发句已包含答案的问题，**跳过该屏不重复展示**（如用户首句已给目录 → 第0问不再出；首句说「用识图」→ 问②不再出）。未含答案的照常问。

## 第0问 要走查的页面在哪里？

话术：「要查的页面在哪？发我目录、单个文件或网址都行。」

- 工作区里有多个候选目录时，**列出来让用户挑**，不自作主张选一个
- 拿到路径后**先做存在性校验**（目录/文件是否存在），不存在 → 回问而不是带病执行
- 给了网址 → 仅走查（问③自动锁定只输出报告）
- 形态登记统一为两类：**本地路径**（目录/单文件）或**线上网址**——台账与锁定单按这两类登记
- 技能为双根安装（`.claude\skills` 与 `.dsh\skills` 各一份）：两根**可能是符号链接或独立副本**——改前先查（PowerShell：`Get-Item <.dsh文件>.Target`，有指向=链接单写即生效；无指向=独立副本须双写同步）。2026-10-21 本机实测为符号链接

## 问① 有没有设计系统？

| 答案 | 模式 | 组装差异 |
|---|---|---|
| 有（给路径） | **严格模式** | 间距刻度/令牌按契约白名单**违规级**组装；离群直接判违规 |
| 没有 | **一致模式** | 事实基线（统计主流值为基线），离群报建议级；报告头注明"立场为推断"，并建议先跑设计系统提取 |

## 问② 要不要用 AI 识图能力？

**前置自检**：先确认当前会话具备截图与读图能力——不具备 → 提示"当前会话不支持识图"，按「不用」处理，**不问此题**。

| 答案 | 对用户说的全部内容 |
|---|---|
| 用 | 额外可评美观/构图/层级 |
| 不用 | 只用脚本查几何/字号/间距等硬指标；错误分析仍由 AI 做 |

> 选项话术**只说对用户的结果**，禁止带"场景菜单会隐藏/全显/耗时增加"这类机制解释——过滤是系统行为，菜单出现时用户自然看到。

## 【场景选择菜单】（唯一模板；点选即定，回复编号即可）

> 问②=不用识图时：**隐藏 2/4（含 AI 读图项），保留原编号跳号**（1/3/5/6），自定义清单同步剔除观感评审组；菜单头加一句「已按你的选择精简：2 项含 AI 读图的选项已隐藏」。
> 不用识图 ≠ 全程无 AI：文字内容检查（AI 参与分析，不看图）保留显示。

| # | 场景 | 内容 | 耗时 |
|---|---|---|---|
| 1 | UI 脚本 | 几何布局/遮挡/Z轴/换行/字号/间距/资源健康 | 几分钟 |
| 2 | UI 脚本+观感评审（AI 读图）〔不用识图时隐藏〕 | 1 + AI 读图判美观 | +数分钟 |
| 3 | UI 脚本+文字内容检查（AI 参与分析，不看图） | 1 + AI 文案（错字/占位/死文案） | +数分钟 |
| 4 | UI 脚本+观感评审+文字内容检查〔不用识图时隐藏〕 | 2 + 3 | +数分钟 |
| 5 | UI 脚本+交互完整 | 1 + 触控/表单/列表/弹层 + 路由完整 | +10 分钟起 |
| 6 | 全选（当前菜单全部可选项） | 用识图=全量；不用识图=1+3+5 | 半小时起 |
| 7 | 深度走查（AI 深检） | 1 + 界面六轴深检（排印/文案/无障碍/布局/颜色/打磨），按严重度排序出深检报告 | 随页数增长，最久 |
| ▸ | 自定义 | 用多选问题把全部能力按域分组列出，用户逐项打勾；**过滤规则与菜单一致** | — |

有设计系统时，以上各场景的间距/令牌项自动升级为违规级组装。

## 问③ 检查出的问题是否修复？（决定中间是否还有人工参与）

| 答案 | 行为 |
|---|---|
| 按照 AI 诊断内容直接修复 | 仲裁后连跑规划/派发/修复/复验，中间不停 |
| 仲裁后暂停确认 | 仲裁完成出**修复任务单**（按子代理逐个列分工：谁修哪些页/哪些文件/什么修法），用户确认后才派发；确认后修复与复验连跑 |
| 只输出报告 | 仲裁完成后交付，修复另起 |

> 输入为线上网址时，问③ 固定为**只输出报告**——线上站没有源码，修复层不可用。

## 探查层对照表（场景菜单的组装依据）

| 探查层 | 方式 | 查得到 | 查不到/风险 | 成本 |
|---|---|---|---|---|
| 脚本机检 | 无头浏览器+确定性探针 | 几何/对比度/触控/资源/报错/令牌 | 美丑、因果归属 | 极低 |
| 源码静态分析 | 不开浏览器扫样式与结构 | 硬编码色、非法嵌套、弃用模式 | 渲染后才暴露的问题 | 低 |
| 读证归因 | 模型读证据包 | 病因、跨页一致性、业务合理性 | 纯视觉观感 | 中 |
| 观感评审 | 模型读截图 | 构图/层级/品牌感/"看着不对" | 精确数值、幻觉误报 | 高 |
| 交互旅程 | 脚本化交互后测量 | 状态类缺陷（提交后/展开后/加载后） | 需逐页旅程配置、黑盒 | 中高 |
| 人眼终审 | 用户开真页面 | 一切 | 不可扩展 | 人 |

## 口径说明（静默，不询问）

字号下限（正文 12 / 说明 11）、触控硬线（22px，建议 44px）、间距刻度（契约刻度表，无契约用事实基线众数）均为常识线**静默校验**——不问用户；项目差异（渐变令牌/豁免/视口档）由 `--caliber 项目口径.json` 注入，不改技能内缺省文件。
