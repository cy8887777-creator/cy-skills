# 场景路由表 · 特殊场景约束

> 输入识别后按本表路由；**不支持的场景必须在报告显式声明，禁止静默跳过。**

## 输入形态路由

| 输入形态 | 路由 | 约束 |
|---|---|---|
| 本地目录（纯静态） | file:// 直取 | 可直接跑，零配置 |
| 本地目录（带 query 链接/相对资源跨根） | 起本地静态服务走 http | 路径解析不认 query 后缀；`python -m http.server` 即可 |
| 单文件 | file:// 直取 | 同目录资源相对路径需保持 |
| 双尺寸镜像树（如 `375/` 与 `750/` 2× 导出成对） | 只扫 1x 主检面树（390 视口）；镜像树**不机检**（2× 尺寸在 390 下全量假溢出），仅作修复镜像（px×2 脚本同步），报告头显式声明 | 逐字溯源：两树页面一一对应（`-750` 后缀） |
| URL（http/https） | 直取 | 需网络可达；**仅走查**——线上站无源码，修复层不可用，报告头注明"仅走查" |
| dev server | 直取 | 记录端口与 commit SHA 进报告头 |
| SPA（元素 <20 疑似空壳） | waitFor 标志性选择器后重取证 | 仍 <20 → 读源码归因，声明"未完成取证" |
| 需登录 | 种子账号/存储态 | 拿不到 → 降级组件级审计并声明 |

> **形态登记与校验**：锁定单/台账统一登记为两类——**本地路径**（目录/单文件为其子形态）与**线上网址**。第0问拿到路径先做存在性校验，不存在 → 回问，不带病执行。
> **双根安装**：本技能在 `.claude\skills\` 与 `.dsh\skills\` 各有一份——两根可能是符号链接（单写即生效）或独立副本（须双写同步），改前先查拓扑（见 onboarding.md）；防两处漂移。

## 视口与主题路由

| 场景 | 约束 |
|---|---|
| 手机原型（device-frame 壳） | 390 主视口；壳体本身不计入布局判定 |
| admin / PC 布局 | **≥1280 视口**，禁用 390 出结论 |
| 品牌横滑 / 轮播 / 懒加载 | 脚本机检 + 观感评审；渐隐遮罩/部分渲染为有意设计，**勿报** |
| 深色模式站点 | 双主题各跑一遍（对比度/遮挡双份） |
| 响应式专项 | 320/768/1440 矩阵 |
| Windows 缩放 125% / DPR 2 | 抽测一档，固定宽布局照妖镜 |

## 明确不支持（报告显式声明）

- canvas / WebGL 绘制内容（图表内部、游戏画面）——DOM 探针不可见
- React Native / Flutter / nvue 原生渲染——无 DOM
- 微信小程序包——需小程序自动化独立工具链（二期预留）
- 需真实后端数据的业务正确性——只查展示层

## 已知翻车案例（从本项目实战沉淀，防再犯）

1. 平滑滚动未到位即截/量——scrollTo 后等 ~1s 确认落点
2. reveal 入场动画让整页取证出现假空白——滚动到位重取；"reveal 对无滚动场景不友好"记观察项
3. 内部滚动容器冒充页面溢出——`overflow-x:auto` 包裹的宽表是合法的，只认 documentElement 级横滚
4. 悬浮横滑条右缘渐隐/渐出是有意的——勿报
5. 页面自带评审/注释 UI（默认展开的面板、悬浮球）——取证时必须关闭：注入配置的 hide_selectors 过滤 + 按项目 query 约定关闭
6. admin 页是 PC 布局——禁用 390 出结论
